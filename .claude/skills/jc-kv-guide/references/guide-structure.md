# guide-structure.md — 키비주얼 제작 가이드 8섹션 표준

가이드의 정본은 `guide.json`(구조: `assets/guide.schema.json`) 하나다. 이 문서는 그 안의 8섹션이 **무엇을 담고, 어떤 규칙으로 채우는지**를 정의한다. 렌더 형식(HTML/MD)은 `scripts/render_guide.py`가 담당한다.

## 0. 출처 태그 4종 — 모든 항목에 하나씩

| source | 뜻 | 필수 부속 | 표시 |
|---|---|---|---|
| `quote` | 입력 문서 원문 그대로 | `ref`(`D1 §2`, `D2 p.4`) | 원문 배지 + 출처 |
| `variable` | 사용자가 이번 건에 직접 준 값(주입 슬롯) | — | 주입값 배지 |
| `tbd` | 원문·주입값 모두 없음 → [확인 필요] | `question`(발주처에 물을 문장) | 확인 필요 배지, 질문 리스트에 자동 등재 |
| `standard` | §6 표준 금지 4항목 + §8 검수 기준 전용 | — | 표준 배지 |

원칙:
- `tbd` 항목의 `value`는 비운다. 채워 넣는 순간 추측이다.
- `quote`는 원문 그대로다. 문장 부호·띄어쓰기까지 유지한다. 줄이거나 다듬지 않는다.
- 같은 항목에 원문과 주입값이 둘 다 있으면 원문(`quote`)이 이긴다. 충돌하면 항목을 `tbd`로 바꾸고 질문에 "원문 A와 전달값 B가 다릅니다. 어느 쪽이 맞습니까?"를 적는다.
- 인용 원문의 오탈자·명백한 오류는 고치지 않고 `sourceCorrections`에 별도 기록한다(원문 수정 제안 블록).

## 1. 행사 개요·핵심 메시지
| 항목 | 채우는 규칙 |
|---|---|
| 행사명(국문·영문) | 원문/주입값. 영문 표기가 원문에 없으면 `tbd` |
| 일시 | 원문/주입값. 연도 누락·요일 불일치는 수정 제안 블록으로 |
| 장소 | 원문/주입값 |
| 주최 | 원문/주입값 |
| 행사 주제 문장 | 원문 그대로 |
| 핵심 메시지(슬로건) | **발주처가 쓴 문장 그대로**. 요약·윤색·대안 문구 금지. 없으면 `tbd` |

## 2. 용도·타깃
| 항목 | 채우는 규칙 |
|---|---|
| 1차 사용 지면 | 기본값은 "행사 랜딩페이지 상단(히어로) 이미지". 원문이 다르게 말하면 원문 |
| 전개 지면(옵션) | 원문에 열거된 것만(현장 배너·초청장·SNS 등). 열거 없으면 항목 자체를 넣지 않는다 |
| 보는 사람 | 원문의 타깃 서술 그대로. 없으면 `tbd` |

## 3. 필수 요소
| 항목 | 채우는 규칙 |
|---|---|
| 반드시 들어갈 텍스트 | 행사명·일시·장소 등 원문이 지정한 것. 어떤 정보를 KV에 실을지는 발주처 결정 — 지정이 없으면 `tbd` |
| 반드시 들어갈 로고 | `{{logo_files}}` 목록 |
| 로고·주최 표기 위계 | `{{organizer_hierarchy}}`(주최→주관→후원 순서). 없으면 `tbd` — Claude가 순서를 정하지 않는다 |

## 4. 브랜드 제약
| 항목 | 채우는 규칙 |
|---|---|
| 컬러 | 브랜드 가이드 원문의 코드값. `swatches` 배열에 이름·hex·출처. **값 표시만** — 어떤 색을 어디에 쓸지 제안하지 않는다 |
| 서체 | 원문의 서체명·굵기. 대체 서체 제안 금지 |
| 로고 사용 규정 | 원문 규정(최소 크기·여백·금지 변형) 그대로 |
| 기타 브랜드 규정 | 원문에 있는 것만 |

## 5. 무드·톤 키워드
- 원문(주제·개요·제작요청서·jc-doc-coauthor 메시지 기획 문서의 확정 본문)에 **있는 형용사·방향 표현만**, 인용 부호로 묶고 출처를 단다.
- 원문에 없으면 항목 하나를 `tbd`로 두고 질문: "키비주얼이 전달해야 할 인상·방향을 한두 단어로 알려주세요."
- Claude가 만든 형용사 0개. "~한 느낌", "~한 분위기"류는 원문에 그 표현이 있을 때만.

## 6. 금지 사항
- 원문이 명시한 금지는 `quote`.
- 아래 4개는 `standard` 태그로 항상 넣는다. 발주처·디자이너가 삭제할 수 있도록 `[표준]` 표시를 유지한다.

| # | 표준 금지 항목 |
|---|---|
| S1 | 로고의 비율 왜곡·색 변경·효과(그림자·외곽선 등) 적용 금지 |
| S2 | 저작권·사용권을 확인하지 않은 이미지·서체 사용 금지 |
| S3 | §3 필수 요소 누락 금지 |
| S4 | §7 텍스트 안전영역 침범 금지 |

이 4개 외의 "일반적으로 피하는 것"을 Claude가 추가하지 않는다.

## 7. 규격
| 항목 | 채우는 규칙 |
|---|---|
| 가로×세로 크기 | `{{lp_hero_spec}}` 또는 원문. **숫자 추정 금지** — 없으면 `tbd` |
| 비율 | 위와 같음 |
| 해상도·색 공간 | 원문/주입값. 없으면 `tbd` |
| 텍스트 안전영역 | 원문/주입값. 없으면 `tbd` |
| 납품 파일 형식 | 원문/주입값(예: 원본 파일 + 웹용 이미지). 없으면 `tbd` |
| 반응형 변형(옵션) | 원문이 모바일 규격을 줬을 때만 |

## 8. 납품·일정·검수
| 항목 | 채우는 규칙 |
|---|---|
| 납품물 목록 | `{{deliverables}}` |
| 초안·최종 마감 | `{{deadline}}` |
| 검수 기준 | **사실 확인 항목만**: 행사명·일시·장소 표기 일치 / 로고·주최 위계 준수 / 규격 일치 / 필수 요소 전부 포함 / 금지 항목 위반 없음. 미적 판단 항목("완성도", "세련됨")은 넣지 않는다 |
| 연락 | `{{contact}}` |

## +. 발주처 확인 질문 리스트
- `tbd` 항목의 `question`을 섹션 순서대로 자동 집계한다(스크립트).
- 가이드 말미와 대화 본문 두 곳에 같은 리스트를 낸다. 대화용은 그대로 복사해 발주처에 보낼 수 있는 문장이어야 한다 — 업계 약어 없이 평이한 한국어.
- 질문 수 = `tbd` 항목 수. 하나라도 다르면 검수 실패.

## 언어 규칙
- 전부 한국어. 영문은 고유명사·원문 인용·파일 형식명만.
- 디자이너와 발주처가 같은 문서를 읽는다. 업계 약어(KV, LP, CI, BI, RGB/CMYK 단독 표기 등)는 첫 등장에 풀어 쓴다: "키비주얼(KV)", "랜딩페이지", "웹용 색 공간(RGB)".
