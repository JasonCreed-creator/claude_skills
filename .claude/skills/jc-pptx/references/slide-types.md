# Slide Types — 16종 타입 지오메트리·레시피 정본

> 그리드 상수·컴포넌트 함수는 `scripts/deck_kit.py`가 구현체. 본 문서는 각 타입의 설계 의도와 슬롯 정의.
> 실측 출처: 레퍼런스 데크 XML 지오메트리 (2026-07 분석)

## 공통 그리드 (13.33 × 7.5 in)

| 요소 | 위치 | 스펙 |
|---|---|---|
| 좌우 마진 | x=0.62 | 콘텐츠 폭 12.09in |
| 아이브로우 | y=0.50, h=0.32 | 11.5pt Bold accent, 자간 확대, `NN · SECTION NAME` |
| 헤드라인 | y=0.90, h=1.30 | 31~32pt Bold, text-primary + accent 런 믹스 |
| 서브라인 | y=2.05, h=0.60 | 13~14.5pt Regular, text-body |
| 콘텐츠존 | y=2.50 ~ 6.30 | 타입별 상이 |
| 테이크어웨이 바 | y=6.34, h=0.62 | 14~16pt Bold 중앙, 밀도형에서 필수 |
| 푸터 | y=7.06, h=0.30 | 8pt muted — 좌 문서명 / 우 섹션명 (또는 페이지번호 하단 중앙) |

밀도 모드: SIMPLE(도형~16개/장, ~300자) / CUSTOM(30~45개/장, 450~650자, 이미지 3~4+)

## 타입 카탈로그

### T01 커버
슬롯: 문서명 / 부제 / 발행 주체(주입 변수) / 일자. 풀블리드 비주얼 or 텍스처 배경, 아이브로우 자리에 문서 성격 라벨(예: SESSION PROPOSAL). 부제는 영문 이탤릭 세리프 허용.

### T02 목차/인덱스
슬롯: 챕터 번호·명 목록(+페이지). CUSTOM 모드는 각 장 시작마다 재등장 — 현재 장만 액센트 하이라이트, 나머지 muted.

### T03 섹션 디바이더
슬롯: 챕터 번호 / 챕터명 / (선택) 대표 이미지. 고스트 넘버(200pt+, 저대비) 좌측, 섹션명 하단. 우측 풀블리드 이미지 or 배경 텍스처.

### T04 개요 스펙
슬롯: 항목-값 쌍 4~8개 (일시·장소·대상·규모·구성 등). 2단 분할(좌 6.5 / 우 4.8in): 좌 라벨-값 리스트(라벨 accent Bold, 값 text-primary), 우 보조 박스(시간표·부가정보).

### T05 KPI 하이라이트
슬롯: 핵심 수치 1~4개 + 단위 + 상하 캡션. 숫자 40~60pt accent Bold. 좌 대표 KPI 카드(bg-card) / 우 보조 라벨-값 3행. 증감은 `+N% UP` 표기. 다크: 골드 숫자+카드 박스 / 라이트: 솔리드 컬러 블록+흰 숫자.

### T06 비교 프레임
슬롯: 좌 항목(기존/BEFORE/타사) / 우 항목(제안/AFTER/우리) / 각 항목별 리스트 / 하단 태그(한계 vs 효과). 좌우 아웃라인 박스 + 중앙 화살표. 우측(제안측)에 액센트 테두리로 우위 표현.

### T07 프로세스/스텝
슬롯: 단계 2~6개 (번호·제목·설명). 두 변형 — (a) STEP 카드 + 화살표 연결, (b) 진행 pill 네비(BEFORE/DURING/AFTER 등 구간 반복 등장, 현재 구간만 액센트 활성). 원문자 ①②③ 허용.

### T08 넘버링 카드
슬롯: 병렬 항목 3~6개 (번호 01~ / 제목 / 설명 2줄 이내). 열 그리드(6열 시 폭 1.67in·갭 0.33in). **위계 차등 필수** — 핵심 1개는 크기 또는 액센트로 구분.

### T09 등급/가격 테이블
슬롯: 티어명 3개 표준 / 행 항목 / 셀 값. 헤더행 액센트 Bold, 미제공 항목 "—", 행 구분 얇은 line색. 하단 주석 8pt muted.

### T10 데이터 차트
슬롯: 시리즈 데이터 + 헤드라인 주장(차트가 근거). 단색조(액센트 계열 농도 변주), 값 라벨 직접 표기, 축·격자 최소화. 좌 KPI 요약 카드 + 우 차트 병치 권장. 24pt 미만 표 대신 차트 1 + 핵심 수치 1.

### T11 증빙 콜라주
슬롯: 실적 사진 6~9장 + 캡션 / 레퍼런스 목록. 그리드 정렬, 셀 간격 균일. 다크 테마는 사진 어둡게 보정해 융화. 사진 미제공 시 플레이스홀더 박스 + 이미지 브리프 텍스트.

### T12 인용/후기
슬롯: 인용문 / 발화자(주입 변수). 변형 (a) 대형 따옴표 + 중앙 강조 2줄(핵심어 액센트), (b) 말풍선 후기 카드 3~6개 + 사진(현장감).

### T13 조직/타임라인
슬롯: 노드(조직·마일스톤)·기간·설명. 도트+라인 연결(월 단위 타임라인), 지그재그 연혁, 조직도 박스 트리. 라벨 10~12pt.

### T14 공간/도해
슬롯: 평면도·조닝 구획·동선. 구획 솔리드/아웃라인 + 동선 화살표 + 범례. 실측 이미지 있으면 우측 병치.

### T15 밀도형 종합 (CUSTOM 전용)
슬롯: 복합 콘텐츠(텍스트+도해+사진 혼성). 하단 테이크어웨이 바 **필수**. 섹션 내 구획은 소제목 바(accent 세로 바 + Bold)로 분리. 영문 고스트 워드(한글 라벨 뒤 저대비 영문) 허용.

### T16 클로징 CTA
슬롯: 마무리 주장(긴장 클로징 패턴) / 행동 요청(질문형) / 잔여 옵션(좌석·등급 등 희소성). "감사합니다" 단독 금지. 발행 주체 로고(주입)를 하단.

## 리멤버 DS 슬라이드 템플릿 ↔ 타입 매핑 (v2.0)

Claude Design 프로젝트 "리멤버 제안서 디자인 시스템"(`remember-proposal-ds/slides/01~10`)의 1920×1080 템플릿과 본 스킬 타입의 대응. HTML 템플릿이 시각 정본, deck_kit이 pt 구현체.

| DS 템플릿 | 타입 | deck_kit 메서드 | 비고 |
|---|---|---|---|
| 01 표지 (다크) | T01 | `cover(dark=True)` | 우측 오브제 620px + 좌측 페이드, 상하 60% 화이트 룰, 좌상단 발주처 로고 슬롯 |
| 02 목차 | T02 | `contents()` | 모노 번호 orange + 항목, 옅은 언더라인 |
| 03 섹션 (다크) | T03 | `section_divider(style="dark")` | 고스트 넘버 + 섹션명. 그라디언트 변형은 `style="gradient"` |
| 04 요약 카드 | T08 | `numbered_cards()` | 3열 카드, 핵심 1개 강조(상단 그라디언트 룰) |
| 05 본문 + 표 | T04 / T09 | `table()` + 좌 텍스트 | 좌 텍스트 520px + 우 표. 가로선만 |

| 07 KPI | T05 | `kpi(solid=True)` ×1 + `kpi()` ×n | 솔리드(그라디언트)는 슬라이드당 1개 |
| 08 인력 | T13(조직) | `profile_capsules()` | 4열 프로필, 차콜 캡슐 또는 라이트 카드 |
