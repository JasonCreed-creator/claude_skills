# 체이닝 가이드 (타 스킬 → jc-redteam)

> jc-redteam은 워크플로우 **최하류 품질 게이트**다. 상류 스킬의 산출물을 입력으로 받아 최종 검증한다. 입력은 **명시적 JSON이든 단순 파일/텍스트든 모두 수용**한다(엄격한 스키마 강제 없음). 단, 산출물 유형마다 **집중 공격 포인트**가 다르므로 아래 매핑을 따른다.

> **봉투 정본**: 공통 `ChainPayload/v1` 봉투 구조·전체 워크플로우(본 스킬의 최하류 게이트 위치 포함)·표준 규약은 [jc-design-system/references/chaining-protocol.md](../../jc-design-system/references/chaining-protocol.md §5-4) 참조. 단, **본 스킬은 봉투 유무와 무관하게 모든 산출물·텍스트를 수용**하므로 봉투 스키마를 강제하지 않는다. 본 문서는 jc-redteam **고유의 산출물 유형별 집중 검증 포인트**만 정의한다.

## 입력 수용 원칙

1. 상류 스킬이 산출한 **최종 결과물**(PPTX/XLSX/DOCX/HTML/JSON 또는 결론 텍스트)을 그대로 받는다.
2. 검증 대상의 **핵심 주장(결론)** 을 먼저 한 문장으로 정의한 뒤 검증을 시작한다.
3. 산출물 유형 → 권장 모드(Quick/Deep)는 아래 표 기준. 모호하면 사용자에게 1회 확인.
4. 검증은 산출물을 **재생성하지 않는다.** 결함을 찾아 지적·교정·대안 제시까지만 한다(생성은 원 스킬의 몫).

## 스킬별 집중 검증 포인트

### mice-proposal (제안서 PPTX)
- **권장 모드**: Deep Audit
- **집중 공격 포인트**:
  - 기획 논리의 비약 — "콘셉트 → 효과" 사이 인과가 성립하는가
  - 평가 기준 대응 충실도 — RFP 평가 항목별로 빠짐없이 답했는가 (누락 관점)
  - 운영 리스크·예비비·계약 대응 누락 (화려한 기획 뒤의 빈 곳)
  - 숫자 일관성 — 본문 인원/일정/예산이 견적·일정표와 충돌하지 않는가
  - 과장 표현 — 근거 없는 "최고/유일/보장" 류

### mice-rfp-analyzer (GO/NO-GO 판정)
- **권장 모드**: Deep 또는 Quick (판정 분량에 따라)
- **집중 공격 포인트**:
  - GO 판정의 **숨은 가정** — 승률 추정의 근거는? 낙관편향은?
  - 독소 조항 평가절하 — 리스크를 과소평가하지 않았는가
  - 경쟁사·승률 추정의 근거 — 추정을 사실처럼 쓰지 않았는가 (기저율 무시)
  - NO-GO 판정이라면 — 매몰비용·현상유지 편향으로 기회를 버리는 것은 아닌가

### mice-estimate (견적 XLSX)
- **권장 모드**: Deep Audit
- **집중 공격 포인트** (숫자 검증 최우선):
  - 자릿수·단위·합계 검산 (`proofreading-rules.md` §5 전면 적용)
  - 기획료율·VAT·할인·절사 규칙이 실제 숫자에 일관 적용됐는가
  - 항목 누락 — 필수 비용 항목이 빠지지 않았는가
  - 단가 적정성 — 시장가 대비 과소/과대 (확인 불가 시 "검토 권고")
  - 게런티/인원 기준이 제안서·RFP와 일치하는가 (내부 모순)

### mice-sponsor-deck (스폰서 데크)
- **권장 모드**: Deep Audit
- **집중 공격 포인트**:
  - ROI 주장의 근거 — 노출·리드·전환 수치가 추정인가 보장인가, 프레이밍 오용은
  - Tier 혜택 매트릭스의 내부 정합성 — 상위 Tier가 하위를 모두 포함하는가, 가격-혜택 역전 없는가
  - 과장된 도달/효과 — 검증 가능한가

### mice-dashboard (KPI 대시보드)
- **권장 모드**: Quick 또는 Deep
- **집중 공격 포인트**:
  - KPI 해석의 인과 착각 — 상관을 성과 요인으로 단정하지 않았는가
  - 사후확신 편향 — "예상대로"라는 결과 서술이 사전 예측과 다른가
  - 데이터 → 결론 비약 — 표시된 수치가 결론을 실제로 뒷받침하는가
  - 누락된 부정 지표 — 불리한 KPI를 숨기지 않았는가 (확증편향)

### mice-meeting-minutes (회의록)
- **권장 모드**: Quick Strike
- **집중 공격 포인트**:
  - Action Item의 책임자·기한 누락
  - 결정사항이 실제 발언·합의와 일치하는가
  - 미결 사항이 결정된 것처럼 기록되지 않았는가

## 범용 입력 (스킬 외 결론·문서)

상류 스킬을 거치지 않은 일반 결론·판단·문서도 동일하게 받는다.
- 짧은 결론·판단 텍스트 → **Quick Strike**
- 업로드된 장문 문서·전략 자료 → **Deep Audit**
- "방금 네 답변 검증해봐" → **Quick Strike** + 역할 분리(외부 감사관) 엄격 적용

→ 모드 판정 후 `verification-checklist.md`의 3축 순서로 검증을 실행한다.
