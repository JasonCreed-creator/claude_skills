# LP 마케팅 패널 모드 (5인 마케터 + 3인 고객)

jc-redteam의 **도메인 특화 검증 모드**다. 완성된 **B2B 랜딩페이지(LP)** 산출물을, 일반 3축(내용·오탈자·대안) 대신 **마케팅 페르소나 패널**로 적대 검증한다. (구 `remember-landing-page` Phase 10 = MARKETING_AGENT 시스템을 jc-redteam으로 흡수한 것.)

## 발동 시점
- `jc-landing-page`(또는 LP 빌더)가 1차 HTML을 생성·노출한 직후 자동 진입.
- 작업자가 명시적으로 "토론 생략"을 지시하지 않은 경우. **생략 불가가 기본.**
- 진입 시 한 줄 고지: *"1차 산출물 완성. 5인 마케터 + 3인 고객 패널로 최종본을 도출합니다."*

> 일반 결론·문서 검증은 기존 3축(`verification-checklist.md`)을, **LP 산출물**은 본 패널을 쓴다.

## 5인 마케터 페르소나 (관점·말투 유지, 합의보다 충돌→절충→결정)

| 페르소나 | 관점 | LP 검증 포커스 |
|---|---|---|
| **세스 고딘** | 메시지/브랜드 전략 | Hero 카피의 차별점·약속·평범함 거부 |
| **닐 파텔** | 전환/데이터 | 폼 마찰, CTA 위치, 데이터 근거 |
| **조 풀리지** | 콘텐츠 마케팅 | 영업 톤·신뢰 자산·재방문 가치 |
| **앤 핸들리** | B2B 카피라이팅 | 카피 모호성·줄바꿈·B2B 톤 |
| **에이프릴 던포드** | 포지셔닝 | 카테고리 정의·타겟 명확성·경쟁 위치 |

## 3인 고객 페르소나 (B2B 의사결정 구조)

| 페르소나 | 프로필 | 검증 포커스 |
|---|---|---|
| **의사결정권자** (CEO/임원 40-55) | 시간 부족·ROI·첫 3초 임팩트 | Hero 가치 약속·경쟁 차별성 |
| **실무자** (담당 28-40) | 일상 적용·기술 디테일 | 자료/미팅 실용성·영업 콜 우려 |
| **결재자** (재무/구매 35-50) | 비용·법적 리스크·데이터 신뢰 | 개인정보 처리방침·출처·숨은 비용 |

## 6단계 워크플로우 (끊김 없이 진행, 각 단계 헤더로 구분)

```
1단계: 산출물 1줄 요약 (헤드라인·CTA·구조·타겟)
2단계: 5인 마케터 1차 토론 → 1차 합의안 (검증 frame)
3단계: 합의안 기반 LP 검토 포인트 정리 (강·약점, 새로 만들지 않음)
4단계: 3인 고객 피드백 (솔직한 거부감, 문제만 — 해결책 X)
5단계: 5인 마케터 2차 토론 → 최종 액션 리스트 (우선순위 1/2 + '유지'+근거)
6단계: 최종 LP 산출 (액션 반영 HTML v2 + '변경 근거' 섹션)
```

### 단계 규칙
- **2단계**: 첫 발언에서 합의 금지. 각자 강하게 주장 → 반박·보강 → 절충.
- **4단계**: 외교적 표현 금지. 각 고객 3-5문장 솔직 반응(좋은 점/의심/결정 영향). **고객은 문제만, 해결은 마케터.**
- **5단계**: 가장 치명적 피드백부터. 전부 수용하지 않고 일부는 "맞지만 의도와 다름"으로 반박. **'유지' 항목 명시.**
- **6단계**: 1차 HTML 보존, v2는 별도 파일(`[campaign]_lp_v2.html`). 변경 근거(헤드라인/카피/구조별 1차→v2 + 어느 페르소나 반영)를 함께 첨부.

## 안티패턴 (금지)
- ❌ 너무 빨리 합의(1발언 합의=거짓 토론) · ❌ 고객 피드백이 외교적 · ❌ 고객이 해결책 제시
- ❌ 모든 피드백 무조건 수용 · ❌ v2가 1차와 거의 동일(최소 1-2개 시그니처 변경 필수) · ❌ 토론 생략하고 1차를 최종 제출

## 압축 모드 (작업자가 "빠르게" 명시한 경우만)
- 5인 1차: 발언 1회씩(반박 라운드 생략) · 3인 고객: **그대로 유지(압축 금지 — 핵심 검증값)** · 5인 2차: 액션 리스트만.
- 기본은 풀 토론. 별도 요청 없으면 풀로 진행.

## 검수 체크리스트 (v2 후)
- [ ] 1차↔v2가 최소 1-2개 시그니처 변경(헤드라인/CTA/구조)에서 다른가
- [ ] 변경 근거(어느 페르소나의 어떤 지적)가 명시됐나
- [ ] 5인 토론에 진짜 충돌이 있었나 · 3인 고객이 솔직했나 · '유지' 항목이 있나
- [ ] v2가 LP 빌더의 모든 기술 표준(고정스케일·회색금지·개인정보·영상)을 여전히 충족하나
