## 1. 한글 맞춤법 (고빈도 오류)

비즈니스 문서에서 자주 틀리는 것만 추린다.

| 구분 | 규칙 | 예 |
|------|------|----|
| 되/돼 | '돼' = '되어'로 치환 가능할 때만 | 안 돼요(O, 안 되어요) / 되요(X) |
| 안/않 | '안' = 부사(안 한다), '않' = '아니하'(하지 않다) | 하지 않다(O) / 하지 안다(X) |
| -로서/-로써 | 로서=자격·지위, 로써=수단·도구 | 전략가로서(자격) / 데이터로써(수단) |
| 율/률 | 모음·ㄴ받침 뒤 '율', 그 외 '률' | 비율·전환율·참가율 / 수주율·성공률·확률 |
| -므로/-(으)ㅁ으로(써) | 므로=이유, ㅁ으로=수단 | 늦었으므로(이유) / 분석함으로써(수단) |
| 데/대 | 데=경험·회상, 대=전언·간접 | 좋던데(경험) / 좋다대(전언) |
| 든지/던지 | 든지=선택, 던지=과거 | 하든지 말든지 / 춥던지 |

## 2. 띄어쓰기 (고수익 점검)

- **의존명사 띄움**: 수, 것, 등, 및, 바, 데(곳), 지(시간) → 앞말과 띄움. "할 수 있다"(O), "할수있다"(X).
- **단위명사 띄움**: 숫자와 단위는 띄움이 원칙. "200 명", "5 억"(원칙) — 단, 아라비아숫자+단위는 붙여도 허용("200명").
- **고유명사 + 일반명사**: 행사명·브랜드명 표기를 문서 내에서 통일.
- **보조용언**: "해 보다 / 해보다" 둘 다 허용 — 문서 내 통일이 핵심.
- ⚠️ 미세 띄어쓰기는 표준이 흔들리는 영역. **명백한 것만 지적**하고 나머지는 "통일 권고".

## 3. 용어 일관성

- 같은 개념을 다른 단어로 섞어 쓰는지 점검 → **표기를 하나로 통일** 권고.
- 흔한 혼용: 참가자/참석자/게스트, 발주처/클라이언트/고객사, 견적/견적서/산출내역, 행사/이벤트, 부스/전시대.
- 영문·국문 혼용: PCO/피씨오, RFP/제안요청서, KPI/핵심성과지표 → 문서 내 1개로.
- 약어는 **최초 1회 풀어쓰기 + 약어 병기** 후 약어 사용.

## 4. 비문 · 어색한 문장

| 유형 | 탐지 | 예 |
|------|------|----|
| 주술 불일치 | 주어와 서술어가 호응 안 함 | "본 제안의 목표는 ~을 진행합니다"(목표는 ~이다) |
| 중복 표현 | 같은 뜻 겹침 | "역전 앞", "미리 예약", "약 5억 원 정도" |
| 번역투 | ~을 통해, ~에 대하여, ~에 의해 남발 | "분석을 통해 도출" → "분석해 도출" |
| 만연체 | 한 문장이 3줄 이상 | 끊어 쓰기 권고 |
| 피동 남용 | ~되어지다(이중피동) | "진행되어집니다" → "진행됩니다" |

## 5. 숫자 · 단위 · 계산 검증 (최우선)

> **MICE에서 숫자 한 자리 오류 = 결론 붕괴.** 숫자 오류는 오탈자가 아니라 사실 오류급(🔴 Critical)으로 취급한다.

- **자릿수 검산**: 5,000,000 vs 50,000,000 — 콤마 위치·0 개수 확인. 한 자리 차이는 10배다.
- **단위 통일**: 원/만원/백만원/억 혼용 탐지. "5억 = 500,000,000원 = 50,000만원"이 문서 내에서 일관되는가?
- **합계 검산**: 항목 소계의 합 = 표기된 총계인가? 직접 더해본다.
- **비율·퍼센트**:
  - 부분/전체 = 표기된 퍼센트와 일치하는가?
  - 구성비 합 = 100%인가? (반올림 오차 외)
  - "증가율 200%"와 "3배"가 혼용/오용되지 않았는가?
- **인당 단가 검산**: 인당 단가 × 인원 = 표기 금액인가?
- **세금·할인 규칙**: VAT 포함/별도가 명시됐는가? VAT 포함액 = 공급가 × 1.1인가? 명시된 할인율·기획료율(예: 운영비 × 25%)·절사 규칙이 실제 숫자에 일관 적용됐는가?
- **단위 누락**: 금액에 "원/만원" 단위가 빠지지 않았는가? "예산 500" 같은 모호 표기 탐지.

## 6. 날짜 · 고유명사

- **요일-날짜 일치**: 본문 날짜와 요일이 실제로 맞는가? (불일치 빈발 — 캘린더로 확인 권고)
- **일정 산수**: 시작~종료 일수, 준비기간(D-day)이 본문 서술과 일치하는가?
- **기간 모순**: "3개월 프로젝트"인데 일정표는 4개월 등.
- **고유명사 표기**: 회사명·인명·행사명·지명의 철자·표기가 정확하고 문서 내 통일됐는가?

## 7. 교정 표기 규칙

- **확신 있는 오류**: "오류: A → B로 수정" (단정).
- **확신 없는 사항**: "검토 권고: A가 의도한 표현이 맞는지 확인" (비단정).
- **숫자 의심**: "검산 필요: X + Y = Z여야 하나 표기는 W". 가능하면 직접 계산해 제시.
- Minor 교정은 개별 나열하지 않고 **묶음 표/리스트**로 처리한다(신호 대비 잡음 관리).
