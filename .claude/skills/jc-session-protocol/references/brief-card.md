# 브리프 카드 (옵트인) — 기획안 1회 확인용

기본은 즉시 실행이다. 이 카드는 ① 사용자가 "브리프", "정리하고 시작", "뭘 만들지부터 정리", "작업 계획 잡고"라고 말했거나 ② 고밀도 산출물(덱·장문 문서·대시보드·여러 파일 빌드)의 **기획안 1회 확인**을 할 때만 쓴다. 이 카드가 곧 그 1회 확인이다 — 승인 절차를 따로 늘리지 않는다. (2026-09-21 구 프롬프트 빌더 스킬 요지를 흡수, 2026-10-05 범위 게이트 삭제)

```
📋 기획안
목표      : <의도 1문장 재진술 — 원문에 없는 목적어·수식은 넣지 않는다>
산출물    : <형태·분량·포맷·저장 위치> (스킬: <skill> / 독자: <대상>)
구성      : <섹션·장표 흐름 3~7줄>
핵심 메시지: <1~3줄>
맥락 반영  : ① <핵심> (출처) ② … ③ …   ※ 최대 3. 소스의 금지·조건 조항은 상한 무관하게 '제약'으로
성공 기준  : 1) … 2) … (검증 가능한 문장. "좋게"·"잘" 금지)
제약      : <운영 규칙·형식·톤 자동 반영분 + 소스 내 금지 조항>
가정(기본값): A1) … A2) …   ※ 원문에 없던 추론 채움 전부 — 승인 시 확정
──────────────────────────────
→ 승인 / 필드 수정 / 그대로 실행
```

- 맥락 소스 우선순위: Code = CLAUDE.md → PROGRESS.md → 관련 파일 실측 / Cowork = 폴더 인덱스 → 구조 → 최근 파일.
- "그대로 실행"(= "바로 해줘", "그냥 진행해")이면 카드·가정을 폐기하고 원문만으로 즉시 실행한다.
- 필드 수정 요청은 해당 필드만 교체해 재제시한다. 전체 재작성 금지.
- 승인 뒤에는 빌드·검수까지 다시 묻지 않는다. 진행은 체크리스트로 보인다.
