# jc-slack-relay — Slack 중계 (Code → 파일 → Cowork)

회사 정책으로 claude.ai 커넥터가 막혀 Slack은 Claude Code(PC)의 플러그인 Slack 도구로만 읽힌다. Cowork·채팅에는 Slack 도구가 없으므로 Code가 읽어 파일로 남기고 Cowork는 그 파일을 읽는다. 정책 우회(로컬 중계 서버 등)는 하지 않는다.

## 0. 지금 어느 쪽인지 판단

- 도구 목록에 `mcp__plugin_*_slack__` 계열 Slack 도구가 있으면 → **A. 내보내기 모드**(Claude Code)
- 없으면 → **B. 읽기 모드**(Cowork·채팅). Slack에 직접 접속하려 하지 않는다

## 1. 저장 위치 (경로 상수 정본 — 다른 스킬은 이 절을 가리킨다)

- 폴더: `C:\.Claude\Slack-내보내기\` (Cowork 작업 시 이 폴더를 작업 폴더로 허용해 둔다)
- 파일 이름: `YYYY-MM-DD_HHMM_<채널 또는 주제>.md` (한국 시간 기준)
- 목록 파일: 같은 폴더의 `_목록.md`에 한 줄씩 추가 (파일명 · 범위 · 수집 시각)

## 2. A. 내보내기 모드 (Claude Code)

1. 범위를 정한다: 채널·스레드·검색어·기간. 지정이 없으면 '최근 7일, 요청에 나온 채널'로 하고 그렇게 골랐다고 한 줄 밝힌다.
2. 수집: `slack_read_channel`·`slack_read_thread`·`slack_search_public_and_private` 등 읽기 도구만 쓴다. 메시지 발송·캔버스 수정은 하지 않는다.
3. 아래 형식으로 파일을 쓴다. 기본은 원문을 줄이지 않고 그대로 쓰는 것뿐이다(요약은 선택 — 아래).
4. `_목록.md`에 한 줄 추가.
5. 답장: 저장 경로와 "Cowork에서 '슬랙 파일 읽어줘'라고 하시면 됩니다" 한 줄.

### 파일 형식

```markdown
# Slack 내보내기: <채널/주제>
- 수집 시각: 2026-10-05 20:10 (KST)
- 범위: #채널명 / 2026-09-28 ~ 2026-10-05 / 검색어: (있으면)
- 메시지 수: N건 (스레드 답글 포함)

## 원문
### 2026-10-02 14:03 · 작성자
본문 그대로
- 링크: <permalink>
  - ↳ 14:10 · 답글 작성자: 답글 본문
```

- (선택) 사용자가 요약을 원할 때만 `## 원문` 위에 `## 요약` 절을 둔다. 형식은 `mice-slack-ops/references/briefs.md` §3(스레드별 주제·결론/결정·내 액션·상대 액션·미결) 그대로 — 이 스킬은 별도 요약 형식을 두지 않는다.

## 3. B. 읽기 모드 (Cowork·채팅)

1. `C:\.Claude\Slack-내보내기\_목록.md`를 먼저 읽고 요청에 맞는 최신 파일을 고른다. 폴더에 접근할 수 없으면 "Cowork 작업 폴더에 C:\.Claude\Slack-내보내기 폴더를 추가해 주세요"라고 안내한다.
2. 파일 머리의 수집 시각을 답에 함께 적는다(예: "10/5 20:10 기준 내용입니다"). 그 이후 내용은 모른다고 밝힌다.
3. 더 최신 내용이나 다른 채널이 필요하면 Claude Code에 붙여넣을 지시문을 본문에 그대로 준다:
   > 슬랙 중계: #채널명 최근 N일(또는 검색어 …) 내보내 줘

## 4. 주의

- 내보낸 파일에는 사내 대화가 원문으로 남는다. 이 폴더 밖(개인 클라우드, 외부 공유 링크)으로 옮기지 않는다.
- 오래된 파일 정리는 기획자님 몫이다. Claude는 삭제하지 않는다.
- Slack 운영 규칙(채널 프로토콜·브리프 형식)은 `mice-slack-ops`를 따른다.
