# 전략 프레임워크 카탈로그 (6대)

`jc-strategy-canvas` SKILL §3의 상세 정본. 각 프레임워크는 **언제 / 구조(칸) / 핵심 질문 / MICE 렌즈 / 흔한 함정**으로 정의한다. 출처 패턴: `maigentic/stratarts`(MIT) — *구조·질문 세트만* 흡수, MICE 맥락으로 재구성.

> 공통 채움 규약(SKILL §4 ③): 각 칸 항목에 근거 강도 표식 `[검증]`(출처 있음) / `[가설]`(미검증) / `[추정]`. 추정 숫자는 지어내지 않는다.

## F1. Business Model Canvas (BMC) — 9블록

**언제**: 신규 자체행사·유료 컨퍼런스·신사업 라인의 *수익 구조*를 설계/점검할 때.

**구조 (9칸, 채움 순서 권장 ②⑤④부터)**

| 블록 | 질문 | MICE 렌즈 |
|------|------|----------|
| ① 고객 세그먼트(CS) | 누구를 위해? | 발주처 / 참가자(B2B·B2C) / 스폰서 — 3면 시장일 때 분리 |
| ② 가치 제안(VP) | 어떤 문제를 푸나 | 행사가 주는 핵심 가치(네트워킹·리드·브랜딩·지식) |
| ③ 채널(CH) | 어떻게 전달·도달하나 | 모객 채널·등록 플랫폼·영업 경로 |
| ④ 고객 관계(CR) | 어떻게 획득·유지하나 | 재참가·시리즈화·커뮤니티 |
| ⑤ 수익원(R$) | 무엇으로 버나 | 참가비·부스비·스폰서십·콘텐츠·정부지원 |
| ⑥ 핵심 자원(KR) | 무엇이 필요하나 | 베뉴·콘텐츠 IP·연사 풀·운영 인력 |
| ⑦ 핵심 활동(KA) | 무엇을 하나 | 기획·모객·운영·정산 |
| ⑧ 핵심 파트너(KP) | 누구와 하나 | 베뉴·협력사·미디어·후원기관 |
| ⑨ 비용 구조(C$) | 어디에 돈이 드나 | 고정(베뉴·인력) vs 변동(참가자 비례) |

**핵심 질문**: VP↔CS가 맞물리는가? R$이 C$을 구조적으로 넘는가(단발 흑자가 아니라 모델로)? 3면 시장이면 누가 보조금을 내고 누가 혜택을 보나?

**흔한 함정**: VP를 "좋은 행사"로 뭉뚱그림(고객별로 다른 job을 → F4로 분해). 스폰서십을 잔여 수익으로 취급(스폰서는 별도 CS·VP를 가진 고객).

## F2. Porter's Five Forces — 시장 매력도

**언제**: 신규 전시 분야·신규 지역·신규 포맷 *진입 매력도*를 판단할 때.

**구조 (5개 힘 — 센 힘부터)**

| 힘 | 높을수록 | MICE 렌즈 |
|----|---------|----------|
| 신규 진입 위협 | 매력↓ | 진입장벽(레퍼런스·발주처 관계·베뉴 선점)이 낮으면 위협↑ |
| 공급자 교섭력 | 매력↓ | 베뉴·핵심 연사·독점 협력사의 힘 |
| 구매자 교섭력 | 매력↓ | 발주처·대형 스폰서의 가격 압박 |
| 대체재 위협 | 매력↓ | 웨비나·자체 행사·디지털 커뮤니티 |
| 기존 경쟁 강도 | 매력↓ | 동일 분야 기획사·앵커 전시 난립도 |

**핵심 질문**: 다섯 중 *가장 센 힘*은? 그 힘을 우리가 길들일/회피할 수 있나? 시간이 지나면 각 힘은 강해지나 약해지나(동태적)?

**흔한 함정**: 5힘을 평면 점수로 합산(가장 센 단일 힘이 게임을 지배 — 합산이 아니라 병목으로 본다). 매력 없는 시장이라도 *특정 세그먼트*는 매력적일 수 있음(F6 SOM과 교차).

## F3. SWOT / TOWS — 역량 × 환경 → 전략

**언제**: 신사업 GO/NO-GO나 수주 전략을 *옵션화*할 때. SWOT는 나열, **TOWS는 전략 도출**까지.

**구조**

```
              기회(O)              위협(T)
강점(S)   SO: 공격(강점으로 기회)   ST: 방어(강점으로 위협 차단)
약점(W)   WO: 보완(기회로 약점 메움)  WT: 회피/철수(약점×위협 최소화)
```

**핵심 질문**: 각 칸은 *증거*가 있나(`[검증]`/`[가설]`)? 가장 큰 레버는 어느 사분면(보통 SO 1~2개에 집중)? WT가 크면 진입 자체를 재고.

**흔한 함정**: SWOT를 형용사 목록으로 끝냄(→ TOWS 사분면으로 *전략 문장*까지 가야 산출물). S/W를 환경(O/T)과 혼동(S/W=내부 통제가능, O/T=외부).

## F4. Jobs-to-be-Done (JTBD) — 고객 과업

**언제**: 행사 가치제안·참가자 경험·스폰서 패키지의 *고객 동인*을 정의할 때.

**구조 (고객별 1세트, 3면이면 3세트)**

- **기능적 job**: 고객이 *완수하려는 일* ("우리 제품을 살 의사결정자 30명을 만난다").
- **감정적/사회적 job**: 어떻게 *느끼고/보이고* 싶은가("업계 리더로 인식").
- **Pain**: 현재 해결책의 고통(낮은 리드 품질·ROI 불투명).
- **Gain**: 기대 이득(검증된 리드·브랜드 노출·콘텐츠).
- **현재 대안**: 지금은 어떻게 해결하나(자체 세미나·광고·웨비나) → F5 경쟁 대안과 연결.

**핵심 질문**: 발주처·참가자·스폰서의 job은 *다르다* — 섞지 않는다. 어떤 미충족 job이 가장 큰가? 그 job에 우리가 남보다 잘 답하나(→F5)?

**흔한 함정**: 우리 솔루션(행사)부터 시작(job부터 시작해야 새 가치가 보임). "참가자를 늘린다"를 job으로 착각(그건 우리 목표, 고객 job은 "양질의 만남").

## F5. Positioning (April Dunford) — 차별화

**언제**: 행사·기획사를 경쟁 대안 대비 *어떻게 다르게* 인식시킬지 정의할 때.

**구조 (5스텝)**

1. **경쟁 대안**: 우리가 없으면 고객은 무엇을 쓰나(F4 현재 대안과 연결).
2. **고유 속성**: 대안에 없는 우리만의 특징(데이터·네트워크·운영 IP).
3. **가치**: 그 속성이 주는 *고객 가치*(속성 ≠ 가치 — "왜 좋은가"까지).
4. **타깃 세그먼트**: 그 가치를 *가장* 중시하는 고객(F1 CS의 부분집합).
5. **시장 카테고리**: 우리를 어떤 카테고리로 인식시킬까(기존 카테고리 vs 새 카테고리 정의).

**핵심 질문**: 우리 고유 속성이 *실제로* 대안에 없나(`[검증]`)? 그 가치를 가장 아끼는 세그먼트는? 카테고리를 새로 만들 역량(시장 교육 비용)이 있나, 기존 카테고리에서 이길까?

**흔한 함정**: 모두에게 포지셔닝(타깃을 좁히지 않으면 메시지가 무뎌짐). 속성을 가치로 착각.

## F6. TAM / SAM / SOM + 시장기회 — 규모화

**언제**: 신사업·신규 행사의 *기회 크기*와 *현실적 우리 몫*을 추산할 때.

**구조**

| 층 | 정의 | MICE 렌즈 | 산정법 |
|----|------|----------|--------|
| **TAM** | 전체 시장 | 해당 분야 전체 MICE 지출 | 톱다운(산업통계) |
| **SAM** | 도달 가능 시장 | 우리 지역·포맷·세그먼트로 한정 | TAM × 세그먼트 비율 |
| **SOM** | 획득 가능 시장 | 1~3년 현실적 점유 | 보텀업(베뉴 수용·영업 capacity×전환율) |

**핵심 질문**: TAM은 톱다운, SOM은 *보텀업*으로 — 둘이 만나는지 교차 검증. 숫자마다 출처·가정 명시(`[검증]`/`[추정]`). SOM이 손익분기를 넘나?

**흔한 함정**: TAM만 크게 부풀림(투자 설득용 허수 — 의사결정은 SOM). 보텀업 없이 "시장의 X%" 추정(근거 없는 비율). 데이터가 없으면 → `mice-market-intel`로 검증 위임.

## 조합 레시피 (SKILL §3 권장)

| 전략 질문 | 프레임워크 순서 |
|----------|----------------|
| 신사업 GO/NO-GO | F6(규모) → F2(매력도) → F3(역량 매칭/옵션) → F1(수익구조) |
| 행사 차별화·재포지셔닝 | F4(고객 과업) → F5(포지셔닝) → F3(실행 옵션) |
| 신규 BM 설계 | F1(캔버스) → F4(VP 검증) → F2(외부 압력) |
| 시장 진입 우선순위 | F6(SOM 비교) → F2(시장별 매력도) → F5(진입 포지션) |

> 조합은 *결정에 필요한 최소*로. 6개를 다 채우면 대개 과적합. 교차 종합(SKILL §4 ④)에서 프레임워크 간 모순을 전략 옵션으로 전환한다.
