# Canvas Build — 캔버스 렌더 파이프라인 · 세이프티 · 뮤지엄 패스

STEP 2(캔버스 표현)의 실행 가이드다. 철학(.md)과 추론된 미묘한 레퍼런스를 손에 쥐고 **단일 페이지의 고밀도·비주얼 우선 .pdf/.png**를 만든다. 모드(홈베이스/자유) 색·폰트 규칙은 `mode-toggle.md` 기준.

---

## 1. 빌드 전 준비

1. **모드 확정**(미지정=홈베이스). `mode-toggle.md §2`.
2. **폰트 확보**: 홈베이스 Pretendard(+JetBrains Mono), 자유 모드 canvas-fonts. 확보 순서는 `fonts-strategy.md`.
3. **홈베이스면 SoT 토큰 로드**(미러 금지): `jc-palette-mapping.md §1`의 `load_tokens`/`color`. 자유 모드면 미학이 색을 정함.
4. 마음을 비우고 — 이건 *아트 오브젝트*다. 데크/문서가 아니다.

---

## 2. 렌더 파이프라인 선택

매체·환경에 맞게 택1(원본처럼 "필요한 도구는 가져다 쓴다"):

| 파이프라인 | 적합 | 비고 |
|-----------|------|------|
| **HTML/SVG → PDF/PNG** | 정밀 타이포·벡터 도형·반복 패턴, 웹폰트(Pretendard CSS) | Playwright/Chromium 등으로 스크린샷·인쇄. `@media print` 라이트 강제 자연스러움 |
| **Python(matplotlib/Pillow/svgwrite/reportlab)** | 프로그래매틱 패턴·조밀한 마크 축적·좌표 다이어그램 | 환경에 미설치면 설치. .ttf 직접 등록 |
| **벡터 직접 작성(SVG)** | 완벽한 도형·기하학적 정밀 | 텍스트는 path 또는 폰트 임베드, 페이지 경계 명시 |

- 환경에 라이브러리가 없으면 **설치하거나 다른 파이프라인으로** 전환(이 레포·실행 환경엔 matplotlib/PIL/reportlab이 기본 미설치일 수 있음 — 빌드 시 확인·설치).
- 산출은 **단일 .pdf 또는 .png**(요청 없으면 1페이지).

---

## 3. 캔버스 미학 실행 (원본 정신 계승)

- **고밀도·반복**: 반복 패턴·완벽한 도형. 추상 철학을 *상상 속 학문의 과학 도감*처럼 — 조밀한 마크의 축적, 반복 요소, 레이어드 패턴이 인내심 있는 반복으로 의미를 쌓는다. 지속적 응시에 보답.
- **임상적 타이포 + 체계적 레퍼런스 마커**: 상상 속 분류 체계의 다이어그램처럼. 좌표·번호·눈금·범례를 더해 *보이지 않는 주제를 관찰 가능한 현상처럼 다룬다*.
- **앵커 문구**: 단순한 문구/디테일을 미묘하게 배치. 제한된·의도적·응집된 팔레트.
- **홈베이스 색 절제**: `jc-palette-mapping.md §3·§5`. scale-blue 5단계 명도만으로 깊이를 쌓는 모노크로매틱이 정석. 임의 색 추가 금지.
- **타이포를 아트로**: 추상이면 폰트를 캔버스 위 오브젝트로 끌어들임(디지털 식자만 X). 텍스트 스케일은 맥락이 결정 — 펑크 포스터는 크고 공격적, 미니멀 아이덴티티는 속삭임. 대개 thin 우선.

## 4. 인쇄 라이트 (MICE 배포물 권장)

`#RULE-PRINT-LIGHT` (정본 `jc-design-system/references/shared-rules.md#RULE-PRINT-LIGHT`, 값 `mode-mapping.md §4.2`).

- MICE 키비주얼·표지 아트는 **인쇄·투사·이메일 배포**가 흔하다 → 라이트 배경 + jc 토큰 권장.
- HTML 파이프라인이면 인쇄 라이트 강제:
  ```css
  @media print {
    :root, [data-theme="dark"] {
      --jc-bg: #FFFFFF !important;
      --jc-surface: #FFFFFF !important;
      --jc-text: #1A1D24 !important;
    }
  }
  ```
- **예외**: 다크 풀블리드(`primary` 바탕)가 작품의 *의도된 디자인*이면 그대로 둔다(표지 아트·임팩트 키비주얼). 단 인쇄 배포가 주목적이면 라이트로 간다. 자유 모드 미학이 다크를 요구하면 그 또한 디자인.

## 5. 세이프티 체크 (협상 불가)

빌드 후 **반드시** 확인:

- [ ] **페이지 이탈 0**: 모든 텍스트·그래픽이 캔버스 경계 안, 적절한 마진.
- [ ] **겹침 0**: 요소 간 명확한 분리·breathing room.
- [ ] **가독 텍스트 대비**: 읽혀야 하는 제목·라벨은 배경 대비 4.5:1↑(큰 텍스트 3:1) — `#RULE-WCAG`, 계산 `mode-mapping.md §9`. 순수 장식 마크는 예외.
- [ ] **회사·개인정보 0건**: 작품·파일명·메타에 회사명·실명·부서·실제 로고 없음 — `#RULE-NO-COMPANY`.
- [ ] **홈베이스 색 정합**: jc 토큰만 사용, 임의 색 0(자유 모드 아닐 때). 값 하드코딩 0(SoT 참조).
- [ ] **폰트 라이선스**: 사용 폰트 OFL 확인, 기존 아티스트 작품 모사 0.
- [ ] **단일 페이지**(요청 없으면): 고밀도·비주얼 우선·디자인 포워드.

## 6. 뮤지엄 패스 (정제, 추가 아님)

사용자는 이미 말했다: *"It isn't perfect enough. It must be pristine, a masterpiece of craftsmanship, as if it were about to be displayed in a museum."*

- **그래픽을 더하지 말 것.** 새 함수·새 도형을 부르고 싶으면 STOP하고 물어라: **"이미 여기 있는 걸 어떻게 더 아트로 만들까?"**
- 새 필터·폰트 교체가 아니라 **기존 구성의 응집도**를 높인다. 구도·간격·색·타이포를 극도로 crisp하게.
- 미니멀리즘과 철학을 온전히 존중하며 두 번째 패스를 돌린다. 모든 디테일이 전문가 수준 크래프트맨십을 외치도록.

---

## 7. 멀티페이지 (요청 시에만)

- 첫 장을 *커피테이블 북의 한 장*으로 보고, 다음 장들은 같은 철학 선상이되 distinctly different한 변주·기억. 품격 있게 이야기를 잇는다.
- 한 .pdf로 묶거나 여러 .png로.
- **모드 규칙은 페이지마다 동일**: 홈베이스 북은 끝까지 jc 팔레트·Pretendard. 자유 북은 끝까지 그 미학.

---

## 8. 산출 후 (생태계 연결)

- 철학(.md) + 캔버스(.pdf/.png) 둘 다 전달.
- 완성 아트오브젝트의 **카피(라벨 오탈자)·대비·일관성** 최종 점검이 필요하면 **`jc-redteam`**(플레이북 §6) — 원본의 "fresh Claude 테스트" 대체.
- 산출물에 *기존 클라이언트 오버레이/톤*을 입히는 별도 요청은 `jc-theme-factory` 영역(본 스킬은 미학 아트, theme-factory는 토큰 적용).
