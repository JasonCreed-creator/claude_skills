# 재사용 레퍼런스 케이스 빌더

행사 결과를 **차기 비딩·스폰서 영업에 그대로 인용하는 케이스(case study)**로 전환한다. 보고서(8축)에서 셀링 포인트를 추출해 재사용 단위로 응축한다. proposal-skills의 case study 구조를 흡수했다.

---

## 케이스 4요소 (challenge → approach → result → proof)

| 요소 | 내용 | 출처(8축) |
|------|------|----------|
| **Challenge** | 발주처/시장이 안고 있던 과제·제약 (한 문장) | 2축 개요·6축 |
| **Approach** | 우리가 택한 해법·차별화 (2~3 포인트) | 5축 하이라이트 |
| **Result** | **정량 성과** (목표 대비 달성) — 케이스의 핵심 | 3·4축 |
| **Proof** | 증빙(수치 출처·피드백 인용·미디어·재계약) | 3·4·7축 |

> **Result는 반드시 정량·목표 대비**. "성황리 종료"는 케이스가 아니다. "목표 1,000명 대비 1,180명(118%)·CSAT 4.2"가 케이스다.

---

## 케이스 카드 형식

```
[케이스] {{행사 유형}} — {{한 줄 성과}}
 Challenge : {{과제}}
 Approach  : {{해법 1}} / {{해법 2}} / {{해법 3}}
 Result    : {{KPI1 목표→실적(달성률)}}, {{KPI2 …}}, {{예산 절감 …}}
 Proof     : {{출처/피드백/재계약 등}}
 재사용 등급: {{tier}}  (아래)
 익명화    : {{공개/익명(T社)/동의필요}}
```

한 행사에서 **여러 케이스**를 뽑을 수 있다(예: "모객 성과" 케이스 + "하이브리드 운영" 케이스). 다운스트림 용도별로 분리.

---

## 재사용 등급 (어디에 쓸지)

| 등급 | 의미 | 다운스트림 |
|------|------|-----------|
| **R1 비딩 레퍼런스** | 차기 수주 제안서의 수행실적·유사사례 | → mice-proposal |
| **R2 스폰서 ROI** | 스폰서에게 보여줄 노출·리드·ROI 실적 | → mice-sponsor-deck |
| **R3 시장 근거** | 벤치마크·시장 검증 데이터 | → mice-market-intel/strategy-canvas |
| **R0 내부 전용** | 교훈·실패 사례(외부 비공개) | 내부 위키만 |

각 케이스에 1개 이상 등급 부여. 등급이 `chaining-schema`의 `target`을 결정한다.

---

## 익명화 규칙 (RULE-NO-COMPANY + 발주처 보호)

케이스를 **외부 영업자료로 재사용**할 때:

1. **자사 식별정보**: 항상 외부 주입 변수(`{{company_name}}` 등). 하드코딩 금지.
2. **발주처 실명**:
   - 사용 동의가 있으면 실명 + 로고 가능(가장 강력).
   - 동의 없으면 **익명화**: `T社`·`[공공기관]`·`[국내 대기업]` + 산업·규모로 식별 가능성만.
   - 비공개 계약·NDA 행사는 R0(내부 전용)로만.
3. **실적 수치**: 과장·반올림 왜곡 금지. 출처(내부 정산·설문 n수) 보유. 공개 시 검증 가능 범위만.

> 익명화해도 케이스 가치는 유지된다 — 셀링 포인트는 *회사명*이 아니라 *목표 대비 성과*다.

---

## 안티패턴

- ❌ Result가 정성("성공적")만 → ✅ 목표 대비 정량(달성률).
- ❌ Approach가 일반론("열심히 준비") → ✅ 차별화된 구체 결정(자동 리마인드·하이브리드 송출 등).
- ❌ Proof 없음(주장만) → ✅ 출처·피드백·재계약 등 증빙.
- ❌ 발주처 실명 무단 외부 사용 → ✅ 동의 또는 익명화.
- ❌ 생존자 편향(잘된 것만) → ✅ R0 내부 케이스로 실패도 자산화(외부엔 미노출).
- ❌ 한 케이스에 모든 성과 욱여넣기 → ✅ 용도별 분리(R1/R2/R3).

## 워크드 예시

```
[케이스] 반일 테크 포럼 — 목표 118% 모객·재계약 확정 (R1·R2)
 Challenge : 신생 포럼, 인지도 낮아 목표 1,000명 모객 불확실
 Approach  : ① D-7/D-1 자동 리마인드 ② 연사 라인업 조기 공개 ③ 하이브리드 송출
 Result    : 참가 1,180명(목표 1,000, 118%) / CSAT 4.2(목표 4.0) / 예산 3.2% 절감
 Proof     : 등록시스템 정산·현장 설문 n=412·발주처 차년도 재계약 의향서
 재사용 등급: R1(차기 비딩 실적) + R2(스폰서 노출 ROI)
 익명화    : 발주처 동의 시 실명, 미동의 시 'T社 주최 테크 포럼'
```

→ 이 케이스는 `chaining-schema`로 mice-proposal(R1)·mice-sponsor-deck(R2)에 배출된다.
