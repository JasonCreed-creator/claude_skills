### 4. 섹션 구조 (Row 22~)

리멤버 견적서는 고정 7개 섹션으로 구성:

#### 섹션 헤더 패턴
각 섹션은 아래 구조를 반복:
```
Row N  : "  N. {섹션명}"  (A열)  |  "Package 비용" (D:E 병합)  |  {소계} (F열)  |  비고 (G열)
Row N+1: ITEM | DESCRIPTION | SIZE/SPEC | 정가 | 패키지할인가 | 차액 | REMARKS  ← 헤더행
Row N+2~: 데이터 행들
Row M  : "total" (A열)  |  {정가합계} (D열)  |  {할인합계} (E열)  |  {차액합계} (F열)
```

#### 7개 섹션 목록
1. **베뉴 사용료** — 장소 사용료
2. **시스템 구축 비용** — 영상/음향/등록시스템
3. **디자인 및 브랜딩 비용** — 현수막, 웹페이지, 키비주얼
4. **운영인력 및 보험** — 현장 운영인력, 보험
5. **기타 운영비** — MC, 미디어, 기념품 등
6. **PCO 이윤** — 인건비(운영비 15%) + 기업이윤(운영비+인건비의 10%)
7. **리멤버 모객 솔루션** — 모집리드, 쇼업 (KPI 확정 후 별도 협의)

#### 열 구조 (데이터 행)
| 열 | 헤더 | 설명 |
|----|------|------|
| A | ITEM | 항목명 |
| B | DESCRIPTION | 상세 설명 |
| C | SIZE(mm) / SPEC | 규격·사양 |
| D | 정가 | 원래 가격 |
| E | 패키지 할인가 | 할인 후 가격 |
| F | 차액 | D - E (실제 청구 금액) |
| G:H | REMARKS | 비고 (G:H 병합) |

#### 데이터 행 패턴
- **메인 아이템**: A열에 항목명, B~C에 상세, D에 정가, E에 할인가, F에 차액
- **서브 아이템**: A열 비우고, B~C에 상세 (금액 없음, 메인 아이템에 포함)
- **total 행**: A열에 "total", D/E/F에 각 열 합계

### 5. PCO 이윤 섹션 (섹션 6) — 특수 구조
| 셀 | 내용 |
|-----|------|
| 헤더행 | ITEM / DESCRIPTION / SIZE·SPEC / 운영비 합계 / 비율 / 소계 / REMARKS |
| 인건비 | "운영비의 15%" / D: 운영비합계 / E: 0.15 / F: D×E |
| 기업이윤 | "(운영비+인건비)의 10%" / D: 운영비+인건비 / E: 0.1 / F: D×E |

운영비 합계 = 섹션2~5의 F열 합계 (모객비용 제외)
