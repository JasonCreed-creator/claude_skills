# MICE 경쟁 분석 방법론 (티어링 → 스코어링 → 의사결정 리포트)

`mice-market-intel` Phase 2~3에서 **경쟁 조사**가 조사의 주축일 때 쓰는 3단 방법론. T2(경쟁 구도)·T7(타깃 주체 심층 프로파일)로 모은 원자료를 *비교 가능하고 방어 가능한* 경쟁 인텔로 벼린다.

> 출처 패턴: 외부 3종 경쟁분석 스킬(competitive-platform-analysis · benchmark-methodology · competitive-report-structure)의 *3단 흐름 구조만* 흡수 — 창작 문구·크리에이티브 스튜디오 예시는 버리고 MICE(행사 포트폴리오·베뉴·주최사 경쟁 구도) 문맥으로 재구성. 공통 규약은 상위 SKILL과 동일: **출처·티어 필수, 추정 금지, 다중 출처 교차확인**.
>
> **경계**: 본 방법론은 *경쟁 인텔의 근거·점수·구조*를 산출한다. "그래서 진입해야 하나/이길 수 있나"의 매력도·의사결정 판단은 `jc-strategy-canvas`(F2 5 Forces·F5 포지셔닝) 몫이다. 여기서는 티어·점수·화이트스페이스 후보를 *근거로 배출*하고 판단은 다운스트림에 넘긴다.

## 1단계 — 포지셔닝 브리프 우선 경쟁사 티어링

경쟁셋은 프레임이 전부다. **잘못 잡은 셋은 우리를 무적으로도, 필패로도 보이게 한다.** 목적은 전수 조사가 아니라 *의사결정에 유의미한 방어 가능한 셋*이다.

### 먼저: 포지셔닝 브리프 확립 (건너뛰기 금지)

경쟁셋을 좁히기 **전에** 기획자님(우리 측)의 포지셔닝 브리프를 먼저 세운다. 없으면 짧게라도 확인하고, 절대 blind로 셋을 짜지 않는다. 브리프가 공급하는 것:

- **정체성·성격** — 어떤 기획사/주체이고 시장에서 어떻게 보이려 하는가.
- **오퍼** — 어떤 행사·서비스를 제공하는가.
- **타깃** — 어떤 발주처·참가자·시장을 노리는가.
- **차별점(해자)** — 우리가 믿는 포지셔닝 논거.
- **스코핑 결과** — 경쟁사를 어떤 축으로 가중할지의 함의(차별성 우선 vs 수행역량 겹침 우선 vs 가격대).
- **전략 긴장축** — 우리 화이트스페이스를 정의하는 짝축(예: *규모 × 전문성*, *대중성 × 프리미엄*, *글로벌 × 로컬 밀착*).

> 브리프 없이 짠 경쟁 리스트는 인텔이 아니라 노이즈다. 특히 *스코핑 결과*가 "강한 경쟁사(우리 해자를 직접 다투는 곳)"와 "서비스 메뉴만 겹치는 곳"을 갈라준다.

### 후보를 펼치는 축 (한쪽 아키타입 쏠림 방지)

버킷이 아니라 **일반 축**으로 펼쳐 landscape가 한 유형에 치우치지 않게 한다. 먼저 각 축에서 폭을 확보하고 나서 가장 시사적인 후보로 가지치기:

1. **포지셔닝 스탠스** — 브랜드/컨셉 주도(정체성·POV로 경쟁) vs 수행역량 주도(운영력·규모·성과로 경쟁).
2. **전문화 정도** — 전문형(한 분야·버티컬) vs 범용형(넓은 행사 메뉴). 우리 초점과 겹칠수록 직접 경쟁.
3. **규모/모델** — 개인/소형 vs 부티크 vs 중견 vs 대형 PCO/전시주최사. 동일 밴드가 현실적 맞상대, 상위 밴드는 지향 기준.
4. **개최 포맷** — 정례 앵커 행사(브랜드 소유) vs 수주형 용역(발주처 종속). 포지셔닝 성숙도 신호.
5. **차별성 태세** — 관습·안전 vs 차별·선도.
6. **근거·신뢰 모델** — 성과 주도(참가·바이어·재개최 수치) vs 외형 주도(규모·수상). 어떻게 신뢰를 버는가.
7. **주체 브랜드 강도** — 대체 가능 vs 소유 가능한(고유 인지) 행사 브랜드.
8. **시장·도달** — 로컬/지역 vs 전국/글로벌. 같은 발주처·참가자를 놓고 다투는가.

한 후보가 포지셔닝·전문화·규모·시장에서 동시에 우리와 가까우면 **직접(Direct)** 경쟁이다.

### 티어 확정 (리포트까지 관통)

- **직접(Direct)** — 동일 밴드·오퍼 겹침·동일 타깃. 현실적 정면 승부.
- **인접(Adjacent)** — 부분 겹침(한 역량, 또는 다른 규모대)으로 가장자리를 압박.
- **지향(Aspirational)** — 지금은 안 붙지만 브랜드·상업 성숙도가 우리 목표 기준선을 세우는 상위 주체.
- *(대체재도 주시)* — 자체행사·웨비나·디지털 커뮤니티·인하우스 팀. 프로파일 대상은 아니되 위협 벡터로 메모.

### 선별 사전 필터 (스코어링 진입 게이트)

1~5로 가볍게 채점해 본 채점(2단계)으로 진급시킬 후보를 거른다. **차별성 또는 신뢰성 중 하나라도 높으면** 남긴다(전략 긴장축은 양극이 다 시사적).

| 후보 | 포지셔닝 스탠스 | 전문화 | 규모 밴드 | 티어 | 오퍼 겹침(1–5) | 차별성(1–5) | 상업 신뢰성(1–5) | 근접도(1–5) | 포함? |
|------|----------------|--------|-----------|------|----------------|-------------|------------------|-------------|-------|

- 차별성 高 **and** 신뢰성 高 → 필수 프로파일(우리 목표 긴장축이 달성 가능함을 증명).
- 차별성 高, 신뢰성 低 → 반면교사(기억엔 남되 발주는 못 받는 실패모드).
- 신뢰성 高, 차별성 低 → 우리가 스스로를 구분짓는 "유능하나 잊히는" 다수.
- 둘 다 低 → landscape 폭이 필요할 때만 잔류.

**산출**: 티어링된 경쟁셋(대략 후보 10~18 → 프로파일 8~12), 각 축 위치·티어·출처 링크 태그 → 2단계로 인계. (T2의 "미방어 세그먼트 탐지" 렌즈와 짝을 이룬다 — 티어링이 *누가 있나*, 미방어 탐지가 *어디가 비었나*.)

## 2단계 — 9차원 가중 스코어링 (긴장축 분리)

티어링된 셋을 **비교 가능·방어 가능한 점수**로 바꾼다. 모든 경쟁사를 같은 9차원·같은 1~5 루브릭으로 채점하고 균일 프로파일 카드에 담는다. 일관성이 핵심 — *같은 근거는 어느 경쟁사에서든 같은 점수*를 받아야 한다.

### 9차원과 가중치 (합 100%)

가중치는 종합 시 강조 배분용이며 **단일 합산 점수를 만들지 않는다**(거짓 종합 금지 — 편향 통제 참조).

1. **포지셔닝 명료성·차별성** (18%) — 행사/주체 포지션이 뚜렷·소유 가능·즉시 읽히나, 아니면 범용인가.
2. **행사 브랜드·업계 인지도** (15%) — 소유 가능한 행사 브랜드 자산인가, 대체 가능한가.
3. **콘텐츠·프로그램 경쟁력** (15%) — 프로그램 구성·연사·경험 설계의 완성도(개최물이 곧 실력 증거).
4. **포트폴리오·개최 실적** (12%) — 개최 이력·규모·주기 안정성. 정례화·확장 성숙도.
5. **참가자·바이어 근거** (12%) — 참가규모·바이어 품질·재방문·만족의 *검증된* 근거(주장 vs 검증 구분).
6. **발주처·기관 신뢰/수주 역량** (10%) — 공공·협회 발주 관계, 대형 사업 수행·계약 이행 신호.
7. **스폰서·파트너 유치력** (8%) — 협찬 유치 실적·파트너십 네트워크 깊이.
8. **수익모델·가격 구조** (5%) — 부스/참가/스폰서 가격 투명성과 모델 성숙도.
9. **[기획자님 전략 긴장축]** (5% 플래그; **양극 각각 채점·분리 보고, 절대 평균 금지**) — 브리프의 긴장축 이름·축 설명을 읽어 양극을 각각 1~5로 플롯. 우리 목표 사분면에 *누가 이미 있는가*가 벤치마크 최대 발견.

### 루브릭 (1~5, 1~8차원 공통)

모든 점수를 관찰된 근거에 앵커. **1** 부재/범용(템플릿과 무구분) · **2** 미달(의도는 있으나 산발·모방) · **3** 유능/기본기(견실하나 무주공산) · **4** 강함/차별(동종 대비 확연, 발주처가 짚어낼 강점) · **5** 카테고리 정의(동종 최고, 모방 난망, 남들이 반응하는 기준).

### 긴장축(9차원) — 양극 각각 1~5

브리프에서 축 라벨과 1/3/5 앵커를 읽어 각 극을 채점. 예(*규모 × 전문성* 긴장축):
- **규모** — 1: 소규모 단발 · 3: 지역 중급 정례 · 5: 전국/글로벌 대형 앵커.
- **전문성** — 1: 범용 대행 · 3: 특정 분야 경험 보유 · 5: 해당 버티컬 독보적 권위.

경쟁사를 긴장축 2×2에 플롯. 우리 목표 사분면은 브리프에 명시. **그 사분면을 누가 점유하는가가 벤치마크의 단일 최대 발견.**

### 편향 통제

- **단일 합산 점수 금지** — 차원별 점수와 긴장축 플롯을 분리 보고. 가중평균은 결정적 비대칭을 감춘다.
- **주장 vs 검증** — 자기 보고·미교차 주장은 근거/신뢰 점수 하향. 자사 홍보 문구는 사실이 아니다.
- **외형·최신성 편향** — 화려한 수상작이 상업 깊이를 담보하지 않는다. 참가·발주 근거로 교차확인 후 채점.
- **생존 편향** — 잘 노출된 주체가 시장 전부가 아니다. 디렉터리·발주 이력으로 "조용하지만 강한" 주체를 메모.
- **셋 전체로 캘리브레이션** — 확정 전 점수를 나란히 재검토. "4"는 모든 경쟁사에서 같은 뜻이어야 한다.

### 경쟁사 프로파일 카드 (출력 단위)

프로파일 대상마다 한 장 — 리포트가 조립되는 원자 단위:

```
## <경쟁사/주체명>
- 프로파일/티어: <포지셔닝 스탠스 · 전문화 · 규모밴드> / <직접 | 인접 | 지향>
- 한 줄 포지션: <그들 자신의 언어로>
- 모델/규모/시장: <소형|부티크|중견> · <지역> · <수익/가격 모델>
- 대표 실적·근거: <행사명·참가/바이어 수치 — 검증/주장 태그>

### 차원 점수
| 차원 | 점수(1–5) | 근거(1줄) | 출처 |
|------|-----------|-----------|------|
| 포지셔닝 명료성·차별성 | | | |
| 행사 브랜드·인지도 | | | |
| 콘텐츠·프로그램 경쟁력 | | | |
| 포트폴리오·개최 실적 | | | |
| 참가자·바이어 근거 | | | |
| 발주처·기관 신뢰/수주 역량 | | | |
| 스폰서·파트너 유치력 | | | |
| 수익모델·가격 구조 | | | |

### 긴장축 플롯
- [축1]: <1–5> — <근거>
- [축2]: <1–5> — <근거>
- 사분면: <고/고 | 고1저2 | 저1고2 | 저/저>

### 우리를 위한 읽기
```

**근거 없는 점수 금지** — 모든 점수에 1줄 근거 + 출처 링크. 완성 카드 + 긴장축 플롯을 3단계로 인계.

## 3단계 — 의사결정형 리포트 구조

점수화된 카드를 *의사결정 등급* 리포트로 조립한다. 리포트는 세 질문에 답해야 한다: **누구와 경쟁하나 · 어떻게 경쟁하나 · 우리의 방어 가능한 화이트스페이스는 어디인가.** 이에 기여하지 않는 섹션은 잘라낸다.

> 리포트는 기획자님(우리)의 전략 긴장축을 중심으로 조직되고, 권고는 우리가 의도한 브랜드 밸런스로 회귀한다. 밸런스를 깨는 권고는 "이 수는 밸런스를 X→Y로 이동시킴 — 의도 확인 요망"으로 명시 플래그.

### 섹션 구성

1. **핵심 요약** — 3~5개 의사결정 우선 테이크아웃. 어디가 강하고, 어디가 노출됐고, 목표 화이트스페이스를 누가 점유했고, 상위 2~3수. *이것만 읽어도 무엇을 할지 안다.* 방법론 서술 금지.
2. **시장 landscape·카테고리 프레이밍** — 다축 맵(최소 2×2, 이상적으로 긴장축 플롯을 헤드라인 맵으로). 모든 프로파일 경쟁사와 우리를 배치 → 우리 의도 포지션이 얼마나 붐비는지/비었는지 시각화.
3. **경쟁사 티어** — 직접/인접/지향(1단계). 티어별 한 문단: 누가 왜 여기 있고 우리에게 왜 중요한가.
4. **벤치마킹 매트릭스** — 경쟁사 × 9차원 표(정량 척추). 행=경쟁사(티어별 그룹), 열=9차원(9번 긴장축은 두 극을 **별도 서브열**로, 평균 금지). 우리 정직한 자가평가도 한 행. **히트맵**(색·기호)으로 강약 패턴 스캔. **합산 총점 열 추가 금지**. 우리가 앞서는/뒤처지는 열을 짚어냄.
5. **심층 다이브** — 가장 시사적인 3~5개(카드 → 서사). 랭킹이 아니라 교훈으로 선정: 목표 긴장축 최고 예시(양극 다 高), 한 극만인 반면교사, 우리가 스스로를 구분짓는 "유능하나 잊히는" 원형, 직접 위협. 각각: 무엇을 하나·배울 것·피할 것.
6. **화이트스페이스·위협** — 전략 심장부. (a) *화이트스페이스*: 경쟁사가 못 지키는, 우리가 소유 가능한 포지션 — 맵·매트릭스로 *논증*(단언 아님). 목표 사분면이 진짜 비었는지 확인. (b) *위협*: 격차 좁히는 경쟁사·대체재(자체행사·인하우스·디지털)·카테고리 이동. 우리 자체 리스크도 정직히.
7. **전략 권고(근거형)** — 구체·우선순위화한 수: 누구와 경쟁·어떻게 차별·어디 투자(오퍼 패키징·성과 근거·스폰서 파이프·브랜드 샤프닝). 브랜드 밸런스로 회귀시키고 이탈 시 플래그. 임팩트×노력으로 시퀀싱. → **매력도·진입 여부의 최종 전략 판단은 `jc-strategy-canvas`로 체이닝**(본 스킬은 근거·후보만).
8. **출처·방법론 부록** — 차원·가중치·루브릭, 티어링된 셋, 경쟁사별 출처 링크, 검증 메모(주장 vs 검증). 리포트를 감사 가능·방어 가능하게 하는 부분.
