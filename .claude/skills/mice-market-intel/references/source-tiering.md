# 출처 신뢰도 등급 (티어링)

`mice-market-intel` SKILL Phase 2의 정본. 모든 사실에 출처 + 티어를 부여한다. 상충 시 **높은 티어 우선**, 차이를 명시한다. 출처 패턴: `Anjos2/recursive-research`의 source-tiering 개념 흡수.

## 티어 정의

| 티어 | 신뢰도 | 출처 유형 | 사용 규칙 |
|------|--------|----------|----------|
| **T1** | 최고 | 정부·공공 통계, 산업 협회 공식 집계, 감사된 공시 | 1차 근거. 단독 인용 가능 |
| **T2** | 높음 | 전문 산업 보고서, 공신력 전문지, 학술 | 1차 보강·교차확인 |
| **T3** | 보통 | 일반 언론 기사, 기업 공개 자료(보도자료·IR) | 교차확인 필수. 단독 시 `[단일출처]` |
| **T4** | 낮음 | 블로그·커뮤니티·위키 | 참고·단서만. 결론 근거로 단독 사용 금지 |

> **교차확인 원칙**: 핵심 수치(시장규모·성장률·점유)는 **최소 2개 독립 출처**. 단일 출처면 `[단일출처]` 표식. T3·T4만으로 결론 내지 않는다.

## MICE 데이터 소스 참고 (공개 출처 — 자사 식별 아님)

조사 시작점 후보. *공개된 통계·산업 정보원*이며 `RULE-NO-COMPANY`의 자사·개인 식별 금지와 무관(인용 대상 데이터 소스).

**국내 (한국)**
- 통계청 KOSIS, 한국관광공사 MICE 통계 — 시장·참가 통계(T1)
- 한국전시산업진흥회(AKEI), 한국MICE협회 — 전시·MICE 산업 집계(T1~T2)
- KOTRA, 지자체 컨벤션뷰로(서울/부산 등) — 산업·지원사업(T1~T2)
- 주요 전시장(코엑스·킨텍스·벡스코 등) 공개 행사 캘린더 — 행사 규모·일정(T2~T3)
- 나라장터·조달청 공고 — 발주·예산 패턴(T1, 발주처 환경 T4)

**해외 (글로벌)**
- UFI(국제전시연맹), ICCA(국제컨벤션협회), AIPC — 글로벌 전시·컨벤션 통계(T1~T2)
- Statista·산업 리서치(요약은 T2, 원천 추적 권장)

**검색 운용**
- WebSearch/WebFetch로 위 소스 우선 탐색. 1차 통계 페이지를 직접 페치해 숫자·연도·정의 확인(요약 기사보다 원천 우선).
- 외부 스크립트·데이터셋을 *실행/설치하지 않는다*(가드레일). 읽기·인용만.
- 접근 불가(유료·로그인) 출처는 `[접근불가]`로 표시하고 대체 출처를 찾는다.
