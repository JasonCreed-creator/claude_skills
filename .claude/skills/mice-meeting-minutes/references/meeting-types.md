# Meeting Types — 5종 회의 유형 정의

본 스킬은 MICE 실무에서 빈도가 높은 5종 회의 유형을 인식하고 유형별로 톤·구조·기본 모드를 분기한다.

---

## Type A — 외부 클라이언트 미팅

**대표 케이스**: Discovery Meeting / 킥오프 / 정기 협의 / 제안 직후 협의

| 항목 | 값 |
|------|----|
| 톤 | 정중·사실 위주 |
| 외부 송부 | 송부 가능 (전제) |
| 기본 모드 | `--external` |
| 강조 축 | 결정사항 + 후속 일정 + Action Items |
| 전략 메모 | Internal 백업에만 풀버전 |
| Redaction | 자동 적용 |

**판별 시그널**:
- 미팅 제목·키워드: "Discovery", "킥오프", "Kick-off", "고객사 미팅", "제안 협의", "RFP 설명회"
- 참석자: 고객사 외부 인사 명단 포함
- 발화 패턴: 존칭·격식 어미 비율 70% 이상

**대표 적용 사례 (가명 예시)**:
- A사 고객 컨퍼런스 Discovery 미팅
- B사 정기 협의
- C사 세미나 2026 협의
- D기관 박람회 발주처 협의

---

## Type B — 내부 팀 미팅

**대표 케이스**: 주간 미팅 / TF 미팅 / 사업 검토 회의 / 자사 정기 회의

| 항목 | 값 |
|------|----|
| 톤 | 간결·솔직 |
| 외부 송부 | 내부 한정 |
| 기본 모드 | `--internal` |
| 강조 축 | Action Items 중심 |
| 전략 메모 | 풀버전 포함 |
| Redaction | 미적용 |

**판별 시그널**:
- 미팅 제목·키워드: "주간", "TF", "내부", "팀 미팅", "자사 회의", "정기 회의"
- 참석자: 동일 조직 인사만
- 발화 패턴: 약어·내부 용어 빈도 높음, 평가 표현 자유

---

## Type C — 발주처 공식 협의

**대표 케이스**: 입찰 후 발주처 미팅 / 계약 협의 / 변경 협의 / 정기 보고

| 항목 | 값 |
|------|----|
| 톤 | 공식·중립 |
| 외부 송부 | 송부 필수 (양측 보관) |
| 기본 모드 | `--external` |
| 강조 축 | 책임 소재 + 합의사항 + 일정 |
| 전략 메모 | Internal 백업에만 풀버전 |
| Redaction | 자동 적용 (강도 ↑) |

**판별 시그널**:
- 미팅 제목·키워드: "발주처", "공문", "계약 협의", "PCO 미팅", "변경 협의", "보고 회의"
- 참석자: 발주처 + 수행사(리멤버) 양측 명시
- 발화 패턴: 합의·확인 표현 빈도 높음

**Type A와의 차이**: Type A는 "수주 전·관계 구축", Type C는 "수주 후·계약 이행". 톤이 더 공식적이고 책임 소재 명확화가 핵심.

---

## Type D — 사전답사·현장 점검

**대표 케이스**: 베뉴 사전답사 / F&B 시연 / 리허설 / 현장 점검 / 안전 점검

| 항목 | 값 |
|------|----|
| 톤 | 실무·체크리스트 |
| 외부 송부 | 협력사 공유 |
| 기본 모드 | `--internal` |
| 강조 축 | 체크리스트 + 이슈 발견 + 사진 첨부 위치 |
| 전략 메모 | 운영 리스크 관점 |
| Redaction | 미적용 |

**판별 시그널**:
- 미팅 제목·키워드: "답사", "현장 점검", "F&B 시연", "리허설", "Site Visit", "Walk-through"
- 참석자: 베뉴·협력사 인사
- 발화 패턴: 위치 표현·치수·시간 빈도 높음

**특이 구조**:
- 회의록 형식보다 **체크리스트 형식** 우선
- 이슈 발견 시 "위치 / 현상 / 영향도 / 대응안" 4열 구조
- 사진 첨부 위치 표시 (외부 도구로 사진 삽입)

---

## Type E — 협력사·벤더 미팅

**대표 케이스**: 부스 시공사 / 인쇄 / 케이터링 / 음향·영상 / 출연자 매니지먼트 / 인력 파견

| 항목 | 값 |
|------|----|
| 톤 | 계약 조건 명시 |
| 외부 송부 | 협력사 공유 |
| 기본 모드 | `--internal` (계약 협의 시 `--external`) |
| 강조 축 | 계약 조건 + 단가 + 납기 + 책임 분담 |
| 전략 메모 | 가격 협상 메모 |
| Redaction | 협력사 공유 시 내부 마진 정보 마스킹 |

**판별 시그널**:
- 미팅 제목·키워드: "벤더", "단가", "납기", "MOU", "협력사", "시공", "케이터링", "음향", "출연"
- 참석자: 외부 협력사 + 운영팀
- 발화 패턴: 금액·일정·수량 표현 빈도 높음

## 자동 판정 (Claude 본체 — 묻지 않고 기본값으로 진행)

`scripts/parse_input.py`는 채널·화자·Redaction 힌트까지만 만든다. 유형 판정은 8축 추출 직전에 Claude가 한다.

```
1. 사용자 --type 플래그 또는 메시지 내 "Type X"·유형명 → 확정
2. 미팅 제목·참석자·발화 패턴에 위 판별 시그널을 매칭해 점수화
   - 키워드 매칭 1건당 +2점, 발화 패턴 매칭 +1점, 외부 인사 비율 가중
3. 1위 점수로 확정. 1·2위 차이가 3점 미만이면 더 공식적인 유형(C > A > E > D > B)을 택한다
4. 응답 첫머리에 한 줄로 밝힌다
   예) "유형: Type A로 판정(A=6·C=5 근소 — C로 바꾸려면 말씀만 주세요)"
```

유형은 되돌릴 수 있는 선택이므로 질의하지 않는다. 사용자가 바꾸면 재빌드한다.

## 유형별 산출물 차이 매트릭스

| 산출물 요소 | A | B | C | D | E |
|------------|---|---|---|---|---|
| 대시보드 헤더 표시 | 발주처 슬롯 | 리멤버 기본 | 발주처 슬롯 + 양측 명시 | 리멤버 기본 + 베뉴명 | 협력사 명시 |
| 발화자 표시 | 직함 + 이름 | 이름만 | 직함 + 이름 (역할 강조) | 점검자 + 베뉴 담당 | 담당자 + 회사명 |
| 결정사항 강조 | 박스 | 굵게 | **양측 합의 박스** | 체크박스 | **계약 조건 박스** |
| Action 5열 (칸반) | 표준 | 표준 | **양측 분리 표시** | 체크리스트 형식 | 표준 + 단가·납기 |
| 전략 메모 탭 | External 토글 시 숨김 | 항상 노출 | External 토글 시 숨김 | 운영 리스크 메모 | 가격 협상 메모 |
| 툴바 푸터 | 송부 가이드 | 내부 보관용 | 양측 보관 표기 | 답사일 + 점검자 | 협력사 공유 표기 |

## 유형 변경 처리 (회의 중 성격 변화)

실제 미팅에서 유형이 도중에 변하는 경우 발생 (예: Type C 시작 → Type A 분위기로 전환).

처리 방식:
- 단일 대시보드 + 더 공식적인 유형 적용 (보수적 기본값)
- transcript에 명확한 분기점이 있으면 응답에 한 줄로 밝힌다 — "두 단계로 나뉘어 보입니다(분기 32분). 분리 빌드를 원하시면 말씀만 주세요"
- 요청 시 HTML 대시보드 2개로 재빌드
