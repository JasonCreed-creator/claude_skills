# Redaction Rules — 민감 발언 마스킹 규칙

External 모드에서 외부 송부 가능한 회의록을 만들기 위한 민감 발언 식별·처리 규칙.

**18년 경력 전략가의 정치적 감각이 변별력**. 단순 키워드 매칭이 아닌 문맥 기반 판정.

---

## 1. 마스킹 카테고리 5종

### 카테고리 1: 민감 발언 (Sensitive)

오프 더 레코드 / 비공식 / 솔직한 발언으로 외부 송부 시 문제가 될 수 있는 것.

**시그널 키워드**:
- "솔직히 말하면…"
- "오프 더 레코드", "Off the record"
- "비공식이지만…", "이건 공식 기록 아니고…"
- "여기서만 하는 얘긴데…"
- "사실은…", "진짜로는…"

**처리**:
- External 모드: 해당 발화 통째로 제거
- Internal 백업: 그대로 보존 + "[비공식 발언]" 태그
- 회의록 내 흔적: "[일부 발언 비공식 처리]" 표기

---

### 카테고리 2: 인명 (Personal Names)

실명·직함을 외부 송부 시 마스킹할지 결정.

**적용 대상**:
- 미팅 직접 참석자가 아닌 제3자 실명
- 비판적 맥락의 외부 인사 실명
- 비공식 평가 대상 인사

**처리 옵션**:

| 처리 방식 | 적용 시점 |
|-----------|----------|
| 실명 그대로 | 미팅 직접 참석자 + 직함 명확 |
| 직함만 ("부장") | 외부 인사 직접 참석 + 미팅 호스트 동의 시 |
| 역할명 ("발주처 담당자") | External 송부 시 기본값 |
| 완전 익명화 ("관계자 A") | 비판적 맥락 + Sensitive 카테고리 결합 |

**자동 판정 룰**:
- 발화 내 인명 + 부정 표현 결합 → 역할명 치환
- 발화 내 인명 + 평가 표현 결합 → 익명화
- 그 외 → 직함만 표시

---

### 카테고리 3: 금액 (Financial)

비공식 예산·원가·마진 등 금액 정보.

**시그널 키워드**:
- "예산이 N억밖에 없어서…"
- "마진이 N% 정도라…"
- "원가가 N원이니까…"
- "대표 결재선이 N억이라…"
- "[금액] 깎을 수 있으면…"

**처리**:

| 발화 맥락 | External 처리 |
|-----------|--------------|
| 공식 합의 금액 (계약·견적 명시) | 그대로 표시 |
| 비공식 예산 토로 ("N억밖에 없어서") | 마스킹 ("[비공식 예산 언급]") |
| 우리 측 마진·원가 | 항상 마스킹 (Type E 협력사 미팅도 포함) |
| 경쟁사 입찰가 추정 | 마스킹 ("[경쟁사 가격 언급]") |

---

### 카테고리 4: 미공개 일정 (Undisclosed Schedule)

외부에 공유되면 안 되는 내부 일정·결재 라인.

**시그널 키워드**:
- "사장 결재 일정"
- "이사회 일정"
- "임원 회의"
- "본사 결재"
- "내부 보고"
- "[고위직] 일정"

**처리**:

| 발화 맥락 | External 처리 |
|-----------|--------------|
| "사장 결재 5/15까지" | "별도 공유 예정"으로 치환 |
| "이사회 결과 봐서…" | "내부 검토 후 회신" |
| "본사 시니어 일정" | "글로벌 본사 협의 후" |

---

### 카테고리 5: 정치적 발언 (Political)

경쟁사 비방·내부 갈등·인사 평가·산업 정치 발언.

**시그널 키워드**:
- 경쟁사명 + 부정 표현 ("[경쟁사]가 이번에 망친 거 보니까…")
- 내부 갈등 ("우리 쪽도 의견 안 맞아서…")
- 인사 평가 ("그 분 일 잘 못해서…")
- 산업 정치 ("[협회/단체]가 압력 넣어서…")

**처리**:
- External 모드: 무조건 제거
- Internal 백업: 보존 + "[정치적 발언]" 태그
- 회의록 내 흔적: 표기 없음 (제거 사실 자체를 외부 노출 안 함)

---

## 2. 처리 강도 (모드별)

| 모드 | Sensitive | 인명 | 금액 | 미공개 일정 | 정치적 |
|------|-----------|------|------|-------------|--------|
| `--external` Type A·E | 제거 | 직함/역할명 | 비공식만 마스킹 | 치환 | 제거 |
| `--external` Type C (발주처) | 제거 (강도↑) | 실명+직함 | 비공식 마스킹 | 치환 (강도↑) | 제거 |
| `--internal` (기본) | 보존 | 실명 | 그대로 | 그대로 | 보존 |

**Type C (발주처 공식 협의)는 가장 보수적 처리**. 양측 모두 보관하므로 분쟁 소지 최소화.

---

## 3. 의심 항목 별도 출력

자동 판정 신뢰도가 낮은 발화는 사용자에게 별도 의심 리스트로 출력하여 확인 요청.

### 출력 형식 예시

```
[Redaction 의심 항목 — 검토 부탁드립니다]

1. 21분경 발화: "솔직히 본사가 결재 빨리 안 해줄 것 같은데…"
   - 카테고리 추정: 민감 발언 + 미공개 일정
   - 권장 처리: 제거
   - 사용자 결정: [유지 / 제거 / 직접 수정]

2. 47분경 발화: "[경쟁사명] 작년에 비슷한 거 했는데 평가 안 좋았다고…"
   - 카테고리 추정: 정치적 발언
   - 권장 처리: 제거
   - 사용자 결정: [유지 / 제거 / 직접 수정]

3. 52분경 발화: "마진을 5% 정도만 잡으면 될 것 같습니다"
   - 카테고리 추정: 금액 (마진)
   - 권장 처리: 마스킹
   - 사용자 결정: [유지 / 마스킹 / 직접 수정]
```

→ 사용자가 결정한 후 최종 회의록 생성.

---

## 4. 표기 규칙 (마스킹 표시)

External 회의록에 마스킹된 부분이 있을 때 표기:

| 마스킹 유형 | 표기 |
|-------------|------|
| 발화 통째 제거 | (해당 부분에 표기 없음 — 흔적 남기지 않음) |
| 인명 치환 | 본문에 "[발주처 담당자]", "[관계자 A]" 등 |
| 금액 마스킹 | "[비공식 예산 언급]" |
| 일정 치환 | "별도 공유 예정", "내부 검토 후 회신" |
| 부분 발언 압축 | "(일부 발언은 별도 공유)" 푸터 표기 |

---

## 5. Internal 백업 시드 파일 처리

Redaction 적용된 모든 발화는 Internal 백업 파일에 보존.

### 백업 파일 구조

```
.internal-backup_[프로젝트]_[YYYYMMDD]_[type].docx

[페이지 1] External 회의록 동일 내용
[페이지 N+1] Redaction 처리 비교 표
  ┌──────────────┬──────────────┬──────────────┐
  │ 시점         │ 원문         │ External 처리 │
  ├──────────────┼──────────────┼──────────────┤
  │ 21분         │ 솔직히 본사… │ (제거)        │
  │ 47분         │ [경쟁사명]…  │ (제거)        │
  │ 52분         │ 마진 5%…     │ [비공식…]     │
  └──────────────┴──────────────┴──────────────┘
[페이지 마지막] 전략 메모 풀버전
```

→ 외부 송부 후에도 원본 분석 손실 방지.

## 6. Redaction 한국 MICE 업계 특화 패턴

### 발주처 비공식 발언 패턴
- "예산 좀 더 풀어볼 수 있는데…"
- "윗선 설득 가능한지 봐야 해서…"
- "다른 PCO 견적도 받아봐야…"
- "이번엔 [특정사]에 가야 할 분위기라…"

### 협력사 비공식 발언 패턴
- "단가 더 깎으면 우리 마진 안 나와요"
- "이건 [다른 PCO]랑도 하던 일이라…"
- "내부 인력이 빠져서 외주로 쓸 수밖에…"

### 한국 MICE 업계 정치 발언 패턴
- 협회·단체 압력 언급
- 인맥 기반 결정 시사 발언
- 입찰 결과 사전 인지 시사

→ 모두 External 모드에서 제거. Internal 백업에 "[업계 정치]" 태그로 보존.

---

## 7. Redaction 사용자 오버라이드

자동 판정 결과를 사용자가 변경 가능:

```
사용자: "21분 발화는 그대로 두고, 47분 발화만 제거해줘"
       → 22분·52분 발화도 재확인하여 처리
       → 최종 산출물 재생성
```

또는:

```
사용자: "이번 회의록은 모든 의심 항목 보존. 단, 인명만 직함으로 치환"
       → Sensitive·금액·미공개 일정·정치 발언 모두 보존
       → 인명 카테고리만 처리
```

---

## 8. 리스크 회피 디폴트

판정 신뢰도 낮을 때는 **항상 보수적 처리** (마스킹 권장).

원칙:
> "외부 송부 회의록에서 한 줄을 잘못 남기면 분쟁이 1년 가지만, 한 줄을 더 마스킹해서 가는 건 클라이언트 양해를 구하면 끝난다."

→ 자동 판정 임계값을 낮게 (의심되면 마스킹) 설정. 사용자가 명시적 보존을 요청한 경우만 보존.
