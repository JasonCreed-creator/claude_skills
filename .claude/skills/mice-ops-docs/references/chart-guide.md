# 차트 가이드 — 유형 · 토큰 매핑 · 렌더 규칙

값은 `jc-design-system/references/signature-tokens.md`와 `component-patterns.md §6`이 정본이다. 여기서는 CSS 변수 이름만 쓴다.

---

## 1. 유형 선택

| 보여줄 것 | 차트 |
|-----------|------|
| 목표 대비 하나의 수치 | KPI 카드 + 진행률 바 |
| 단계별 이탈(신청→쇼업→리드) | 퍼널(수평 바 계단) |
| 세그먼트별 계획 대비 지연 | 수평 바(0 기준 좌우, 초과 = `--negative`) |
| 항목별 예산 계획 vs 실적 | 묶음 수평 바(계획 `--s3` 연하게, 실적 `--s1`) |
| 시간 추이(일별 신청) | 선(점 표시 최소) |
| 구성비 | 도넛은 3개 항목 이하만. 그 이상은 바 |

3D·그림자·파이 6조각 이상 금지.

## 2. 시리즈 매핑

- 순서: `--s1`(오렌지) → `--s2`(스틸) → `--s3`(브라운) → `--s4` → `--s5`.
- 강조 시리즈 1개만 `--s1`. 나머지는 중립에서.
- 상태색: 달성 `--positive` · 미달 `--negative` · 주의 `--amber`. 색만으로 구분하지 않고 라벨·기호 병기(`RULE-WCAG`).
- 트랙·격자: `--line-soft`. 축 라벨: `--ink-sub`.

## 3. 렌더 규칙

- SVG 직접 렌더 우선(오프라인·CSP 무관). Chart.js를 쓰면 `getComputedStyle`로 CSS 변수를 읽고 테마 토글 때 다시 칠한다(`usage-guide.md §3.5`).
- 숫자는 tabular-nums, 단위는 캡션색으로 분리.
- 다크 모드는 변수 재정의만으로 바뀌어야 한다. 하드코딩 HEX 금지.
- 인쇄 CSS에서 라이트 변수로 되돌린다(`RULE-PRINT-LIGHT`).
