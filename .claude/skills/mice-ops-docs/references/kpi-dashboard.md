# KPI 대시보드 — 카탈로그 · 화면 구성 · 기획안

행사 단위 결과 화면. 성과는 목표 대비로만 의미가 있다. 산출은 단일 HTML(아티팩트) — 외부 의존 없이 SVG로 그린다.

---

## 1. KPI 카탈로그

| 축 | KPI | 계산 | 목표 출처 |
|----|-----|------|-----------|
| 모객 | 신청 수 · 쇼업 수 · 쇼업률 | 쇼업 ÷ 신청 | 계약완료 메시지 `목표` |
| 모객 | 리드 수 · 게런티 달성률 | 쇼업 ÷ 게런티 | 팀 보드 L열 게런티 |
| 모객 | 타깃 적합률 | 타깃 조건 충족 참석 ÷ 쇼업 | 타깃조건 |
| 현장 | 정시 시작률 · 평균 지연(분) · 초과 세그먼트 수 | `scripts/plan_vs_actual.py` | 큐시트 |
| 현장 | 세션별 착석률 | 세션 착석 ÷ 쇼업 | 운영계획서 |
| 만족 | 만족도 평균 · NPS | 설문 | 발주처 합의 |
| 예산 | 집행률 · 항목별 차이 | 실집행 ÷ 계획 | `mice-estimate` |

목표가 없는 KPI는 실적만 표기하고 달성률 칸은 `[미확보]`.

## 2. 화면 구성

```
헤더: 킥커(행사 ID) · 행사명 · 일자 · 생성일 · 리멤버 로고 (+ 발주처 로고)
KPI 카드 4장: 쇼업 · 게런티 달성률 · 만족도 · 예산 집행률   ← 솔리드 변형은 1장만
본문 2열: 좌 모객 퍼널(신청→쇼업→리드) / 우 세그먼트 지연 바
하단: 세션별 착석률 표 · 인사이트 3줄 · 확인 필요 목록
```

- 라이트 기본 + 다크 토글. 인쇄는 라이트 강제.
- 카드 4장 초과 금지(그룹당 4장).

## 3. 기획안 양식 (빌드 전 1회 확인)

```
대시보드 기획안 — {{행사명}}
1. 보는 사람: 발주처 / 내부 / 영업
2. KPI 4개: …
3. 차트: 퍼널 1 · 바 1 · 표 1
4. 비어 있는 데이터: …(=[미확보]로 표기)
→ 이대로 빌드할까요? (추천: 이대로)
```
