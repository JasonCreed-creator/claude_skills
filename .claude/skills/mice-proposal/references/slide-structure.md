# 섹션별 슬라이드 구성 가이드 (v2.1)

이 문서는 각 섹션의 슬라이드를 어떤 레이아웃과 콘텐츠로 구성할지에 대한 상세 가이드이다. 제안서 생성 시 반드시 참조한다.

**v2.1 변경점**:
- 인포그래픽 패턴(`INFO-I1/I2/I3`) 매핑 추가
- 다크 모드 옵션(`DARK-*`) 표기 추가
- 아이콘 적용 위치(`+ICON`) 표기 추가
- 슬라이드 마스터 적용 옵션(`MASTER-*`) 표기 추가

**좌표 시스템**: 모든 좌표는 `LAYOUT_WIDE` (13.333" × 7.5") 기준.

**패턴 코드 표기법**:
- 이미지: `IMG-HERO`, `IMG-WIDE`, `IMG-CARD`, `IMG-PORTRAIT`, `IMG-AVATAR`, `IMG-MOOD`
- 표: `TBL-T1`(비교), `TBL-T2`(매트릭스), `TBL-T3`(일정), `TBL-T4`(예산)
- 차트: `CHART-C1`(도넛), `CHART-C2`(바/컬럼), `CHART-C3`(빅넘버)
- 다이어그램: `DIAG-D1`(조직도), `DIAG-D2`(프로세스), `DIAG-D3`(타임라인), `DIAG-D4`(카드)
- 인포그래픽 (신규): `INFO-I1`(퍼널), `INFO-I2`(매트릭스), `INFO-I3`(레이더)
- 다크 모드 (신규): 접두사 `DARK-` 또는 동일 패턴 + 다크 컬러
- 아이콘 (신규): `+ICON` 표기 (해당 패턴에 react-icons 추가)
- 마스터 (신규): `MASTER-TITLE`, `MASTER-SECTION_DIVIDER`, `MASTER-CONTENT_BASIC`, `MASTER-CONTENT_WITH_HERO`, `MASTER-THANK_YOU`

## 섹션 1: 표지 및 목차

### 슬라이드 1-1: 표지
- **레이아웃**: 전면 다크 배경
- **적용 패턴**: `IMG-HERO` (반투명 오버레이) + `MASTER-TITLE` (선택)
- **모드 옵션**:
  - **A. 회색 박스 모드**: HERO placeholder + 다크 오버레이 + 제목 텍스트
  - **B. 마스터 모드**: `MASTER-TITLE` 사용 → 우클릭 그림 변경 가능
- **구성 요소**:
  - 배경: HERO 이미지 + Primary 컬러 40~60% 투명 오버레이
  - 행사 정식 명칭 (44pt, 센터, 흰색, Pretendard Bold)
  - 부제 또는 슬로건 (20pt, 센터, `B8C5D6`)
  - 제안사명 (16pt, 하단 우측)
  - 제안 일자 (12pt, 하단 우측)
  - 로고 placeholder 위치: 하단 좌측 (1.5" × 0.8")
- **캡션**: `[이미지: 행사 대표 비주얼]`

### 슬라이드 1-2: 목차
- **레이아웃**: 좌측 좁은 컬러 사이드바 + 우측 본문
- **적용 패턴**: 없음 (텍스트 + 도형 구성) `+ICON` (각 섹션 앞)
- **구성 요소**:
  - 좌측 사이드바 (0 ~ 2.5", `COLOR_PRIMARY`) + "목차" 제목 (흰색, 28pt)
  - 우측 본문: 섹션 번호 + 섹션명 리스트
  - 각 섹션 앞에 0.3" 원형 아이콘 (Heroicons 추천)

## 다크 모드 슬라이드 배분 가이드 (v2.1 신규)

다크 모드 슬라이드가 전체의 30%를 넘으면 가독성 저하. 권장 비율:

| 슬라이드 | 다크 모드 권장 |
|---------|---------------|
| 표지 (1-1) | ✅ 필수 |
| 모든 섹션 구분 (2-1, 3-1, 4-1, 5-1, 6-1, 7-1) | ✅ 필수 (6장) |
| 기대 효과 (2-5) | ⚠️ 선택 — 임팩트 강조 시 |
| KPI 대시보드 (5-2) | ⚠️ 선택 — 임팩트 강조 시 |
| Thank You (7-5) | ✅ 필수 |
| 본문 슬라이드 | ❌ 금지 |

**합계**: 필수 8장 + 선택 0~2장 = 최대 10장 (38장 중 약 26%)

## 비주얼 패턴 적용 체크리스트 (v2.1 확장)

PPTX 생성 후 아래 항목을 확인한다:

### 기본 (v2.0과 동일)
- [ ] 모든 슬라이드에 비주얼 요소(이미지/표/차트/다이어그램/인포그래픽) 중 최소 1개 이상 포함
- [ ] 이미지 placeholder마다 캡션 `[이미지: {설명}]` 또는 `[사진: {설명}]` 명시
- [ ] 슬라이드 노트에 placeholder 교체 안내 + 폰트 안내 자동 기재
- [ ] 동일 비주얼 패턴이 3장 이상 연속되지 않음
- [ ] 표·차트·다이어그램이 jc-design-system 토큰 기반 색상 사용

### v2.1 신규
- [ ] 컬러 모드 결정됨 (RFP / JC / JC+오버레이)
- [ ] 폰트가 Pretendard·Inter·JetBrains Mono로 명시됨
- [ ] 인포그래픽 패턴(INFO-I1/I2/I3) 적용 시 해석 텍스트(인사이트) 함께 배치
- [ ] 다크 모드 슬라이드 비율 30% 이내
- [ ] 마스터 사용 슬라이드에 그림 자리표시자 교체 안내 노트 삽입
- [ ] 아이콘 사용 시 react-icons 의존성 확인 + 폴백 처리(safeAddIcon) 적용
- [ ] 한 슬라이드 내 아이콘 세트 혼용 없음 (Heroicons OR Font Awesome)
