# Analysis Framework — 7축 RFP 분석 프레임

본 문서는 mice-rfp-analyzer의 핵심 분석 엔진. 18년 경력 MICE 전략가의 RFP 해체 시각을 7축으로 표준화.

---

## 1. 요건 (Requirements)

### 1-1. 핵심 질문
"무엇을 해야 하는가? 무엇이 누락되면 실격인가?"

### 1-2. 추출 항목

| 분류 | 추출 데이터 | 판정 기준 |
|------|------------|----------|
| 필수 요건 | "반드시", "필수", "의무", "shall", "must" | 누락 = 실격 |
| 선택 요건 | "권장", "선호", "preferred", "should" | 미반영 시 감점 |
| 가산 요건 | "가산점", "우대", "추가" | 반영 시 가점 |
| 행사 사양 | 일자, 장소, 인원, 규모 | 사실 데이터 |
| 운영 범위 | 사전준비/현장운영/사후정리 구분 | 책임 범위 명확화 |
| 산출물 | 보고서·결과물·인계물 종류 | 누락 시 정산 분쟁 |

### 1-3. RFP에서 자주 누락되는 함정 키워드
- "별첨", "별표", "부록" — 본문보다 깊은 요건이 숨어있음
- "협의", "결정", "지정" — 발주처 권한이 비대칭
- "포함한", "등" — 무한 확장 위험

### 1-4. 산출 형식
필수/선택/가산 3분류 + 각 항목별 출처(페이지·조항) + 우리 측 대응 가능 여부(가능/조건부/불가) 표기.

## 2. 평가 (Evaluation)

### 2-1. 핵심 질문
"어떻게 점수가 매겨지는가? 우리는 어디에서 이길 수 있는가?"

### 2-2. 추출 항목

| 분류 | 추출 데이터 |
|------|------------|
| 평가 항목 | 항목명·정의·세부 지표 |
| 배점 | 항목별 만점·세부 배점 |
| 가중치 | 정성 vs 정량, 기술 vs 가격 비율 |
| 평가 방식 | 절대평가/상대평가, 가산/감산 |
| 평가 위원 | 인원·구성·발주처 직접/외부 |
| 가산점 | 자격증·실적·중소기업·지역 등 |

### 2-3. 표준 MICE 평가 비율 패턴
- **공공기관 일반**: 기술 80 : 가격 20
- **공공기관 협상**: 기술 90 : 가격 10
- **민간 일반**: 기술 60~70 : 가격 30~40
- **단가 입찰**: 가격 100% (최저가)

→ 이 패턴에서 크게 벗어나면 발주처 의도 분석 필요.

### 2-4. 평가 매트릭스 변환
추출된 평가 기준을 evaluation-matrix-spec.md 정의 시트로 변환. 각 항목에 대해 우리 측 예상 점수(자체 추정) 입력.

---

## 3. 리스크 (Risk)

### 3-1. 핵심 질문
"어디에 함정이 있는가? 계약 후 분쟁 소지는 무엇인가?"

### 3-2. 검토 영역

| 영역 | 점검 포인트 |
|------|------------|
| 책임 범위 | 무한 책임·연대 보증·민형사 책임 조항 |
| 손해배상 | 배상 한도·간접손해·일실이익 |
| 변경권 | 일방적 변경권·통보 의무·보상 여부 |
| 정산 | 검수 권한·지급 시점·지연 이자 |
| 지식재산 | 산출물 권리 귀속·재사용 권한 |
| 비밀유지 | NDA 범위·기간·위반 시 제재 |
| 하도급 | 재하도급 금지·승인 절차 |
| 해지 | 발주처 일방 해지 조건 |
| 보험 | 의무 가입 보험·한도 |
| 보증금 | 입찰·계약·하자 보증금 비율 |

### 3-3. 독소 조항 매칭
risk-patterns.md의 패턴 라이브러리와 자동 매칭하여 등급 부여.

| 등급 | 정의 | 대응 |
|------|------|------|
| 상 (Critical) | 응찰 자체를 재검토할 수준 | NO-GO 권고 또는 협상 필수 |
| 중 (High) | 가격에 리스크 프리미엄 반영 필요 | 입찰가 +5~10% |
| 하 (Low) | 일반적 수준 | 정상 진행 |

## 4. 경쟁 (Competition)

### 4-1. 핵심 질문
"누가 응찰할 것인가? 우리의 차별화 포인트는?"

### 4-2. 추정 데이터

| 분류 | 추출 방법 |
|------|----------|
| 응찰 자격 제한 | 매출액·실적·자격증 등 진입 장벽 |
| 예상 경쟁사 풀 | 자격 충족 가능 PCO 추정 |
| 발주처 과거 수주 | 동일 발주처 과거 행사 수행사 |
| 우리 강점 | 유사 실적·차별 역량·단가 경쟁력 |
| 우리 약점 | 자격 미달·실적 부족·내부 자원 한계 |

### 4-3. 한국 MICE 주요 PCO 풀 (참조)
대형 종합 PCO: 4~6개사 (연 매출 300억 이상, 전국 행사 수행 역량)
중형 PCO: 8~12개사 (특정 영역 전문화, 컨벤션·전시·기업행사 중 1~2개 영역 집중)
컨벤션 특화 PCO: 학회·정부 컨퍼런스 중심 3~5개사
전시 특화 PCO: 전시 컨벤션 시설 자회사군 (코엑스·엑스코·벡스코 등)
→ 발주처 행사 성격·예산 규모·지역에 따라 응찰 가능 풀이 달라짐. 실제 응찰사 명단은 발주처 과거 수주 이력·업계 동향 조사로 추정.

### 4-4. 차별 포인트 도출
우리 강점 × 발주처 평가 가중치 = 핵심 메시지 후보. 가중치 높은 항목에서 우리 강점이 우위인 영역에 제안서 자원 집중.

## 5. 일정 (Timeline)

### 5-1. 핵심 질문
"시간이 충분한가? 어느 단계에서 압박이 큰가?"

### 5-2. 추출 항목

| 단계 | 산출 데이터 |
|------|------------|
| 공고일 | RFP 공고 시점 |
| 질의 마감 | 발주처 질의 응답 마감 |
| 제안서 마감 | 응찰 제출 마감 (D-Day 기준) |
| 발표 | 프레젠테이션 일정 |
| 우선협상 | 우선협상자 선정 |
| 계약 | 계약 체결 시점 |
| 행사일 | 본 행사 개최일 |
| 정산 | 최종 정산 시점 |

### 5-3. 압박 강도 산정

| 단계 간 간격 | 강도 |
|--------------|------|
| 공고 → 제안 마감 7일 이내 | 상 (의도된 단가 입찰 가능성) |
| 공고 → 제안 마감 14일 이내 | 중 (제안서 품질 압박) |
| 공고 → 제안 마감 21일 이상 | 하 (정상) |
| 계약 → 행사일 30일 이내 | 상 (운영 리스크) |
| 계약 → 행사일 90일 이상 | 하 (정상) |

→ 강도 "상" 단계가 2개 이상이면 7축 종합에서 -10점 권고.

## 6. 예산 (Budget)

### 6-1. 핵심 질문
"발주가는 적정한가? 우리 입찰가는 얼마여야 하는가?"

### 6-2. 추출 항목

| 분류 | 데이터 |
|------|--------|
| 발주가 (총사업비) | RFP 명시 금액 |
| 추정 원가 | 우리 측 자체 산정 |
| 마진율 | (발주가 - 원가) / 발주가 |
| 부가세 별도 여부 | VAT 포함/별도 |
| 지급 일정 | 선급/중도/잔금 비율 |
| 추가 비용 | 보험·보증·세금 등 |

### 6-3. MICE 업계 표준 마진율 참조
- **일반 행사 운영**: 15~25%
- **전시·컨벤션 종합**: 10~18%
- **컨설팅·기획 단독**: 25~40%
- **단가 입찰 (가격경쟁)**: 5~12%

→ 추정 마진율이 표준 하단 미만이면 NO-GO 또는 가격 협상 권고.

### 6-4. 입찰가 권고 알고리즘
```
입찰가 권고 = 추정 원가 × (1 + 목표 마진율) × (1 + 리스크 프리미엄)
```
- 목표 마진율: 행사 유형별 표준 중간값
- 리스크 프리미엄: 3축 리스크 등급 합산 (상=10%, 중=5%, 하=0%)
- 평가 가격 가중치가 30% 미만이면 입찰가 -3~5% 조정 가능

## 7. 전략 권고 (Strategy)

### 7-1. 핵심 질문
"응찰할 것인가? 응찰한다면 핵심 메시지는?"

### 7-2. GO/NO-GO 점수화 알고리즘

각 축을 1~5점으로 평가 후 가중 합산:

| 축 | 가중치 | 1점 | 5점 |
|----|--------|-----|-----|
| 1. 요건 | 15% | 필수 요건 충족 50% 미만 | 필수 100% + 가산 50% 이상 |
| 2. 평가 | 20% | 우리 강점이 평가 가중치와 불일치 | 우리 강점이 평가 가중치 70% 이상 점유 |
| 3. 리스크 | 20% | 독소 조항 "상" 1개 이상 | 독소 조항 없음 |
| 4. 경쟁 | 15% | 강력한 단독 경쟁사 존재 | 차별 포인트 명확 |
| 5. 일정 | 10% | 압박 강도 "상" 단계 2개 이상 | 모든 단계 "하" |
| 6. 예산 | 15% | 추정 마진율 5% 미만 | 추정 마진율 25% 이상 |
| 7. 종합 | 5% | 전략적 가치 낮음 | Track A/B 양쪽에 가치 |

### 7-3. 종합 점수 → 권고

| 종합 점수 | 판정 | 색상 | 권고 |
|-----------|------|------|------|
| 4.0 ~ 5.0 | **GO** | Neon Green | 즉시 응찰, 자원 집중 투입 |
| 3.0 ~ 3.9 | **GO (조건부)** | Neon Green | 응찰하되 리스크 영역 보완 |
| 2.0 ~ 2.9 | **HOLD** | Orange | 발주처 질의·협상으로 조건 개선 후 재판단 |
| 1.0 ~ 1.9 | **NO-GO** | Magenta | 응찰 보류, 리소스 다른 건에 집중 |

### 7-4. 핵심 메시지 도출 (GO인 경우)

```
핵심 메시지 = (4축 우리 강점 ∩ 2축 평가 가중치 상위) × (1축 필수 요건 100%)
```

- 평가 배점이 높은 항목 중 우리가 명확한 우위인 영역을 1~3개 핵심 메시지로 도출
- 제안서 표지·도입부·결론에 동일 메시지 일관 노출 권고

### 7-5. 승률 추정

승률은 **추정**임을 명시. 다음 4개 변수의 가중 평균으로 산정:

| 변수 | 가중치 |
|------|--------|
| 종합 점수 (7-3) | 40% |
| 우리 vs 예상 1위 경쟁사 차이 | 30% |
| 발주처 과거 수주 패턴 | 20% |
| 평가 방식 (절대/상대) 영향 | 10% |

→ 승률은 보고서에 "추정 승률 XX% (참고용, 실제 결과와 다를 수 있음)"으로 명시.
