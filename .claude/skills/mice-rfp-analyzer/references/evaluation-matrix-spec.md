# Evaluation Matrix Spec — .xlsx 평가 매트릭스 스키마

mice-rfp-analyzer가 생성하는 .xlsx 파일의 시트 구조·컬럼·수식·서식 정의.

---

## 파일 사양

- **파일명**: `rfp-evaluation-matrix_[발주처]_[행사명]_[YYYYMMDD].xlsx`
- **시트 수**: 7개 (요건 / 평가 / 리스크 / 경쟁 / 일정 / 예산 / 종합)
- **인코딩**: UTF-8
- **글꼴**: 본문 Pretendard 10pt / 헤더 Pretendard SemiBold 11pt
- **색상**: jc-design-system signature 토큰 호출

---

## 시트 1. 표지 + 종합

### 시트명: `0_종합`

| 컬럼 | 내용 | 너비 |
|------|------|------|
| A | 항목 라벨 | 25 |
| B | 값 | 40 |
| C | 비고 | 30 |

### 행 구성

```
1행:  RFP 분석 평가 매트릭스 (병합 A1:C1, 헤더, 16pt Bold, Primary Navy 배경)
3행:  발주처              | [발주처명]
4행:  행사명              | [행사명]
5행:  분석 일자            | [YYYY-MM-DD]
6행:  분석자              | [작업자명]
8행:  ▼ 7축 종합 점수
9행:  1. 요건             | [점수]/5.0 | 가중치 15%
10행: 2. 평가             | [점수]/5.0 | 가중치 20%
11행: 3. 리스크           | [점수]/5.0 | 가중치 20%
12행: 4. 경쟁             | [점수]/5.0 | 가중치 15%
13행: 5. 일정             | [점수]/5.0 | 가중치 10%
14행: 6. 예산             | [점수]/5.0 | 가중치 15%
15행: 7. 종합 가치         | [점수]/5.0 | 가중치 5%
17행: ▶ 가중 평균 종합 점수 | =SUMPRODUCT(B9:B15, 가중치) | 자동 계산
18행: ▶ 판정              | =IF(B17>=4,"GO",IF(B17>=3,"GO 조건부",IF(B17>=2,"HOLD","NO-GO")))
19행: ▶ 추정 승률          | [XX%] | 참고용
21행: ▼ 핵심 메시지 (GO인 경우)
22행: 메시지 1
23행: 메시지 2
24행: 메시지 3
```

### 서식 규칙
- B18 셀 조건부 서식:
  - "GO" → 배경 #00E676 (Neon Green)
  - "GO 조건부" → 배경 #00E676 (Neon Green) 30% 투명도
  - "HOLD" → 배경 #FF5722 (Orange)
  - "NO-GO" → 배경 #E91E63 (Magenta), 글자 흰색

## 시트 2. 요건

### 시트명: `1_요건`

| 컬럼 | 내용 | 너비 |
|------|------|------|
| A | 분류 (필수/선택/가산) | 12 |
| B | 요건 항목 | 40 |
| C | 출처 (페이지·조항) | 18 |
| D | 우리 측 대응 (가능/조건부/불가) | 18 |
| E | 비고 | 30 |

### 데이터 행 시작: 3행
헤더 1~2행 병합·고정.

### 자동 집계 (시트 하단)
```
필수 요건 수      | =COUNTIF(A:A,"필수")
대응 가능        | =COUNTIFS(A:A,"필수",D:D,"가능")
충족률           | =대응가능/필수요건수
```

### 서식 규칙
- A열 조건부 서식:
  - "필수" → 배경 #E91E63 (Magenta), 글자 흰색
  - "선택" → 배경 #FF5722 (Orange)
  - "가산" → 배경 #00E676 (Neon Green)
- D열 조건부 서식:
  - "불가" + A열="필수" → 행 전체 빨강 강조 (실격 위험 경고)

## 시트 3. 평가

### 시트명: `2_평가`

| 컬럼 | 내용 | 너비 |
|------|------|------|
| A | 대분류 | 18 |
| B | 평가 항목 | 35 |
| C | 배점 | 10 |
| D | 가중치 (%) | 12 |
| E | 우리 예상 점수 | 14 |
| F | 환산 (E×배점/만점) | 14 |
| G | 우리 강점 여부 | 14 |
| H | 비고 | 25 |

### 자동 집계
```
총 만점          | =SUM(C:C)
우리 예상 총점    | =SUM(F:F)
강점 항목 비중    | =SUMIFS(C:C,G:G,"강점")/SUM(C:C)
```

### 서식 규칙
- G열 조건부 서식:
  - "강점" → 배경 #2962FF (Electric Blue), 글자 흰색
  - "약점" → 배경 #E91E63 (Magenta), 글자 흰색
  - "중립" → 배경 회색

## 시트 4. 리스크

### 시트명: `3_리스크`

| 컬럼 | 내용 | 너비 |
|------|------|------|
| A | 영역 (책임/배상/변경권/...) | 15 |
| B | 조항 원문 | 50 |
| C | 출처 (페이지·조항) | 18 |
| D | 등급 (상/중/하) | 12 |
| E | 영향 분석 | 30 |
| F | 대응 방안 | 30 |

### 서식 규칙
- D열 조건부 서식:
  - "상" → 배경 #E91E63 (Magenta), 글자 흰색
  - "중" → 배경 #FF5722 (Orange)
  - "하" → 배경 #00E676 (Neon Green) 50% 투명도

### 자동 집계
```
"상" 등급 수     | =COUNTIF(D:D,"상")
리스크 프리미엄  | =COUNTIF(D:D,"상")*10% + COUNTIF(D:D,"중")*5%
```

## 시트 6. 일정

### 시트명: `5_일정`

| 컬럼 | 내용 | 너비 |
|------|------|------|
| A | 단계 | 18 |
| B | 일자 | 14 |
| C | D-Day | 10 |
| D | 직전 단계와의 간격(일) | 18 |
| E | 압박 강도 (상/중/하) | 14 |
| F | 비고 | 25 |

### 자동 계산
```
C열 D-Day      | =B열 - TODAY()
D열 간격       | =B열 - 직전 행 B열
```

### 서식 규칙
- C열 조건부 서식:
  - 7일 이하 → 배경 #E91E63 Magenta
  - 14일 이하 → 배경 #FF5722 Orange
- E열 조건부 서식 동일 매핑

## 시트 7. 예산

### 시트명: `6_예산`

| 컬럼 | 내용 | 너비 |
|------|------|------|
| A | 항목 | 25 |
| B | 금액 (원) | 18 |
| C | 비고 | 35 |

### 행 구성
```
1행: 발주가 (총사업비)         | [금액]
2행: 부가세 (별도/포함)        | [금액 또는 별도 표기]
3행: 추정 원가                | [금액]
4행: 추정 마진                | =B1-B3
5행: 추정 마진율              | =B4/B1
6행: MICE 업계 표준 마진율    | [참조 값]
7행: 표준 대비 차이            | =B5-B6
9행: ▼ 입찰가 권고 시뮬레이션
10행: 목표 마진율             | [%]
11행: 리스크 프리미엄          | =리스크시트!리스크프리미엄
12행: 입찰가 권고             | =B3*(1+B10)*(1+B11)
13행: 발주가 대비              | =B12/B1
```

### 서식 규칙
- B5 조건부 서식:
  - 5% 미만 → 배경 #E91E63 Magenta
  - 5~15% → 배경 #FF5722 Orange
  - 15% 이상 → 배경 #00E676 Neon Green

## 공통 서식 토큰 (jc-design-system 호출)

```python
# build_matrix.py 에서 사용할 컬러 상수
COLOR_PRIMARY     = "0A2540"  # Deep Navy
COLOR_ACCENT      = "2962FF"  # Electric Blue
COLOR_NEON        = "00E676"  # Neon Green (GO)
COLOR_ORANGE      = "FF5722"  # Orange (HOLD)
COLOR_MAGENTA     = "E91E63"  # Magenta (NO-GO/리스크 상)
COLOR_LIGHT_GRAY  = "F5F5F5"  # 헤더 배경
COLOR_DARK_GRAY   = "333333"  # 본문 텍스트
```

## 헤더 행 표준 서식
- 배경: COLOR_PRIMARY
- 글자: 흰색 (#FFFFFF)
- 글꼴: Pretendard SemiBold 11pt
- 가운데 정렬
- 행 높이: 28pt
- 셀 테두리: 흰색 1pt

## 데이터 행 표준 서식
- 배경: 짝수 행 #F8F9FB / 홀수 행 흰색
- 글자: COLOR_DARK_GRAY
- 글꼴: Pretendard 10pt
- 셀 테두리: #E0E0E0 0.5pt
- 행 높이: 22pt
