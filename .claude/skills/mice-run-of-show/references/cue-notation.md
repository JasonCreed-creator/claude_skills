# 연출·AV·조명 표준 표기

큐시트의 Audio/Video/Light/연출 cue 컬럼은 **자유 서술이 아니라 표준 약어**로 적는다. 쇼콜러가 어두운 콘솔 앞에서 0.5초 안에 판독해야 하기 때문이다.

---

## 1. 기본 약어

| 분류 | 약어 | 의미 | 예 |
|------|------|------|-----|
| 조명 | `LX` | Lighting cue + 번호 | `LX1`, `LX2.5` |
| 조명 | `하우스` / `암전` / `스팟` / `무대FULL` | 상태 | `암전→스팟` |
| 음향 | `MIC#` | 마이크 채널 | `MIC1`(핸드), `MIC2`(핀) |
| 음향 | `SQ` | Sound cue(효과·시그널) + 번호 | `SQ3 등장음` |
| 음향 | `BGM` / `FADE` / `CUT` | 배경음·페이드·정지 | `BGM FADE OUT` |
| 영상 | `VT#` | Video Tape/클립 + 번호 | `VT1 인트로` |
| 영상 | `LED` / `중계` / `PIP` / `로비루프` | 스크린 상태 | `LED→발표 PPT` |
| 무대 | `SB` | Standby(대기) | `SB 다음 연사` |
| 무대 | `FOH` / `백스테이지` | 위치 | — |
| 전환 | `→` | 전환 트리거 | `VT1→발표 전환` |
| 동시 | `+` | 동시 발생 | `암전 + SQ3` |

---

## 2. 연출 cue 작성 패턴

연출 cue 컬럼은 **트리거 → 결과** 형식을 권장한다.

```
<트리거> → <결과>            예: "사회자 멘트 끝 → VT1 + 암전"
<상태 변경>                  예: "LED 발표모드 전환"
SB <대상>                    예: "SB 기조연사 백스테이지"
```

- 한 셀에 cue가 여럿이면 `;`로 구분: `LX2; SQ3; VT2`.
- 시간 트리거가 있으면 비고에: "(T-30초 SB)".

---

## 3. 큐콜 범례(deep 모드 — 시트에 동봉)

deep 모드는 큐시트 하단/별도 영역에 약어 범례를 자동 첨부해 신규 스태프도 판독 가능하게 한다.

```
[범례] LX 조명 · MIC 마이크 · SQ 음향효과 · BGM 배경음 · VT 영상클립
       LED 스크린 · SB 대기 · → 전환 · + 동시 · ; 복수 cue
```

---

## 4. 표기 검수 체크 (루브릭 '표기 표준' 항목)

- [ ] 조명/음향/영상 cue가 분류 약어로 시작하는가 (자유문장 금지)
- [ ] 전환은 `→`, 동시는 `+`, 복수는 `;`로 통일됐는가
- [ ] 마이크·VT·LX에 **번호**가 있는가(추적 가능)
- [ ] deep 모드에 범례가 동봉됐는가
- [ ] 약어가 행사 전체에서 일관(같은 의미에 같은 약어)된가

---

## 5. 안티패턴 연결

- ❌ "조명 어둡게 하고 영상 틀기" (자유 서술 — 콘솔에서 판독 불가)
- ✅ `암전 + VT1` / 연출 cue: `멘트 끝 → 암전 + VT1`

자세한 함정은 `anti-patterns.md` 참조.
