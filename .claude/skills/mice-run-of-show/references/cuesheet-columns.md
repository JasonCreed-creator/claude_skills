# 큐시트 10컬럼 작성 규약

`[큐시트]` 시트의 표준 10컬럼. 순서·의미를 고정한다(쇼콜러가 어느 행사든 같은 위치에서 같은 정보를 찾도록).

---

## 컬럼 정의

| # | 컬럼 | 키 | 내용 | 작성 규칙 |
|---|------|-----|------|----------|
| 1 | **Cue#** | (자동) | 큐 식별자 | `C01`, `C02`… 2자리 0패딩, 연속. 자동 생성 |
| 2 | **시간** | (자동) | 클록 시작 시각 | `HH:MM`. 시작시각+누적 소요로 **자동 산출**(수기 금지) |
| 3 | **세그먼트** | `segment` | 프로그램 단위 | 명사형(등록·입장 / 개회 / 기조연설 / 휴식 …) |
| 4 | **무대·발표** | `stage` | 무대 위 주체·콘텐츠 | 발표자 역할·세션명. 없으면 `-` |
| 5 | **Audio** | `audio` | 음향 cue | `cue-notation.md` 약어 (MIC#·BGM·SQ#…) |
| 6 | **Video** | `video` | 영상 cue | VT#·LED·중계·로비루프 등 |
| 7 | **Light** | `light` | 조명 cue | LX#·하우스·무대FULL·스팟 등 |
| 8 | **연출 cue** | `cue` | 연출 콜(전환·트리거) | 표준 표기. 예 `VT1→발표전환`, `암전→스팟` |
| 9 | **Owner** | `owner` | 책임자 | 역할명(운영/사회/기술/무대감독…). **실명·소속사 금지** |
| 10 | **비고** | `note` | 부가 메모 | 소요·주의·예비 안내 등 자유 |

> 입력에는 **소요(분) `duration_min`** 이 필요하다(시간 무결성·클록 산출용). 단, 표에는 별도 소요 컬럼을 두지 않고 `시간`(클록)으로 표현한다 — 다음 행의 시간이 이전 큐의 종료를 알려준다.

---

## 입력 cue 객체 스키마

```python
{
  "segment": "개회·환영사",     # 필수
  "duration_min": 10,           # 필수 (정수 분, >0)
  "stage": "사회자",            # 없으면 "-"
  "audio": "MIC1",
  "video": "인트로 VT",
  "light": "무대 FULL",
  "cue": "VT1→발표 전환",
  "owner": "사회",              # 역할명
  "note": "2분 내 정시 시작"
}
```

- 필수: `segment`, `duration_min`. 나머지는 비면 빈칸/`-`.
- `duration_min`은 **양의 정수**. 0·음수는 빌드 반려(시간 무결성).

---

## 클록·시간 무결성 규칙

1. **클록 산출**: `clock[0] = start_time`, `clock[i] = clock[i-1] + duration_min[i-1]`.
2. **총합 검증**: `start_time + Σ duration_min == end_time`(end_time 제공 시). 불일치는 Critical(빌드 경고/반려).
3. **단조 증가**: 클록은 항상 증가. (durations가 양수면 자동 보장 — 검증으로 재확인)
4. **표시**: 시간 셀은 `HH:MM`. 24시 넘김(자정 교차) 행사는 `+1d HH:MM`로 표기.

---

## 행 그룹·구분

- **세그먼트 경계**: 큰 블록(오전/오후, 1부/2부) 사이에 구분 행(병합·중립 배경) 삽입 가능.
- **휴식/전환**: 휴식도 하나의 cue로 행을 차지한다(시간 누락 방지).
- **헤더 블록**: 시트 상단에 행사명·일자·베뉴·버전·생성시각 + 컬럼 헤더(2행 고정).
