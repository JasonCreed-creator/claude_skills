## 1. 월요일 / 오늘 브리프

### 수집 (기본 범위: 지난 금요일 09:00 이후, 또는 "지난 24시간")
1. `slack_search_public_and_private` `after:YYYY-MM-DD` — 사용자 본인 멘션·`@MICE비즈팀` · 키워드(견적·계약완료·킥오프·결과보고·정산·법인폰·통신비 등 사용자가 준 주제).
2. `slack_read_channel` — `#mice_운영요청`(최상위 + 갱신된 스레드), `#mice-biz-team`(근공 스레드·트래커 알림), `#마켓데이터사업실_leader`(팀장 공지).
3. 갱신된 행사 스레드는 `slack_read_thread`로 마지막 5~10개 댓글만. 상태 보드 댓글이 있으면 그것을 기준으로.
4. DM은 사용자가 지정한 상대만.

### 분류
| 구분 | 기준 |
|------|------|
| 🔴 오늘 처리 | 기한이 오늘·지났음, 고객·팀장 회신 대기, 긴급 봇 |
| 🟠 이번 주 | 기한 5영업일 내, 위클리 안건, 견적 회신 약속 기한 |
| ⚪ 대기·관찰 | 타팀 응답 대기, 결정 대기(누가) |
| ℹ️ 정보 | 공지·룰 변경·참고 |

### 출력 형식
```
📋 월요일 브리프 (9/22 기준 · 수집 범위 9/19 09:00~)
🔴 오늘
- [행사 ID] 무엇을 · 누구에게 · 기한 · 링크
🟠 이번 주
- …
⚪ 대기
- … (누구 응답 대기 · 언제부터)
ℹ️ 정보
- …
```

- 항목당 1줄, 링크는 Slack permalink. 추측하지 않는다 — 기한이 메시지에 없으면 "(기한 미기재)".
- 사용자가 "법인폰 관련 내용 정리"처럼 주제를 좁히면 해당 스레드·공지만 시간순으로 요약하고 결론·미결·담당을 끝에 붙인다.

## 2. 위클리 회의 준비 (월 10:00 · 먼슬리 있는 주는 위클리 패스)

1. 오픈 건 목록: `#mice_운영요청` 최상위(견적문의) 게시물 전수 → 상태 보드 단계 읽기 → 표(행사 ID · 단계 · 담당 · 다음 액션 · 기한).
2. 「MICE 오픈 건 현황」 채널 캔버스 갱신 초안(매주 월요일) — `canvas-rules.md`.
3. 상태 보드 최신화가 필요한 스레드(최종 수정 7일 초과) 목록.
4. 결정 필요 항목(팀장) · 팀 공유 사항(근공·휴가·외근) · 주간 3P(`comms-templates.md §2`).

## 3. 슬랙 요약 ("오늘 내가 슬랙으로 대화한 내용", "내가 보낸 메시지")

1. 범위 확정: 기간 + 채널/DM + 대상(`from:@나` 또는 전체).
2. 수집 → 스레드별로 묶기 → 각 스레드: 주제 · 결론/결정 · 내 액션 · 상대 액션 · 미결.
3. 출력: 스레드 순서는 최신 활동순. 결정은 `[결정]`, 내 할 일은 굵게. 링크 첨부.
4. 민감 발언(개인 평가·금액·마진)은 기본 마스킹하고 그렇게 했다고 한 줄로 밝힌다(원문이 필요하면 사용자가 해제).

## 4. 근공 스레드 (팀 내부, 매주 월 09:00 자동)

재택·휴가·외근·현장은 근공 스레드 댓글로 공유. 브리프에는 "이번 주 팀 가용" 한 줄로 반영(누가 언제 현장·휴가).

## 5. 회의록 DM·파일 공유 요청

"OOO이 공유한 A사 회의록 DM으로 보내줘" 류: `slack_search_public_and_private`로 파일·메시지 찾기 → permalink 확인 → 사용자에게 DM 초안(링크 + 한 줄) 보여주고 승인 후 발송. 파일 자체 재업로드는 하지 않는다(권한·중복).
