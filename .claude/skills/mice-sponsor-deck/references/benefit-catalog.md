# Benefit Catalog — 7카테고리 표준 혜택 사전

스폰서 데크의 핵심 자산. 모든 혜택은 다음 7카테고리에 매핑된다.

---

## 카테고리 개요

| # | 카테고리 (KO) | 카테고리 (EN) | 핵심 가치 |
|---|--------------|---------------|----------|
| 1 | 브랜딩 노출 | Brand Exposure | 오프라인 시각 노출 |
| 2 | 미디어 노출 | Media Coverage | 외부 매체·SNS 확산 |
| 3 | 디지털 자산 | Digital Assets | 온라인 채널 노출 |
| 4 | 부스·공간 | Booth & Space | 직접 체험·인터랙션 |
| 5 | 연사·세션 권리 | Speaking Rights | 콘텐츠 리더십 |
| 6 | 리드·CRM | Leads & CRM | 영업 데이터 확보 |
| 7 | VIP·네트워킹 | VIP Networking | 의사결정자 직접 접점 |

각 카테고리는 다수의 표준 혜택 항목으로 구성된다. 행사가 보유한 자산에 맞춰 발췌·매핑한다.

---

## 1. 브랜딩 노출 (Brand Exposure)

오프라인 시각 노출. 행사 현장에서 스폰서 로고·CI가 노출되는 모든 슬롯.

### 1.1 표준 혜택 항목

| 항목 | 정량화 단위 | 우선 적용 Tier |
|------|------------|---------------|
| 메인 무대 백드롭 로고 | 위치(상단 단독/병기) × 시간 | T1, T2 |
| 메인 사이니지 | 위치 × 노출 횟수 | T1, T2, T3 |
| 행사장 입구 아치 | 단독/공동 | T1 |
| 셔틀버스·차량 래핑 | 차량 수 | T1, T2 |
| 행사 명찰(뱃지) 로고 | 위치 | T1, T2 |
| 프로그램북 표지 | 단독/공동 | T1, T2 |
| 프로그램북 내지 광고 | 페이지 수·위치 | T2~T5 |
| 안내 데스크·등록대 사이니지 | 위치 | T2, T3 |
| 행사장 내부 사이니지 | 위치·수량 | T3, T4 |
| 식음료 테이블 미니 사이니지 | 수량 | T4, T5 |
| 노벨티·기념품 패키징 | 단독/공동 | T2, T3 |

### 1.2 정량화 표현 룰

매트릭스에 들어갈 때는 단순 ✓가 아니라 **정량 표기**로 전환.

```
❌ 메인 사이니지: ✓
✓ 메인 사이니지: 8회 (1F 입구 / 메인홀 좌우 / 등록대 / VIP 라운지 / 식당 / 화장실 안내)
```

### 1.3 Tier 차별화 핵심 룰

- **메인 무대 백드롭**과 **행사장 입구 아치**는 T1 단독 혜택 (스폰서 영업의 가장 강력한 무기)
- T2 이하는 메인 사이니지 위치·수량 차이로 차별화
- T5는 "기본 노출" 수준 (프로그램북 내지 등)

## 2. 미디어 노출 (Media Coverage)

외부 매체·SNS 확산. 행사 외부로 스폰서 노출이 확산되는 채널.

### 2.1 표준 혜택 항목

| 항목 | 정량화 단위 | 우선 적용 Tier |
|------|------------|---------------|
| 보도자료 본문 명시 | 노출 차수(메인/공동/일반) | T1, T2, T3 |
| 기자간담회 참여권 | 발언/배석 | T1 |
| 행사 후 사후 보도자료 | 명시 여부 | T1, T2 |
| 행사 영상 인트로 로고 | 위치(첫 화면/엔딩) | T1, T2 |
| 공식 SNS 단독 포스트 | 게시 횟수 | T1, T2 |
| 공식 SNS 공동 포스트 | 게시 횟수 | T3, T4 |
| 행사 후기 영상 출연 | 분량 | T1, T2 |
| 인플루언서 협업 콘텐츠 | 횟수 (행사 따라) | T1, T2 |
| 미디어 파트너 매체 노출 | 매체 수 | T1, T2, T3 |
| 행사 뉴스레터 헤드라인 | 호수 | T1, T2 |

### 2.2 보도자료 표기 룰

- T1: "주관: [행사명] (Title Sponsor [브랜드])"
- T2: "[행사명] (Platinum Sponsor [브랜드])"
- T3: 본문 첫 문단에 명시
- T4~T5: 부록 협찬사 리스트에 포함

### 2.3 미디어 가치 환산 (옵션)

ROI 케이스에서 미디어 노출은 PR 가치 환산 가능:

```
보도자료 메인 명시 (5개 매체) × 평균 PR 가치 KRW 5,000,000
= KRW 25,000,000 상당
```

(`roi-case-templates.md` 와 연동)

## 3. 디지털 자산 (Digital Assets)

온라인 채널 노출. 행사 디지털 자산을 통한 스폰서 노출.

### 3.1 표준 혜택 항목

| 항목 | 정량화 단위 | 우선 적용 Tier |
|------|------------|---------------|
| 행사 공식 홈페이지 메인 배너 | 위치(상단 단독/병기) | T1 |
| 홈페이지 스폰서 섹션 로고 | 노출 크기 | T1~T5 |
| 행사 앱 스플래시 로고 | 단독/공동 | T1, T2 |
| 행사 앱 푸시 알림 스폰서 | 횟수 | T1, T2 |
| 행사 이메일 헤더 로고 | 발송 횟수 | T1, T2 |
| 행사 이메일 본문 광고 | 발송 횟수 | T2, T3 |
| 행사 LIVE 스트리밍 인트로 | 위치 | T1, T2 |
| 행사 LIVE 사이드 배너 | 노출 시간 | T1, T2, T3 |
| 디지털 사이니지 (행사장) | 노출 횟수·시간 | T2, T3 |
| 행사 메타버스/가상 부스 | 평수·위치 | T1, T2, T3 |

### 3.2 정량화 정책

디지털 자산은 **노출 횟수 × 도달 추정**으로 정량화. 출처 명시 의무.

```
이메일 헤더 로고: 사전 안내 3회 + 사후 안내 1회 = 총 4회
└ 발송 대상 약 28,000명 (2024년 회차 기준)
└ 추정 노출: 4 × 28,000 = 112,000회
```

### 3.3 데이터 추적 권장

홈페이지·앱 노출은 클릭 트래킹 (Google Analytics 또는 자체 트래커) 가능. 사후 보고에 활용.

## 4. 부스·공간 (Booth & Space)

직접 체험·인터랙션. 참가자가 스폰서 부스에서 직접 경험하는 자산.

### 4.1 표준 혜택 항목

| 항목 | 정량화 단위 | 우선 적용 Tier |
|------|------------|---------------|
| 프리미엄 부스 (메인 동선) | 평수·위치 | T1, T2 |
| 표준 부스 | 평수 | T3 |
| 컴팩트 부스 | 평수 | T4 |
| 부스 위치 우선 선택권 | 우선순위 | T1, T2 |
| VIP 라운지 운영권 | 단독/공동 | T1 |
| 체험존·POP-UP 구역 | 평수 | T1, T2 |
| 자판기·전시품 노출 | 위치·수량 | T2, T3 |
| 식음료 부스 운영권 | 단독/공동 | T2, T3 |
| 등록대 옆 광고 부스 | 위치 | T2 |
| 휴게 공간 스폰서 | 단독 | T2, T3 |

### 4.2 부스 평수 표준 (전시회 기준)

| Tier | 부스 평수 권장 | 위치 |
|------|---------------|------|
| T1 | 36~54㎡ | 메인 동선 정중앙 또는 입구 |
| T2 | 27~36㎡ | 메인 동선 |
| T3 | 18~27㎡ | 표준 동선 |
| T4 | 9~18㎡ | 일반 동선 |
| T5 | 부스 미제공 또는 공동 부스 | — |

### 4.3 위치 우선 선택권

T1~T2는 부스 위치를 우선 선택할 수 있다. 메인 동선·입구 정면 등 노출 최우위 위치 확보.

## 5. 연사·세션 권리 (Speaking Rights)

콘텐츠 리더십. 스폰서가 행사 콘텐츠에 직접 참여하는 권리.

### 5.1 표준 혜택 항목

| 항목 | 정량화 단위 | 우선 적용 Tier |
|------|------------|---------------|
| 키노트 발표 슬롯 | 분량 (분) | T1 |
| 메인 세션 스폰서 | 세션 수 | T1, T2 |
| 트랙 세션 스폰서 | 세션 수 | T2, T3 |
| 패널 토론 패널 1석 | 세션 수 | T1, T2 |
| 워크숍·라운드테이블 호스트 | 세션 수 | T2, T3 |
| 개회식·폐회식 인사말 | 시간 | T1 |
| MC 멘트 노출 | 노출 횟수 | T1, T2, T3 |
| 사회자 인트로 멘트 | 횟수 | T2, T3 |

### 5.2 세션 시간 권장

- 키노트 (T1): 20~30분
- 메인 세션 (T1~T2): 40~60분
- 트랙 세션 (T2~T3): 30~45분
- 패널 토론: 1석 × 60~90분 패널

### 5.3 콘텐츠 가이드라인

스폰서 세션은 **광고가 아닌 인사이트 콘텐츠**여야 한다. 행사 사무국 콘텐츠 가이드라인 사전 협의 의무.

```
✓ 산업 트렌드·기술 인사이트·고객 사례
❌ 자사 제품 직접 홍보 (광고성 콘텐츠)
```

## 6. 리드·CRM (Leads & CRM)

영업 데이터 확보. 스폰서가 행사 후 영업 활동에 직접 활용 가능한 데이터.

### 6.1 표준 혜택 항목

| 항목 | 정량화 단위 | 우선 적용 Tier |
|------|------------|---------------|
| 부스 방문자 명함 데이터 | 건수 | T1, T2, T3, T4 |
| QR 스캔 리드 | 건수 | T1, T2, T3 |
| 사전 등록자 마케팅 동의 데이터 | 건수 | T1 |
| B2B 매칭 미팅 (1:1) | 미팅 수 | T1, T2, T3 |
| 행사 앱 메시징 권한 | 메시지 수 | T1, T2 |
| 사후 참가자 설문 결과 | 설문 항목 수 | T1, T2 |
| 데이터 파트너 매칭 리포트 | 리포트 1건 | T1 |
| 마케팅 자동화 연동 | 연동 채널 수 | T1, T2 |

### 6.2 개인정보 처리 룰 (필수)

리드·CRM 혜택은 개인정보보호법(PIPA) 준수가 필수. 다음 룰을 데크에 명시:

```
ⓘ 모든 참가자 데이터 제공은 마케팅 활용 동의를 받은 데이터에 한합니다.
   행사 사무국이 PIPA 준수 절차를 보증합니다.
```

### 6.3 데이터 정량화 추정

```
부스 방문자 명함 데이터:
└ T1 평균 800~1,200건 (메인 동선 부스)
└ T2 평균 500~800건
└ T3 평균 300~500건
└ T4 평균 150~300건
※ 실 수치는 행사 규모·부스 위치·체험 매력도에 따라 변동
```

## 7. VIP·네트워킹 (VIP Networking)

의사결정자 직접 접점. 일반 참가자가 접근할 수 없는 고가치 네트워킹 기회.

### 7.1 표준 혜택 항목

| 항목 | 정량화 단위 | 우선 적용 Tier |
|------|------------|---------------|
| VIP 만찬 단독 호스트 | 단독 권한 | T1 |
| VIP 만찬 참석 좌석 | 좌석 수 | T1, T2 |
| 임원 라운지 단독 운영권 | 단독 | T1 |
| 임원 라운지 출입권 | 출입자 수 | T1, T2 |
| 바이어 미팅 1:1 매칭 | 미팅 수 | T1, T2, T3 |
| 사전 임원 라운드테이블 | 참석 권한 | T1 |
| 키노트 연사 사전 미팅 | 미팅 수 | T1 |
| VIP 의전·픽업 서비스 | 서비스 수 | T1 |
| 골프·문화 행사 패키지 (옵션) | 동반 인원 | T1 |

### 7.2 좌석 수 권장

- T1: VIP 만찬 8~10석 단독 테이블
- T2: VIP 만찬 4~6석
- T3: 임원 라운지 출입권만

### 7.3 미팅 매칭 룰

```
바이어 매칭 미팅:
└ 사전 매칭 폼 작성 → 사무국 큐레이션 → 1:1 미팅 슬롯 배정
└ T1: 10미팅 × 30분
└ T2: 6미팅 × 30분
└ T3: 3미팅 × 30분
```

## 매트릭스 표현 룰

Tier × 7카테고리 매트릭스 작성 시 다음 3가지 표기로 통일.

| 표기 | 의미 |
|------|------|
| 정량 (예: "8회", "30석", "5명") | 정량화 가능한 혜택 |
| ✓ | 제공 (수량 무관) |
| — | 미제공 |

### 매트릭스 시각화 가이드

```

─────────────────────────────────────────────────────────

미디어      보도자료  보도자료    SNS공동    SNS언급    —
            메인명시  공동명시
디지털      홈페이지  홈페이지    홈페이지    —          —
            상단단독  상단병기    스폰서섹션

            30분      45분       30분
리드        1,000건   600건      400건       200건       —

```

## 행사 유형별 카테고리 우선순위

행사 성격에 따라 어떤 카테고리가 핵심인지 다르다.

| 행사 유형 | 1순위 | 2순위 | 3순위 |
|----------|------|------|------|
| 전시회·박람회 | 부스·공간 | 브랜딩 노출 | 리드·CRM |
| 컨퍼런스·포럼 | 연사·세션 | VIP·네트워킹 | 브랜딩 |
| 기업 행사 | 브랜딩 | VIP·네트워킹 | 미디어 |
| 페스티벌 | 브랜딩 | 미디어 | 디지털 |
| 시상식·갈라 | VIP·네트워킹 | 브랜딩 | 미디어 |

데크 작성 시 행사 유형의 1~2순위 카테고리를 슬라이드 상단에 배치한다.
