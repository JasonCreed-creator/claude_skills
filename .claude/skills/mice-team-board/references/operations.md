# 보드 운영 절차

---

## 1. 계약완료 → 등록·갱신

1. `mice-slack-ops`가 계약완료 메시지를 파싱해 `contract` 페이로드와 `action`(`new | update`)·`matched_row`를 낸다.
2. `python scripts/board_rows.py payload.json` → 프로젝트 탭 행 값 표(TSV) 확인.
3. 사용자에게 행 값 표를 보여주고 승인을 받는다.
4. 입력: PC 세션은 `chrome-ext-recipes.md` 셀 입력, 아니면 사용자가 붙여넣기(TSV는 시트에 그대로 붙는다).
5. 신규만: 메뉴 "프로젝트 ID 채우기" → "표준 마일스톤 생성" → 배정 탭 영업 3 M/D.
6. TSV를 `data/프로젝트_등록_YYYY-MM-DD.tsv`(또는 `_갱신_`)로 저장.

갱신일 때 바꾸는 열: B 행사명 · E 상태(`계약` 또는 유지) · L·M · N · O 비고(누적). A·P와 다른 탭은 그대로.

### DMS·주최형(③)

자체 행사 1행에 파트너별 계약이 쌓인다. N = 파트너 계약 합계, 파트너별 메시지는 O 비고에 누적.

## 2. 상태 전이

| 지금 | 다음 | 조건 |
|------|------|------|
| 견적 | 계약 | 계약완료 메시지 |
| 계약 | 준비 | MICE PM 배정 · 킥오프 착수 |
| 준비 | 진행 | 행사 주간 진입 |
| 진행 | 완료 | 행사 종료 다음 날 |
| 완료 | 정산완료 | 정산 탭 마감 |
| (어디서든) | 드롭 | 사용자 지시. O 비고에 `드롭 M/D: 사유` |

역행(예: 진행 → 준비)은 일정 변경일 때만, 비고에 사유.

## 3. 표준 마일스톤

메뉴 "표준 마일스톤 생성"을 쓴다. 손으로 만들지 않는다. 세트 내용은 시트 실측 후 `sheet-schema.md §3`에 기록.

## 4. 배정 M/D

- 영업 3 M/D 기본. MICE PM·운영 인력은 배정 확정 시 사용자 지시대로.
- 가동률 = 기간 내 배정 M/D 합 ÷ 가용 M/D. 히트맵 색 규칙은 `jc-design-system/references/component-patterns.md §6`(over orange · ok green · warn amber).

## 5. 현황 질의 (읽기 전용)

| 질문 | 읽는 곳 | 답 형식 |
|------|---------|---------|
| 이번 달 행사 | 프로젝트 F열 · E열 | 날짜순 표(ID·행사명·발주처·상태) |
| 누가 바쁜가 | 배정 탭 | 사람별 M/D 합계 + 과부하 표시 |
| 미정산 | E = 완료 | 행사일 오래된 순 |
| 이번 분기 계약액 | E ∈ {계약~정산완료} · N | 합계 + 건수 |
