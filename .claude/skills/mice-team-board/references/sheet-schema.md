# 시트 구조 — 탭 · 열 · 메뉴

> "실측 필요" 표시는 2026-10-05 스킬 작성 시 보드 원본을 열어 확인하지 못한 항목이다. 첫 실사용 때 시트를 읽어 이 문서를 고치고 버전을 올린다(`jc-skill-forge` 모드 C).

---

## 1. 탭

| 탭 | 단위 | 용도 |
|----|------|------|
| 프로젝트 | 1행 = 1프로젝트(운영요청) | 기본 정보·상태·금액 |
| 배정 | 1행 = 1인 × 1프로젝트 × 역할 | M/D 배정, 가동률 집계 원천 |
| 마일스톤 | 1행 = 1마일스톤 | 표준 마일스톤 세트 + 완료일·담당 |
| 정산 | 1행 = 1정산 항목 | 정산 진행·마감 (열 구성 실측 필요) |

## 2. 프로젝트 탭 (A~P)

정본: `mice-slack-ops/references/contract-message.md §3`. 요약:

| 열 | 필드 | 형식 |
|----|------|------|
| A | 프로젝트ID | `P-YYYY-NNN`. 메뉴 "프로젝트 ID 채우기" 또는 수기 |
| B | 행사명 | 계약완료 `주제` |
| C | 발주처 | 고객사 |
| D | 유형 | ① 리멤버 MICE 솔루션(모객+운영) ② 일반 행사 ③ DMS·주최형 ④ 커스터마이즈 |
| E | 상태 | 견적 · 계약 · 준비 · 진행 · 완료 · 정산완료 · 드롭 |
| F~J | 일정 | F 행사일(KST). G~J 세부 일정 열 이름 실측 필요(설치일 등) |
| K | 베뉴 | 행사장소 |
| L | 게런티 | 목표 쇼업 수 |
| M | 예상 참가 | 별도 없으면 L과 동일 |
| N | 계약금액 | 원, VAT 별도, 숫자만 |
| O | 비고 | 결제 조건 · PO/계약서 형태 · 리드 수 · 타깃 요지 · 재계약ID · 아이템ID · 인입채널 · 운영 Cell |
| P | 등록일 | YYYY-MM-DD |

## 3. 배정 · 마일스톤 탭

- 배정 기본 행: 영업 담당 3 M/D(역할 = 영업). MICE PM은 배정 확정 후 추가.
- 마일스톤 첫 항목: "계약 체결" — 완료일 = 메시지 날짜(실제 체결일이 없으면), 담당 = 영업.
- 두 탭의 정확한 열 순서와 표준 마일스톤 전체 목록은 실측 필요. 메뉴 "표준 마일스톤 생성"이 만드는 세트를 그대로 따른다.

## 4. 커스텀 메뉴 (Apps Script)

| 메뉴 | 동작 |
|------|------|
| 프로젝트 ID 채우기 | A열 빈 칸에 다음 `P-YYYY-NNN` |
| 표준 마일스톤 생성 | 선택한 프로젝트의 표준 마일스톤 행 생성(신규 행에만) |

그 밖의 메뉴는 실측 필요.
