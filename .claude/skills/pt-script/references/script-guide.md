# 프레젠테이션 스크립트 작성 가이드

## 슬라이드 유형별 멘트 패턴

### 1. 표지 슬라이드

```
[비딩 PT]
안녕하십니까. [회사명] [직책] [이름]입니다.
오늘 [행사명] [업무 범위]에 대한 저희의 제안을 말씀드리겠습니다.
약 [N]분간 진행되며, 발표 후 질의응답 시간을 갖겠습니다.

[컨퍼런스]
안녕하십니까. [소속] [이름]입니다.
오늘 [발표 제목]이라는 주제로 말씀드리겠습니다.
[주제의 중요성을 한 문장으로 환기]

[MC/사회자]
안녕하십니까, [행사명]에 참석해 주신 여러분을 진심으로 환영합니다.
저는 오늘 행사를 진행할 [이름]입니다.
오늘 준비된 프로그램을 간략히 안내드리겠습니다.
```

### 2. 목차/아젠다 슬라이드

```
오늘 발표는 크게 [N]가지로 구성했습니다.
먼저 [첫 번째 주제]를 살펴보고,
이어서 [두 번째 주제]를 말씀드린 후,
마지막으로 [세 번째 주제]로 마무리하겠습니다.
```

### 3. 배경/현황 슬라이드

```
먼저 [주제]의 현재 상황을 짚어보겠습니다.
화면에 보시는 것처럼, [핵심 데이터/트렌드 설명].
특히 주목할 점은 [강조 포인트]입니다.
이는 [의미/시사점]을 보여주고 있습니다.
```

### 4. 핵심 제안/전략 슬라이드

```
[비딩 PT]
이러한 분석을 바탕으로, 저희가 제안드리는 핵심 전략은 [전략명]입니다.
[전략의 핵심 내용을 2~3문장으로 설명]
이 전략의 가장 큰 차별점은 [차별화 포인트]에 있습니다.
구체적으로 어떻게 실행할지 다음 슬라이드에서 말씀드리겠습니다.

[컨퍼런스]
여기서 제가 강조하고 싶은 점은 [핵심 메시지]입니다.
[데이터/사례로 뒷받침]
이것이 의미하는 바는 [인사이트/시사점]입니다.
```

### 5. 데이터/차트 슬라이드

```
화면의 [차트/표] 유형을 보시겠습니다.
[X축]은 [설명], [Y축]은 [설명]을 나타냅니다.
여기서 눈에 띄는 것은 [핵심 수치/트렌드]입니다.
이 수치가 의미하는 것은 [해석]이며,
[결론/시사점]이라고 할 수 있습니다.
```

### 6. 프로세스/타임라인 슬라이드

```
전체 [프로세스/일정]을 단계별로 정리했습니다.
[1단계]에서는 [내용], 기간은 [기간]입니다.
이어서 [2단계]로 넘어가면 [내용]을 진행합니다.
가장 중요한 마일스톤은 [핵심 일정]이며,
이 시점까지 [달성 목표]를 완료할 계획입니다.
```

### 7. 실적/레퍼런스 슬라이드

```
[비딩 PT]
저희의 관련 실적을 말씀드리겠습니다.
[유사 행사명]을 성공적으로 수행한 바 있으며,
이 행사에서 [성과 수치]를 달성했습니다.
특히 이번 [대상 행사]와 [유사점]이 있어,
축적된 노하우를 충분히 활용할 수 있습니다.
```

### 8. 마무리/감사 슬라이드

```
[비딩 PT]
이상으로 [회사명]의 제안 발표를 마치겠습니다.
저희는 [핵심 약속/차별점]으로
[행사명]의 성공적인 개최에 기여하겠습니다.
경청해 주셔서 감사합니다. 질의응답을 받겠습니다.

[컨퍼런스]
오늘 말씀드린 내용을 정리하면,
[핵심 메시지 1~2개 요약]입니다.
[향후 전망 또는 제언 한 문장]
감사합니다.

[MC/사회자]
이것으로 오늘 [행사명]의 모든 프로그램을 마무리하겠습니다.
참석해 주신 모든 분들께 다시 한번 감사드립니다.
안전하게 귀가하시기 바랍니다. 감사합니다.
```

## 전환 멘트 패턴

슬라이드 간 자연스러운 연결을 위한 전환 멘트:

### 순접 (논리적 흐름)
- "이어서 [다음 주제]를 살펴보겠습니다."
- "이를 바탕으로 [다음 내용]을 말씀드리겠습니다."
- "그렇다면 구체적으로 어떻게 실행할 수 있을까요?"
- "이제 [다음 주제]로 넘어가겠습니다."

### 전환 (새로운 섹션)
- "지금까지 [이전 주제]를 살펴보았습니다. 이제 [새 주제]를 말씀드리겠습니다."
- "다음으로 중요한 부분인 [새 주제]입니다."
- "여기서 시각을 바꿔 [새 관점]에서 보겠습니다."

### 강조 전환
- "여기서 한 가지 꼭 짚고 넘어가야 할 부분이 있습니다."
- "특히 주목해 주실 부분은 다음입니다."
- "이 부분이 오늘 발표의 핵심입니다."

## Q&A 질문 유형별 가이드

### 비딩 PT 예상 질문 유형

| 유형 | 예시 질문 패턴 |
|------|---------------|
| 실행 가능성 | "[제안 내용]을 [기간] 안에 실제로 구현할 수 있는 근거는?" |
| 예산 적정성 | "[항목]의 단가 산출 근거를 설명해 주십시오" |
| 리스크 대응 | "[상황] 발생 시 대응 방안은?" |
| 차별화 | "타 업체와 비교했을 때 귀사만의 강점은?" |
| 실적 관련 | "[유사 행사]에서의 구체적인 성과 지표는?" |
| 인력 투입 | "핵심 인력의 전담 여부와 경력을 확인하고 싶습니다" |

### 컨퍼런스/포럼 예상 질문 유형

| 유형 | 예시 질문 패턴 |
|------|---------------|
| 심화 질문 | "[발표 내용]의 구체적인 방법론은?" |
| 반론 | "[주장]에 대한 반대 의견도 있는데, 어떻게 보시는지?" |
| 적용 가능성 | "이 사례가 [다른 분야/국내]에도 적용 가능한지?" |
| 데이터 출처 | "[데이터]의 출처와 신뢰성에 대해 설명해 주십시오" |
| 후속 연구 | "향후 이 주제에 대한 추가 연구 계획은?" |

### Q&A 답변 구조 (PREP)

```
[Point] 핵심 답변을 먼저 제시
  "네, [질문 핵심]에 대해 말씀드리겠습니다. [핵심 답변]."

[Reason] 이유/근거 설명
  "그 이유는 [근거 1], [근거 2] 때문입니다."

[Example] 구체적 사례/데이터
  "실제로 [사례/데이터]에서 확인할 수 있었습니다."

[Point] 핵심 메시지 재강조
  "따라서 [핵심 답변]이 적절하다고 판단합니다."
```

## 발표 팁 가이드

### 슬라이드 유형별 발표 팁

| 슬라이드 유형 | 발표 팁 |
|-------------|---------|
| 표지 | 첫 인상이 중요. 당당한 자세, 청중과 눈 맞춤. 원고를 보지 말 것 |
| 데이터/차트 | 레이저 포인터 또는 손으로 핵심 수치를 가리키며 설명 |
| 핵심 제안 | 속도를 약간 늦추고, 목소리 톤을 높여 강조 |
| 사례/레퍼런스 | 에피소드나 스토리를 곁들여 생동감 부여 |
| 마무리 | 마지막 핵심 메시지를 천천히, 명확하게 전달 |

### 공통 발표 팁

- **호흡**: 슬라이드 전환 시 1~2초 멈춤(pause)으로 청중 집중 유도
- **시선**: 원고 7 : 청중 3이 아닌, 청중 7 : 원고 3으로
- **속도**: 긴장 시 빨라지므로, 의식적으로 천천히
- **강조**: 핵심 키워드 앞에서 잠시 멈추고 또렷하게 발음
- **제스처**: 숫자를 말할 때 손가락으로 표현, 비교할 때 양손 활용
