# JC Asana HTML — 라이트 SaaS 프로덕티비티 룩 빌드 엔진

HTML 산출물에 **"정돈된 협업툴 화면"** 룩을 재현하는 전용 스킬이다. 화이트 캔버스 + 코랄 단일 액센트 + 파스텔 필 태그 + 체크서클 태스크 리스트 + 칸반 보드 + 상태 신호등. 여백이 기본값이고, 코랄은 행동 유도 지점에만 허락된다.

> 본 스킬이 이 룩의 **정본(SoT)** 이다. 토큰·컴포넌트 규격의 실행 정본은 `references/build-kit.md`.

## 핵심 원칙

1. **파생 테마 지위** — jc-design-system 시그니처(딥네이비·일렉트릭블루)를 수정하지 않는다. 산출물 단위 `:root` 오버라이드 레이어(`--al-*` 네임스페이스)로만 적용한다.
2. **컴포넌트가 룩이다** — 색만 코랄로 바꾸는 것은 본 룩이 아니다. 체크서클 리스트·필 태그·칸반·상태 도트·사이드바 도트 내비 중 산출물 성격에 맞는 문법을 반드시 함께 적용한다.
3. **라이트 기본 = 인쇄 호환** — 본 룩은 라이트가 정체성이라 `shared-rules.md#RULE-PRINT-LIGHT`에 자연 부합한다. PDF 배포 산출물에도 그대로 사용 가능(jc-cinematic-html과의 실용적 차별점).
4. **상표 자산 미포함** — Asana 로고·삼점 심볼·유니콘 등 셀레브레이션 캐릭터를 그리거나 삽입하지 않는다. 컴포넌트 문법과 색 감성만 재현한다(build-kit.md §7).
5. **식별정보 금지** — 클라이언트 실명·전용 컬러 하드코딩 금지(`shared-rules.md#RULE-NO-COMPANY`). 담당자명·회사명은 주입 변수다.
6. **팩트 규율** — 액센트 코랄 `#F06A6A`는 공개 브랜드 가이드 검증값(2026-07-31). UI 중립 톤·radius 등은 공개 미기재로 **재현 근사치**이며 build-kit에 `≈`로 표기되어 있다. 근사치를 "공식 값"으로 서술하지 않는다.

## 사용 시점

- **신규 빌드**: 본 룩의 회의록·전략지표·대시보드·리포트 HTML을 처음부터 제작
- **리스킨**: 기존 HTML 산출물에 본 룩 이식 (콘텐츠·차트 엔진 유지, 스킨 레이어 교체)
- **체이닝**: mice-meeting-minutes·mice-dashboard 등 콘텐츠 스킬 작업 중 사용자가 본 룩을 지정하면, 해당 스킬의 산출 구조 위에 본 스킬의 스킨 절차를 적용(콘텐츠 8축·KPI 로직은 해당 스킬 소관 유지)

## 워크플로우

### A. 신규 빌드
1. `references/build-kit.md` §2 토큰 블록으로 `:root` 구성 → §3 레이어 아키텍처로 페이지 골격(사이드바 + 탭 헤더 + 콘텐츠)
2. §4 컴포넌트 규격 적용 — 산출물 유형별 최소 문법: 회의록=체크서클 리스트+칸반 / 전략지표=상태 도트+진행률+KPI 카드 / 공통=필 태그
3. §6 파스텔 대비 페어 표만 사용(임의 파스텔 조합 금지)

### B. 리스킨 (기존 HTML)
1. §2 토큰 블록을 기존 CSS **최하단**에 삽입 (캐스케이드 승리)
2. **하드코딩 색 스캔** — §5 스캔 목록(`#2962FF` · 딥네이비 계열 · `#5B9BD5` 등) 기준 토큰 밖 색상 전량 치환
3. 컴포넌트 문법 치환 — §5 매핑 표(기존 테이블 행→태스크 리스트 행, 기존 신호등→상태 도트+라벨 등)
4. 검수: 잔존 다크/쿨톤 0건 · 필 대비 페어 준수 · 코랄 광원 남용 없음

### C. 품질 게이트
- 대비: `#F06A6A` 위 흰 텍스트는 버튼·큰 텍스트 전용, 본문 금지 (`shared-rules.md#RULE-WCAG`, 검증은 jc-design-system `mode-mapping.md §9` 표준)
- 필 태그는 §6 페어 표의 배경·텍스트 조합만 사용
- 상표 자산(로고·삼점·캐릭터) 0건 확인
- 완성 산출물의 최종 감수는 jc-redteam
