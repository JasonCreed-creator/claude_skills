## Instructions

행사 프로젝트의 **3P 주간 업데이트**를 작성한다. 3P는 "Progress, Plans, Problems"(진척·계획·문제)의 약자다. 주요 대상은 **발주처·사무국·협력사·내부 리더십**이다. 30~60초 안에 다 읽을 수 있을 만큼 **아주 간결하고 핵심만** 담는다. 행사 맥락을 깊게 모르는 사람도 이해할 수 있어야 한다.

3P는 어떤 단위에도 쓴다 — 하나의 행사 프로젝트, 한 사무국, 여러 행사를 묶은 본부 전체까지. 단위가 클수록 항목은 덜 세분화한다. 예를 들어 "운영팀"은 "등록 시스템 오픈", "현장 동선 확정"처럼 쓰고, 본부 전체라면 "3개 행사 동시 진행 중", "연간 수주 OO억 달성"처럼 굵직하게 쓴다.

3P는 한 기간(거의 항상 **1주**)의 일을 대표한다. 세 섹션으로 구성한다:

1) **Progress(진척)**: 지난 기간 동안 끝낸 것. 확정·오픈·송출·체결 등 **완료된 일** 중심. (예: "연사 12명 섭외 확정", "참가 등록 오픈 — 첫 주 320명")
2) **Plans(계획)**: 다음 기간에 할 것. 지금 팀의 **최우선·top-of-mind** 항목 중심. (예: "현장 동선 리허설", "스폰서 부스 배치 확정")
3) **Problems(문제)**: 팀을 느리게 만드는 것. 인력 부족, 발주처 의사결정 지연, 협력사 단가 이슈, 장소 변경, 무산된 섭외 등. (예: "연사 2명 일정 미확정 — 발주처 컨펌 대기")

작성 전 반드시 **무엇에 대한 3P인지**(행사/프로젝트/사무국 이름 = `{{event_name}}` 또는 `{{project_name}}`)를 확인한다. 명시되지 않았으면 직접 묻는다.

## Tools Available

가능하면 가용 소스에서 필요한 정보를 끌어온다(해당 기간을 커버하는 것 위주):
- **Slack**: 팀원들이 올린 업데이트 — 반응·답글 많은 큰 채널 글 우선
- **Google Drive**: 핵심 멤버가 쓴, 조회 많은 운영 문서(진행상황·체크리스트·운영계획)
- **메일**: 회신·내용 많은 발주처/협력사 스레드
- **캘린더**: 발주처 정기협의·현장 점검·리허설·납품 마감 등 비반복 핵심 일정

기간별로 모은다:
- Progress: 1주 전 ~ 오늘
- Plans: 오늘 ~ 다음 1주
- Problems: 1주 전 ~ 오늘

접근 권한이 없으면 커버할 항목을 사용자에게 직접 받는다. 사용자가 항목을 직접 주면 본 스킬은 주로 이 포맷으로 **정리·정형화**하는 역할이다.

## Workflow

1. **범위 확정**: 행사/프로젝트 이름(`{{event_name}}`)과 기간 확인(보통 Progress/Problems는 지난주, Plans는 다음 주)
2. **정보 수집**: 가용 도구 활용 또는 사용자에게 직접 수집
3. **초안 작성**: 아래 고정 포맷을 엄격히 따른다
4. **검토**: 30~60초에 읽히는지, 데이터(수치) 기반인지 확인

## 톤 분기 (외부 송부 vs 내부 보관)

| | 외부 송부용 (발주처·협력사) | 내부 보관용 (사무국·리더십) |
|---|---|---|
| Problems | 영향+대응책 중심, 책임 표현 절제("○○ 확정 대기 → 대안 일정 준비 중") | 원인·내부 사정 솔직히("발주처 컨펌 3주째 지연으로 연사 락 불가") |
| 금액 | 비공식 수치 비노출 | 마진·예산 기재 가능 |

모호하면 외부(보수적) 톤으로 기운다.

## Formatting

포맷은 항상 동일하며 매우 엄격하다. **이 외의 어떤 포맷도 쓰지 않는다.** 팀과 업데이트의 분위기를 살리는 이모지를 하나 고른다.

```
[이모지] [행사/프로젝트명] ([커버 기간], 보통 1주)
Progress: [1~3문장]
Plans: [1~3문장]
Problems: [1~3문장]
```

각 섹션은 **1~3문장**을 넘지 않는다 — 명확하고 핵심만. **데이터 기반**으로, 가능하면 수치를 넣는다. 톤은 매우 사실 위주(matter-of-fact), 장황한 산문체 금지.

### 예시 (가상 — 모든 식별자는 외부 주입 변수)

```
🎤 {{event_name}} (6/1–6/7)
Progress: 키노트·트랙 연사 12명 섭외 확정(목표 14명 中 86%). 참가 등록 오픈 — 첫 주 320명(목표 대비 64%). {{venue}} 메인홀·세미나실 4개 가계약 완료.
Plans: 현장 동선 1차 리허설(6/12), 스폰서 부스 배치 확정, 모바일 안내 페이지 오픈. {{client_company}} 정기협의에서 프로그램 최종본 컨펌 받기.
Problems: 잔여 연사 2명 일정 미확정 — {{client_company}} 컨펌 대기 3주차로, 미확정 시 6/14 대체 섭외안 가동. 현장 인력 2명 충원 지연.
```

> 내부 보관용이면 Problems를 더 솔직하게: "발주처 의사결정이 계속 밀려 연사 락이 안 되고, 이대로면 인쇄물 마감(6/20)도 위태롭다. 현장 인력은 타 행사와 겹쳐 충원이 막힌 상태."
