## Instructions

표준 양식(3P·뉴스레터·FAQ)에 들어맞지 않는 **모든 행사 운영 커뮤니케이션**을 작성한다. 대표적으로 **상태 보고·인시던트(장애·사고) 보고·리더십 업데이트·프로젝트 업데이트**, 그리고 내부 공지·대외 안내문 등이 여기 속한다.

진행 전:
1. **대상**을 묻는다 (발주처 / 사무국 / 협력사 / 참가자 / 리더십 중 누구인가)
2. **목적**을 파악한다 (알림 / 결정 요청 / 사과·수습 / 경과 공유 등)
3. **톤**을 확정한다 (격식 / 캐주얼 / 긴급 / 정보 전달)
4. 특정 **포맷 요구사항**을 확인한다 (메일 / Slack / 공문 등)

일반 원칙:
- 명확하고 간결하게
- 능동태로
- **가장 중요한 정보를 맨 앞에**(두괄식)
- 관련 링크·근거를 포함
- 회사의 커뮤니케이션 스타일에 맞춘다

## 톤 분기 (외부 송부 vs 내부 보관)

- **외부 송부용**(발주처·참가자·협력사): 정중·사실 위주, 책임 공방·내부 사정 배제, 영향+대응책 중심. 비공식 금액·내부 일정 비노출.
- **내부 보관용**(사무국·리더십): 솔직한 원인·평가·내부 사정 포함 가능.
- 모호하면 외부(보수적) 톤. 외부 송부 글은 발송 전 `jc-redteam` 3축 검증 권장(특히 인시던트·리더십 보고).

## 자주 쓰는 4종 — 권장 골격

각 골격은 두괄식·핵심만 원칙을 구체화한 것이다. 모든 식별자(`{{client_company}}`·`{{event_name}}`·`{{author_name}}` 등)는 외부 주입 변수로 둔다.

### A. 상태 보고 (Status Report)

진행 상황을 한눈에. 보통 발주처·리더십 정기 공유용.

```
■ {{event_name}} 상태 보고 ({{date}} 기준)
한 줄 요약: [전체 상태 — 정상 / 주의 / 위험] + 핵심 한 문장
- 전체 진행률: [N%] (마일스톤 [X/Y] 완료)
- 이번 주 주요 진척: [2~3개]
- 다음 주 핵심: [2~3개]
- 주의/리스크: [있으면 영향+대응. 없으면 "특이사항 없음"]
- 의사결정 요청: [발주처/리더십 컨펌 필요 항목, 없으면 생략]
```

상태 신호는 **정상 / 주의 / 위험** 3단계로 명시한다. 위험 신호는 반드시 대응책·필요 지원과 함께.

### B. 인시던트 보고 (Incident Report)

현장 장애·사고·중대 차질 발생 시. **속도와 사실 정확성이 생명.** 추측·책임 단정 금지.

```
■ [인시던트] {{event_name}} — [한 줄 제목]
발생 시각: [일시]  |  영향 범위: [대상·규모]  |  현재 상태: [수습 중 / 복구 완료]
1) 무슨 일이 일어났나 (사실만)
2) 영향 (참가자/일정/발주처에 미친 영향)
3) 즉시 취한 조치
4) 현재 상태 및 다음 조치 (ETA)
5) 재발 방지 (확정 전이면 "원인 분석 중", 추측 금지)
```

- **1보(속보)는 빠르게**: "무슨 일 + 영향 + 지금 대응 중 + 다음 업데이트 시각"만으로도 먼저 보낸다.
- 외부(발주처·참가자)용은 사실·대응·사과에 집중하고 내부 책임 소재는 빼되, 내부 보관본에는 원인·경위를 솔직히 기록한다.
- 금액·법적 책임·환불 약속은 임의로 적지 않는다 — 책임자/발주처 컨펌 후.

### C. 리더십 업데이트 (Leadership Update)

경영진·본부장 등 의사결정자 대상. 결론·임팩트·필요 결정 위주, 실무 디테일 최소화.

```
■ {{event_name}} 리더십 업데이트 ({{date}})
핵심 메시지 (1문장): [지금 가장 알아야 할 것]
- 성과/임팩트: [수치 중심 2~3개]
- 리스크/이슈: [의사결정자가 알아야 할 것 + 영향도]
- 필요한 결정/지원: [구체적으로 — 무엇을, 언제까지]
- (선택) 전망: [다음 분기/행사 한 줄]
```

리더는 시간이 없다 — **읽는 데 30~60초**, 필요 결정은 굵게. 좋은 소식·나쁜 소식 모두 솔직하게(나쁜 소식 숨기면 신뢰가 깨진다).

### D. 프로젝트 업데이트 (Project Update)

특정 행사 프로젝트의 경과를 이해관계자 묶음(발주처+협력사+사무국)에 공유. 3P보다 길고 서술적일 수 있다.

```
■ {{event_name}} 프로젝트 업데이트 ({{기간}})
1) 개요: [현재 단계 — 기획/준비/실행/마감]
2) 이번 기간 완료: [주요 산출·확정 사항]
3) 진행 중: [지금 돌고 있는 작업]
4) 예정: [다가오는 마일스톤 + 일정]
5) 이슈·리스크: [영향+대응]
6) (선택) 협조 요청: [이해관계자별로 필요한 것]
```
