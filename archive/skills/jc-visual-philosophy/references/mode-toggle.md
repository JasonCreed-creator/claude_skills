# Mode Toggle — 홈베이스 vs 자유 아트 (정본)

이 스킬의 **핵심 긴장점**이다(플레이북 §4 홈베이스 원칙). 원본 `canvas-design`은 "예술적 자유"를 silent default로 두었다. jc 생태계에서는 그 전제를 뒤집어, **jc 시그니처를 기본값으로 두고 자유는 이름 붙은 opt-in으로만** 노출한다.

> 한 줄 요약: **별 지시 없으면 산출 아트가 jc 룩과 한 가족.** 임의 팔레트·디스플레이 폰트의 무한 자유는 사용자가 명시적으로 켤 때만.

---

## 1. 두 모드 정의

| 항목 | 🏠 홈베이스 (기본·default) | 🎨 자유 아트 (opt-in) |
|------|---------------------------|----------------------|
| **언제** | 사용자가 모드를 지정하지 않은 모든 경우 | 사용자가 자유 모드를 **명시**했을 때만 |
| **팔레트** | jc 토큰 고정 — 시그니처(§1.1~1.7) + 인포그래픽 스케일(§1.8 scale-blue/green/red/amber) | 임의 팔레트 자유 (미학이 요구하는 어떤 색이든) |
| **타이포** | Pretendard(한/혼용) 기본 + 필요 시 JetBrains Mono(숫자·임상 라벨) | canvas-fonts 디스플레이 폰트 자유 (Boldonse·Gloock·EricaOne 등) |
| **무드** | jc 룩과 한 가족 — 제안서·대시보드·랜딩과 같은 비주얼 언어 | 미학 선언 우선, jc 종속 없음 |
| **값 출처** | jc-design-system SoT 런타임 참조(미러 금지) | 미학이 정함 — SoT 토큰에 묶이지 않음 |
| **인쇄** | 인쇄 라이트 권장(`#RULE-PRINT-LIGHT`) | 미학이 다크 풀블리드면 그 자체가 디자인(예외) |

**공통 불변(두 모드 모두 지킴)**: 크래프트맨십(뮤지엄 퀄리티)·미니멀 텍스트·미묘한 레퍼런스·겹침 0/페이지 이탈 0·`#RULE-NO-COMPANY`(회사·개인정보 0건)·가독 텍스트 `#RULE-WCAG`.

## 2. 모드 결정 규칙 (우선순위)

```
1. 사용자가 자유 모드를 명시        → 자유 아트
2. 그 외 전부                       → 홈베이스 (기본)
```

- **자유 모드를 켜는 명시 신호**(이 중 하나라도 있으면): "자유 아트 모드", "free art", "자유 모드", "팔레트 자유롭게", "색 마음대로", "폰트 자유", "디스플레이 폰트 써도 돼", "jc 룩 말고", "브랜드 색 빼고 예술적으로", "completely free", "any palette".
- **약한·암묵 신호는 자유 모드로 치지 않는다**: "예쁘게", "감각적으로", "임팩트 있게", "독특하게" 같은 표현은 홈베이스 안에서 충분히 달성한다 → 홈베이스 유지.
- **애매하면 홈베이스로 가고 한 줄 안내한다**:
  > "jc 기본 룩(시그니처 컬러 + Pretendard)으로 갑니다. 임의 팔레트·디스플레이 폰트가 필요하면 '자유 아트 모드'라고 말씀해 주세요."
- 자유 모드를 **추측으로 켜지 않는다.** opt-in의 핵심은 명시성이다.

### 2.1 부분 자유(하이브리드)도 명시로

사용자가 "색은 jc 그대로 두고 폰트만 자유" 또는 "폰트는 Pretendard, 색만 좀 풀어줘"처럼 **부분 해제**를 명시하면 그 축만 연다:

| 사용자 명시 | 팔레트 | 타이포 |
|------------|--------|--------|
| "폰트만 자유" | jc 토큰 고정 | canvas-fonts 허용 |
| "색만 자유" | 임의 팔레트 | Pretendard 고정 |
| (전체 자유) | 임의 팔레트 | canvas-fonts 허용 |

축이 명시되지 않은 쪽은 홈베이스 기본값을 유지한다.

## 3. 홈베이스 모드 — 색·폰트 규칙

- **색**: `references/jc-palette-mapping.md` 가 정본. 요지 — 시그니처 베이스(네이비·일렉트릭 블루·잉크/서피스) + 포인트 풀(오렌지·마젠타·네온·블루) + **§1.8 인포그래픽 스케일**(연속·단계 표현). 임의 색을 더하지 않는다. 값은 SoT(`signature-tokens.md §6 JSON`) 런타임 참조.
- **폰트**: `references/fonts-strategy.md` 가 정본. 기본 Pretendard(미설치 환경이면 GitHub 릴리스에서 다운로드), 숫자·임상 라벨은 JetBrains Mono. canvas-fonts 디스플레이 폰트는 홈베이스에서 **쓰지 않는다.**
- **"제한된 팔레트로도 미학을 낸다"**: 홈베이스는 표현을 죽이는 게 아니다. 일렉트릭 블루의 단일 색조 + scale-blue 5단계 그라데이션만으로도 모노크로매틱 마스터피스가 나온다. 색 수를 줄이고 형태·리듬·반복·여백으로 승부한다(원본의 "limited color palette that feels intentional and cohesive"와 정확히 같은 정신).

## 4. 자유 아트 모드 — 해방의 범위와 한계

opt-in으로 켜졌을 때 **풀리는 것**:

- 임의 팔레트(미학이 요구하는 어떤 컬러 시스템이든 — 보색·파스텔·형광·모노톤 자유).
- canvas-fonts 디스플레이 폰트(원본 폴더의 54개 .ttf — Boldonse·Gloock·EricaOne·Italiana·BigShoulders·Silkscreen 등). 출처·로딩은 `references/fonts-strategy.md`.

자유 모드에서도 **여전히 지키는 것**(공통 불변):

- **`#RULE-NO-COMPANY`**: 자유라도 회사명·실명·부서·로고는 절대 박지 않는다. 미학적 자유 ≠ 식별정보 자유.
- **가독 텍스트 `#RULE-WCAG`**: 작품 안에 *읽혀야 하는* 제목/라벨이 있으면 대비 4.5:1↑(큰 텍스트 3:1). 순수 장식 마크는 예외.
- **크래프트맨십·미니멀 텍스트·겹침 0**: 자유는 "막 그려도 된다"가 아니다. 뮤지엄 퀄리티 기준은 동일하다.
- **기존 아티스트 작품 모사 금지**(저작권): 원본 작품을 만든다.

---

## 5. 안티패턴 (하지 말 것)

- ❌ 사용자 지시 없이 "더 예술적으로 보이려고" 자유 모드를 임의로 켜기 → 기본은 항상 홈베이스.
- ❌ 홈베이스인데 canvas-fonts 디스플레이 폰트나 jc 외 임의 색을 섞기.
- ❌ 자유 모드라고 회사 로고·실명·식별정보를 넣거나, 가독 텍스트 대비를 무시하기.
- ❌ jc 토큰 값을 본문/코드에 하드코딩(홈베이스는 SoT 런타임 참조 — 플레이북 §3).
- ❌ canvas-fonts 30여 개를 레포에 대량 복사(경량 유지 — `references/fonts-strategy.md`).
