# KPI 자동 감지 패턴

## 컬럼명 키워드 매핑

아래 키워드가 컬럼명에 포함되면 해당 KPI 카테고리로 분류한다.
매칭은 대소문자 무시, 한글/영문 모두 지원.

## KPI 카드 우선순위 로직

KPI 카드에 표시할 지표를 아래 우선순위로 선별한다 (최대 6개):

1. **필수 표시** (존재하면 무조건 포함):
   - 총 참가자 수
   - 매출액/총 수입
   - 전체 만족도

2. **높은 우선순위** (공간이 있으면 포함):
   - 목표 달성률 (목표 데이터가 있을 때)
   - 전년 대비 증감률 (비교 데이터가 있을 때)
   - ROI

3. **보조 지표** (위 항목이 부족할 때):
   - 등록률, 세션 수, 부스 수
   - 기타 합계/평균값

## 증감률 계산 규칙

- 비교 기준이 있는 경우 (전년/전분기/목표): `(현재 - 기준) / 기준 × 100`
- 비교 기준이 없는 경우: 증감률 표시하지 않음
- 증감 방향:
  - 참가자/매출/만족도: ▲ 초록(긍정), ▼ 빨강(부정)
  - 비용/결점: ▲ 빨강(부정), ▼ 초록(긍정) — 의미 반전 주의

## 영문 컬럼 → 한국어 자동 매핑

| 영문 | 한국어 |
|------|--------|
| total, sum | 합계 |
| average, avg, mean | 평균 |
| count, number, qty | 수량 |
| rate, ratio, percentage | 비율 |
| target, goal, plan | 목표 |
| actual, result | 실적 |
| previous, last, prior | 전년/전기 |
| growth, increase | 성장 |
| decline, decrease | 감소 |
| category, type, group | 구분 |
| name, title, label | 명칭 |
| date, period, month, year | 기간 |
