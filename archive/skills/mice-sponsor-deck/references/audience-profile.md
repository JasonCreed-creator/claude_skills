# Audience Profile — 청중 자산 데이터 가이드

스폰서 데크의 두 번째 축. **"이 행사 청중이 누구인지"** 가 스폰서의 의사결정에 가장 큰 영향을 준다.

---

## 1. 청중 데이터의 구성

스폰서 데크 "Who Attends" 섹션에 들어가야 하는 청중 데이터는 다음 5개 차원이다.

| 차원 | 데이터 항목 | 시각화 권장 |
|------|------------|------------|
| ① 규모 | 예상/과거 참가자 수 | 큰 KPI 숫자 |
| ② 산업 분포 | 산업별 비율 | 도넛 차트 또는 가로 바 차트 |
| ③ 직급 분포 | 직급별 비율 | 가로 바 차트 |
| ④ 의사결정권 | 구매·예산 결정자 비율 | 단일 KPI 또는 도넛 |
| ⑤ 지역·규모 | 기업 규모·지역 분포 | 보조 차트 (선택) |

### 1.1 5개 차원의 우선순위

데크 슬라이드는 2~3장이 한계. 모든 차원을 다 표현하면 정보 과잉. 다음 우선순위로 압축한다.

1. **규모** (필수, 가장 큰 KPI)
2. **산업 분포** (필수, 스폰서가 자기 산업 비중 확인)
3. **의사결정권** (필수, "내 영업 대상이 있는가?" 핵심 질문)
4. 직급 분포 (선택)
5. 지역·기업 규모 (선택)

---

## 2. 데이터 출처 표기 (필수)

모든 청중 데이터에는 **반드시 출처를 명시**한다. 추측 금지·팩트 기반 원칙.

### 2.1 출처 4분류

| 출처 | 표기 형식 | 신뢰도 |
|------|----------|--------|
| 과거 회차 실데이터 | "2024년 회차 실측" | 가장 높음 |
| 산업 벤치마크 | "(국내 IT 컨퍼런스 평균, [출처])" | 중간 |
| 데이터 파트너 (예: 명함 데이터) | "데이터 파트너사 분석" | 중간 |
| 추정 | "신규 행사 추정 — 본 사무국 기획 가이드 기반" | 가장 낮음 |

### 2.2 출처 캡션 위치

각 차트·KPI 우측 하단 또는 슬라이드 푸터에 작게 표기.

```
참가자 규모: 5,200명 (예상)
└ 출처: 2024년 회차 4,800명 + 2025년 14% 성장 가정
```

---

## 3. 신규 행사 fallback 룰

신규 행사(1회차)는 과거 데이터가 없다. 이 경우 다음 fallback 패턴을 적용한다.

### 3.1 우선순위

```
1순위: 데이터 파트너 추정치 (명함 데이터 기반 타겟 매칭 등)
       ↓
2순위: 유사 행사 벤치마크 (동일 산업 동일 규모 행사)
       ↓
3순위: 주최사 보유 자산 (회원 DB·과거 행사 누적)
       ↓
4순위: 산업 일반 통계 (산업협회·정부 통계)
```

### 3.2 fallback 시 문구 템플릿

**1순위 (데이터 파트너):**

```
예상 참가자 5,200명
└ 데이터 파트너사가 보유한 [산업/직급] 명함 데이터 [N만명] 중
   타겟 모집단 매칭 결과 기반 추정
```

**2순위 (유사 행사 벤치마크):**

```
예상 참가자 5,200명
└ 2024년 [유사 행사명] 4,800명 / [업계 평균] 5,000명 참조
```

**3순위 (주최사 자산):**

```
예상 참가자 5,200명
└ 주최사 회원 DB [N만명] 중 동일 산업 응답률 [평균값] 적용
```

**4순위 (산업 통계):**

```
예상 참가자 5,200명
└ [산업협회/통계청] [연도] [통계명] 기반 추정
```

### 3.3 절대 회피 표현

신규 행사라도 다음 표현은 금지:

- ❌ "약 5,000명 이상 예상"
- ❌ "최대 1만명 규모"
- ❌ "수천명의 의사결정자"
- ❌ "업계 핵심 인사 다수 참여"

이런 표현은 추측이며 스폰서 신뢰를 깎는다. 출처 없는 숫자는 쓰지 말 것.

## 4. 산업 분포 표기 가이드

산업 분포는 스폰서 영업의 핵심 데이터다. 자기 산업 비중을 보고 의사결정한다.

### 4.1 산업 분류 표준 (한국 시장)

본 스킬은 다음 8대 산업 분류를 표준으로 사용. 행사 성격에 따라 가감 가능.

1. IT·소프트웨어
2. 제조·산업재
3. 금융·보험
4. 유통·소비재
5. 헬스케어·바이오
6. 건설·부동산
7. 미디어·엔터테인먼트
8. 공공·교육·연구

### 4.2 비율 합계 룰

- 비율 합계는 100%가 되어야 함
- "기타"는 5% 이내로 통제
- 5% 미만 산업은 "기타"로 통합

### 4.3 시각화 가이드

```
도넛 차트 (5개 이하 산업) → 한눈에 비중 파악
가로 바 차트 (6개 이상 산업) → 정렬·비교 용이
```

색상은 jc-design-system 데이터 시리즈 5색 풀 사용 (`--jc-data-1` ~ `--jc-data-5`).

## 5. 직급 분포 표기 가이드

### 5.1 직급 분류 표준

| 분류 | 포함 범위 |
|------|----------|
| C-Level | CEO·CFO·COO·CTO·CMO 등 |
| 임원 | 부사장·전무·상무·이사 |
| 시니어 매니저 | 부장·팀장·실장 |
| 매니저 | 과장·차장·매니저 |
| 실무자 | 대리·사원·주니어 |

### 5.2 의사결정권 강조

직급 분포 표기 시 **C-Level + 임원 합계를 별도 KPI**로 강조.

```
C-Level + 임원 비율: 23%
(전체 5,200명 중 1,196명)

= 의사결정권자 1,196명에게
  당신의 브랜드를 직접 노출
```

이 KPI가 스폰서 영업의 가장 강력한 무기다.

---

## 6. 의사결정권 표기 가이드

직급과 별개로, **구매·예산 결정 권한**이 있는 참가자 비율을 별도 표기.

### 6.1 표기 예시

```
의사결정권자 비율: 32%
└ 정의: 자사 마케팅·구매 예산 결정 권한 보유
└ 출처: 2024년 회차 등록 시 자기 응답
```

### 6.2 데이터 없는 경우

자기 응답 데이터가 없는 경우 직급 기반 추정 사용:

```
의사결정권자 비율: 약 25~30% (추정)
└ 직급 분포(C-Level 8% + 임원 15% + 시니어 매니저 25%) 중
   구매 의사결정 통상 비율 적용
```

추정 명시 의무.

## 7. 데이터 파트너 모델 처리 (REMEMBER 추상화)

본 스킬은 회사·파트너 종속 표현을 회피한다. 데이터 파트너 모델은 다음 일반 표현으로 처리.

### 7.1 추상화 표현

| 회사 종속 표현 | 일반 표현 (본 스킬 사용) |
|---------------|------------------------|
| ❌ "리멤버 명함 데이터" | ✓ "데이터 파트너사 명함 데이터 기반 분석" |
| ❌ "REMEMBER 협업" | ✓ "데이터 기반 타겟 참가자 모집 모델" |
| ❌ "[데이터 파트너사 임원 실명] 협업" | ✓ "데이터 파트너사 협업" |

### 7.2 클라이언트 토큰 적용 시

`client_id = remember` 토큰 지정 시 jc-design-system 의 client-overlays.md 룰에 따라 REMEMBER 브랜딩이 토글된다. 이 경우에만 명시적 표기 가능.

## 8. 산업 벤치마크 빠른 참조

신규 행사 fallback 시 산업 벤치마크 추정값. **본 수치는 가이드일 뿐 정확한 통계가 아니다.** 사용 시 반드시 출처를 보강할 것.

### 8.1 한국 MICE 행사 평균 청중 구성 (2023~2024 추정)

| 행사 유형 | 평균 참가자 | C-Level+임원 비율 | 의사결정권자 비율 |
|----------|-----------|------------------|-----------------|
| 기술 컨퍼런스 (B2B) | 2,000~5,000명 | 15~25% | 25~35% |
| 산업 박람회 (전시회) | 10,000~50,000명 | 8~15% | 15~25% |
| 임원 포럼 (초청제) | 200~500명 | 70~85% | 80~90% |
| 소비자 페스티벌 | 30,000~100,000명+ | 거의 없음 | — |
| 기업 행사 (자체) | 500~3,000명 | 50~70% (사내 임원) | — |

**주의:** 위 표는 본 스킬 가이드용 보수적 추정치다. 실제 데이터로 대체 권장.
