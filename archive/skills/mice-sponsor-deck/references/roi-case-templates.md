# ROI Case Templates — 산업별 ROI 시나리오 가이드

스폰서 데크의 가장 결정적 슬라이드. **"내 산업에서 이 행사 협찬이 어떤 가치를 주는가"** 를 산업별로 변환해 보여준다.

---

## 1. ROI 3단 표현 룰 (필수)

ROI는 본질적으로 추정치다. 추측 금지·팩트 기반 원칙을 지키기 위해 **모든 ROI 케이스는 다음 3단 구조로 표현**한다. 이 룰은 강제된다.

```
┌──────────────────────────┐
│ ① 전제 조건              │ ← 객관적 데이터 (행사 규모·청중 구성)
└──────────┬───────────────┘
           ↓
┌──────────────────────────┐
│ ② 산출 공식              │ ← 어떻게 계산했는지 (투명성)
└──────────┬───────────────┘
           ↓
┌──────────────────────────┐
│ ③ 보수적 추정값          │ ← 결과 (보수적 범위 + 캡션)
└──────────────────────────┘
```

### 1.1 캡션 의무

모든 ROI 슬라이드 하단에 다음 캡션 의무 삽입:

```
ⓘ 본 수치는 산업 벤치마크 기반 추정치이며, 실제 결과는 노출 환경·콘텐츠 품질에 따라 변동됩니다.
```

### 1.2 표현 예시 (상세)

```
┌─────────────────────────────────────────────────────┐
│ Tech 산업 스폰서 ROI 시뮬레이션                     │
├─────────────────────────────────────────────────────┤
│ ① 전제 조건                                         │
│    참가자 5,200명                                    │
│    IT 산업 비중 42% → 약 2,184명                     │
│    의사결정권자 비율 30% → 약 655명                  │
│                                                     │
│ ② 산출 공식                                         │
│    부스 방문 전환율 (산업 평균 12%) × 의사결정권자  │
│    = 655 × 0.12 = 약 78명                           │
│    리드 전환율 (산업 평균 35%) 적용                  │
│    = 78 × 0.35 = 약 27건                            │
│                                                     │
│ ③ 보수적 추정값                                     │
│    리드 약 25~30건                                   │
│    예상 PR 가치 약 KRW 25,000,000 (메인 노출 환산)   │
│                                                     │
├─────────────────────────────────────────────────────┤
│ ⓘ 본 수치는 산업 벤치마크 기반 추정치이며, 실제      │
│   결과는 노출 환경·콘텐츠 품질에 따라 변동됩니다.   │
└─────────────────────────────────────────────────────┘
```

## 2. 산업 5종 표준 케이스

본 스킬은 다음 5개 산업에 대한 ROI 시나리오 템플릿을 표준 제공. 행사 청중 산업 분포 상위 2~3종을 선택해 데크에 반영.

### 2.1 산업 분류

| ID | 산업 | 핵심 ROI 지표 |
|----|------|--------------|
| `tech` | IT·소프트웨어·테크 | 리드·B2B 매칭·인재 채용 노출 |
| `finance` | 금융·보험·핀테크 | 임원 노출·신뢰도·고가치 리드 |
| `cpg` | 소비재·유통 | 브랜드 노출·체험·미디어 확산 |
| `b2b` | 산업재·B2B 제조 | 바이어 매칭·기술 리더십 |
| `public` | 공공·교육·연구 | ESG·사회적 책임·정책 영향력 |

---

## 3. Tech 산업 ROI 템플릿

### 3.1 핵심 가치 제안

> "행사 참가자 중 IT 의사결정권자 N명에게 직접 노출 + 영업 리드 확보 + 인재 채용 브랜딩"

### 3.2 표준 시나리오

```
[ 전제 조건 ]
- 참가자 [총 N]명 / IT 산업 비중 [X%] → IT 참가자 [A]명
- IT 의사결정권자 비율 [Y%] → [B]명

[ 산출 공식 ]
1) 부스 방문 리드:
   B × 부스 전환율(평균 12~18%) = 약 [C]건
2) B2B 매칭 미팅 (T1 기준 10미팅): 미팅당 평균 1.2 리드 = 12건
3) PR 가치 환산:
   메인 보도자료 노출 5개 매체 × 평균 KRW 5M = KRW 25M
4) 인재 채용 브랜딩:
   IT 참가자 노출 [A]명 × 채용 인지도 (정성 가치)

[ 보수적 추정값 ]
- 리드 총 약 [C+12 → 보수치] 건
- PR 가치 약 KRW 25M
- 인재 채용 인지도 노출 [A]명 (정성)
```

### 3.3 강조 포인트

- T1·T2 키노트 발표 슬롯 → 기술 리더십 포지셔닝
- B2B 매칭 미팅 → 즉시 영업 파이프라인
- 데이터 파트너 매칭 리포트 → 사후 영업 자산

## 4. Finance 산업 ROI 템플릿

### 4.1 핵심 가치 제안

> "C-Level·임원 [N]명에게 신뢰도 기반 노출 + VIP 만찬·라운지 직접 접점 + 고가치 1:1 미팅"

### 4.2 표준 시나리오

```
[ 전제 조건 ]
- 참가자 [총 N]명 / 금융 산업 비중 [X%] → 금융 참가자 [A]명
- C-Level + 임원 비율 [Y%] → [B]명
- 평균 LTV (금융 B2B 고객) 약 KRW 50,000,000~200,000,000

[ 산출 공식 ]
1) VIP 만찬 단독 호스트 (T1):
   직접 접점 8~10명 × 신뢰도 기반 영업 가능성
2) 임원 라운지 노출:
   임원 [B]명 중 30% 라운지 이용 추정 = [B×0.3]명
3) 고가치 1:1 미팅:
   미팅당 평균 LTV × 보수적 전환율 5%
   = KRW [LTV] × 0.05 × 미팅 수
4) PR 노출:
   금융 산업 매체 5개 + 보도자료 1회

[ 보수적 추정값 ]
- 직접 접점 약 8~10명 (VIP 만찬 단독)
- 추가 임원 노출 약 [B×0.3]명
- 잠재 영업 가치 약 KRW [LTV × 0.05 × 미팅] (1:1 미팅 기반)
```

### 4.3 강조 포인트

- VIP 만찬 단독 호스트는 T1만 가능 → 강력한 차별화
- 신뢰도·격조 톤 (광고성·할인 강조 금지)
- 평균 LTV 명시는 산업 벤치마크 또는 자사 평균 LTV 사용 (출처 의무)

## 5. CPG 산업 ROI 템플릿 (소비재·유통)

### 5.1 핵심 가치 제안

> "참가자 [N]명에게 브랜드 직접 노출 + SNS 확산 + 체험 마케팅 + 미디어 노출"

### 5.2 표준 시나리오

```
[ 전제 조건 ]
- 참가자 [총 N]명 (행사 현장)
- 행사 SNS 팔로워 [F]명 + 미디어 도달 [M]명
- 행사 체험존 평균 방문율 60~75%

[ 산출 공식 ]
1) 현장 브랜드 노출:
   참가자 [N]명 × 사이니지 평균 노출 횟수 [X]회 = [N×X] 노출 임프레션
2) SNS 확산:
   공식 SNS 단독 포스트 (T1·T2 기준) × 평균 도달
   = [F]명 × 평균 도달률 15% × 포스트 수
3) 체험존 직접 인터랙션:
   참가자 [N]명 × 체험존 방문율 65% = [N×0.65]명
4) 미디어 노출:
   보도자료 5개 매체 × 평균 PR 가치 KRW 5M = KRW 25M

[ 보수적 추정값 ]
- 현장 노출 임프레션 약 [N×X]회
- SNS 도달 약 [F×0.15×포스트수]명
- 체험 인터랙션 약 [N×0.65]명
- PR 가치 약 KRW 25M
```

### 5.3 강조 포인트

- 체험·시각·SNS-가능한 콘텐츠 강조
- 인플루언서 협업 옵션 (T1·T2)
- "샘플링 N개 배포 → 직접 체험" 가시성

## 6. B2B 산업재 ROI 템플릿

### 6.1 핵심 가치 제안

> "산업 바이어 [N]명에게 직접 접점 + 1:1 미팅 + 기술 리더십 콘텐츠"

### 6.2 표준 시나리오

```
[ 전제 조건 ]
- 참가자 [총 N]명 / 동일 산업 비중 [X%] → 산업 참가자 [A]명
- 구매·기술 의사결정권자 비율 [Y%] → [B]명
- 평균 B2B 거래 단가 (산업별) 약 KRW [V]

[ 산출 공식 ]
1) 부스 방문 리드:
   B × 부스 전환율 (B2B 산업재 평균 8~15%) = [C]건
2) 1:1 매칭 미팅:
   T1 10미팅 / T2 6미팅 / T3 3미팅
   미팅당 평균 견적 가능성 30%
3) 기술 세션·키노트:
   산업 참가자 [A]명 노출 → 기술 리더십 포지셔닝
4) PR 가치:
   산업 전문매체 3~5개 × 평균 KRW 3M = KRW 9~15M

[ 보수적 추정값 ]
- 리드 약 [C]건
- 견적 발생 가능성 약 [미팅수×0.3]건
- 잠재 거래 가치 약 KRW [V × 0.3 × 미팅수] (보수치)
- PR 가치 약 KRW 9~15M
```

### 6.3 강조 포인트

- 부스 위치·기술 시연 공간 강조
- 1:1 매칭 미팅 품질 (사전 큐레이션)
- 기술 세션 콘텐츠 가이드라인 준수

## 7. 공공·교육·연구 산업 ROI 템플릿

### 7.1 핵심 가치 제안

> "ESG·사회적 책임 노출 + 정책·연구 커뮤니티 영향력 + 비영리 영역 신뢰도"

### 7.2 표준 시나리오

```
[ 전제 조건 ]
- 참가자 [총 N]명 / 공공·교육·연구 비중 [X%] → [A]명
- 정책·기관 의사결정권자 비율 [Y%] → [B]명
- ESG 관련 매체 도달 추정 [M]명

[ 산출 공식 ]
1) ESG 브랜드 노출:
   참가자 [N]명 × ESG 메시지 노출 횟수
2) 정책·연구 영향력:
   기관 의사결정자 [B]명 × 직접 접점
3) ESG 보고서 활용:
   행사 협찬 → 자사 ESG 보고서 수록
4) 미디어 노출:
   ESG 전문매체 + 일반매체 = 약 [매체수]
5) 사회적 가치 환산:
   GRI/SASB 기준 사회공헌 활동 가치 환산 (선택)

[ 보수적 추정값 ]
- ESG 노출 임프레션 약 [N×3]회
- 정책 영향력 직접 접점 [B]명
- ESG 보고서 활용 자산 (정성)
- 미디어 도달 약 [M]명
```

### 7.3 강조 포인트

- ESG·사회적 가치·격조 톤
- 광고성·매출 직결 표현 회피
- 비영리 행사인 경우 격조 유지 필수

## 8. 산업 추천 룰

행사 청중 산업 분포 상위 2~3종을 자동 선택해 ROI 케이스 작성. 단 다음 룰 준수:

### 8.1 자동 선택 룰

```
1. 청중 산업 분포에서 상위 3개 산업 추출
2. 비중 5% 미만 산업 제외
3. 본 스킬 표준 산업 5종(tech/finance/cpg/b2b/public)에 매핑
4. 매핑 안 되는 산업은 가장 가까운 표준 산업 선택
   - 예: "헬스케어·바이오" → tech (B2B 영업 패턴 유사)
   - 예: "건설·부동산" → b2b
```

### 8.2 사용자 명시적 선택

사용자가 "이번 행사는 금융 스폰서를 핵심으로 영업하고 싶다" 등 명시 시 자동 룰 무시하고 사용자 지정 산업 우선.

### 8.3 슬라이드 구성

ROI Snapshot 섹션은 1~2 슬라이드. 산업별 카드 2~3개를 한 슬라이드에 표시.

---

## 9. 표현 절대 회피 룰

다음 표현은 ROI 슬라이드에서 절대 사용 금지:

- ❌ "수억원 가치"
- ❌ "수천명에게 노출"
- ❌ "확실한 ROI 보장"
- ❌ "압도적 효과"
- ❌ "[N]배 효과"

이런 표현은 추측이며 신뢰를 깎는다. **항상 보수적 범위 + 출처 + 추정 명시**.

---

## 10. 행사 후 측정 권장 (사후 보고)

ROI 슬라이드 마지막에 "사후 측정 권장 지표" 1~2줄로 안내:

```
ⓘ 행사 종료 후 본 사무국이 다음 지표를 측정하여
  스폰서별 결과 보고서를 제공합니다:
  - 노출 임프레션 (사이니지·디지털 추적)
  - 리드 건수 (부스·QR·매칭 미팅)
  - 미디어 노출 결과 (보도 매체·게시 횟수)
```

이 약속이 영업의 신뢰도를 높인다.
