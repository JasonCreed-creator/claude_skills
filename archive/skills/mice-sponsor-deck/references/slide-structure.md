# Slide Structure — 표준 12~18 슬라이드 콘텐츠 구조

본 스킬의 슬라이드 콘텐츠 구조 가이드. HTML/PPTX 양쪽에 동일하게 적용된다.

---

## 1. 표준 슬라이드 구성

| # | 섹션 | 슬라이드 수 | 6축 매핑 |
|---|------|------------|---------|
| S1 | 표지 | 1 | ① |
| S2 | Why This Event | 2~3 | ① |
| S3 | Who Attends | 2~3 | ② |
| S4 | What We Offer | 2~3 | ③ |
| S5 | Sponsor Tiers | 1~2 | ④ |
| S6 | Benefits Matrix | 2~3 | ⑤ |
| S7 | ROI Snapshot | 1~2 | ⑥ |
| S8 | Past Sponsors / Reference Cases | 0~2 | — |
| S9 | Contact & Next Steps | 1 | ⑥ |

**최소 12장 / 표준 15장 / 최대 18장**

---

## 2. S1: 표지 (1 슬라이드)

### 2.1 콘텐츠 요소

| 요소 | 위치 | 폰트·크기 | 비고 |
|------|------|----------|------|
| 행사명 (메인) | 상단 중앙 | text-5xl bold | 가장 큰 텍스트 |
| 행사 부제 (서브) | 행사명 아래 | text-2xl regular | 선택 |
| 일시·장소 | 중앙 | text-lg | 한 줄 |
| "For Sponsors" 표기 | 우상단 또는 좌하단 배지 | text-sm semibold | **본 스킬 전용 식별 표기** |
| 본 사무국 로고 | 좌하단 | — | 클라이언트 토큰으로 주입 |
| 발행일 또는 버전 | 우하단 | text-xs muted | 예: "2026.01 v1.0" |
| (조건부) "잠정안" 캡션 | 표지 푸터 | text-xs warning | 슬롯 미확정 시 |

### 2.2 디자인 룰

- 배경: `--jc-primary` (Deep Navy)
- 메인 텍스트: `--jc-surface` (흰색)
- 액센트 라인 또는 도형: `--jc-accent` (Electric Blue)

### 2.3 "For Sponsors" 배지 의무

표지에 반드시 "For Sponsors" 또는 "Sponsorship Package" 배지를 표시한다. 이는 mice-proposal과 본 스킬 산출물을 시각적으로 구분하는 핵심 식별자.

## 3. S2: Why This Event (2~3 슬라이드)

### 3.1 슬라이드 분할

| 슬라이드 | 내용 |
|---------|------|
| S2-1 | 행사 한 줄 정의 + 시장 맥락 |
| S2-2 | 행사 의의 (왜 이 시점·이 산업) |
| S2-3 (선택) | 행사 비전·차별점 |

### 3.2 콘텐츠 가이드

```
S2-1: 행사 정의
─────────────────────────────────────────
[행사명]은 [산업/주제] 분야의
[N]번째 [행사 유형]입니다.

핵심 KPI 3종:
- 회차: 제 N회 / 신규 1회차
- 규모: 참가자 [N]명 + 부스 [N]개
- 주관: [주최사]
```

### 3.3 시장 맥락 표현 룰

- "한국 [산업] 시장 규모 [출처: 통계]"
- "최근 [N]년 [트렌드 1줄] (출처)"
- 추측 금지. 통계·매체 인용 의무.

## 4. S3: Who Attends (2~3 슬라이드)

### 4.1 슬라이드 분할

| 슬라이드 | 내용 | 시각화 |
|---------|------|--------|
| S3-1 | 규모 KPI 3~4개 | 큰 KPI 카드 |
| S3-2 | 산업 분포 | 도넛 또는 가로 바 차트 |
| S3-3 (선택) | 직급·의사결정권 | 가로 바 차트 + KPI |

### 4.2 KPI 3~4개 표준

```
[ 5,200명 ]      [ 32% ]         [ 23% ]       [ 87% ]
참가자          의사결정권자    C-Level+임원   B2B 비율
(2024 회차)     (자기 응답)     (직급 기반)    (자기 응답)
```

각 KPI에 출처 캡션 의무.

### 4.3 산업 분포 슬라이드

```
산업 분포 (Top 5)
─────────────────────────────
IT·소프트웨어    ████████████ 42%
금융·보험        ███████      24%
제조·산업재      █████        18%
헬스케어         ███          10%
기타             ██            6%
─────────────────────────────
ⓘ 출처: 2024년 회차 등록 산업 분류
```

### 4.4 직급·의사결정권 슬라이드 (선택)

C-Level+임원 비율을 별도 KPI로 강조:

```
┌──────────────────────────────────┐
│ 의사결정권자 1,196명               │
│ (전체 5,200명 중 23%)              │
│                                  │
│ = 당신의 브랜드를                  │
│   이 사람들에게 직접 노출          │
└──────────────────────────────────┘
```

## 5. S4: What We Offer (2~3 슬라이드)

### 5.1 슬라이드 분할

| 슬라이드 | 내용 |
|---------|------|
| S4-1 | 오프라인 노출 자산 인벤토리 |
| S4-2 | 디지털·미디어 노출 자산 인벤토리 |
| S4-3 (선택) | VIP·콘텐츠 자산 인벤토리 |

### 5.2 콘텐츠 표현 룰

행사가 보유한 모든 노출 슬롯을 카테고리별로 정리. 7카테고리(`benefit-catalog.md`)와 매핑.

```
오프라인 노출 자산 인벤토리
────────────────────────────────
■ 메인 무대 백드롭 (1점)
  └ 약 8시간 노출 / 메인 키노트·세션 송출

■ 입구 아치 (1개)
  └ 행사장 정문 / 모든 참가자 통과 동선

■ 행사장 사이니지 (총 12점)
  └ 위치별 노출 횟수 정량화

■ 셔틀버스 래핑 (3대)
  └ 호텔↔행사장 운행 / 일 평균 6회

(이하 인벤토리 계속)
```

### 5.3 인벤토리 시각화

리스트 + 도면 (있으면). 도면은 옵션이며 행사장 평면도가 있는 경우만 사용.

## 6. S5: Sponsor Tiers (1~2 슬라이드)

### 6.1 슬라이드 구성

```
S5-1: Tier 5단 카드 가로 배치 (또는 2x3 그리드)
S5-2 (선택): In-kind 별도 트랙
```

### 6.2 Tier 카드 표준

각 Tier는 좌측 3px 액센트 막대 + 다음 정보:

```
┌───────────────────────────┐
│ ▌ T1 Title (타이틀)        │ ← 좌측 액센트: Magenta
│                           │
│ 한정 1석                   │
│ 가격 별도 협의             │ ← price_mode = on_request
│  (또는)                    │
│ KRW 100,000,000            │ ← price_mode = explicit
│                           │
│ ─────────                 │
│                           │
│ 핵심 혜택 3~5개:            │
│ • 행사명 결합권             │
│ • 키노트 발표 30분          │
│ • 메인 사이니지 8회         │
│ • VIP 만찬 단독 호스트       │
│ • 부스 54㎡ 메인 동선        │
└───────────────────────────┘
```

### 6.3 영문 병기 모드 적용

| 모드 | Tier 표기 |
|------|----------|
| `ko_first` | `T1 타이틀 (Title)` |
| `en_first` | `T1 Title (타이틀)` |

### 6.4 슬롯 수 미확정 처리

```
한정 [TBD] 석 · 확정 시 통지
```

표지 푸터에도 "잠정안" 캡션 자동 삽입.

## 7. S6: Benefits Matrix (2~3 슬라이드)

### 7.1 슬라이드 분할

매트릭스 1장에 7카테고리 × 5 Tier 모두 담으면 가독성 떨어짐. 다음 분할 권장:

| 슬라이드 | 카테고리 |
|---------|---------|
| S6-1 | 카테고리 1~3 (브랜딩·미디어·디지털) |
| S6-2 | 카테고리 4~5 (부스·연사) |
| S6-3 | 카테고리 6~7 (리드·VIP) |

행사 유형이 컨퍼런스/포럼인 경우 5(연사)·7(VIP) 우선. 전시회인 경우 4(부스)·1(브랜딩) 우선.

### 7.2 매트릭스 표 표준

```
                      T1        T2        T3        T4        T5
─────────────────────────────────────────────────────────────────
브랜딩 노출
  메인 사이니지        8회       6회        4회         2회         ✓
  프로그램북 표지      단독      공동        —           —           —
미디어 노출
  보도자료 명시        메인      공동        본문        부록        —
  공식 SNS 포스트      3회       2회         1회         —           —
─────────────────────────────────────────────────────────────────
한정 슬롯               1석       3석         6석         10석        무제한
가격 (또는 협의)        100      65          40          22          12
─────────────────────────────────────────────────────────────────
```

### 7.3 시각 표현 룰

- ✓ 셀: `--jc-success` 색상 + 굵은 폰트
- — 셀: `--jc-text-disabled` 색상 + 정렬 중앙
- 정량 셀: 기본 색상 + JetBrains Mono (숫자) 또는 Pretendard (텍스트)
- Tier 헤더 행: Tier 색상 배경 (위 design-tokens-mapping.md §2.2)

## 8. S7: ROI Snapshot (1~2 슬라이드)

### 8.1 슬라이드 구성

산업 2~3종 ROI 카드를 한 슬라이드에 가로 배치 (또는 1산업당 1슬라이드).

```
S7-1: 산업 2~3종 ROI 카드 가로 배치 (권장)
       또는
S7-1, S7-2: 산업 1종당 1슬라이드 (대형 행사)
```

### 8.2 ROI 카드 표준

3단 구조 강제 (`roi-case-templates.md` §1 참조):

```
┌──────────────────────────────────────┐
│ ■ Tech 산업 스폰서 ROI               │ ← Tier 색상 배지
├──────────────────────────────────────┤
│ ① 전제 조건                          │
│ • IT 참가자 약 2,184명               │
│ • IT 의사결정권자 약 655명            │
├──────────────────────────────────────┤
│ ② 산출 공식                          │
│ • 부스 전환율 12% × 의사결정권자       │
│ • 리드 전환율 35% 적용                │
├──────────────────────────────────────┤
│ ③ 보수적 추정값                      │
│ • 리드 약 25~30건                    │
│ • PR 가치 약 KRW 25M                 │
├──────────────────────────────────────┤
│ ⓘ 본 수치는 산업 벤치마크 기반 추정치 │
└──────────────────────────────────────┘
```

### 8.3 캡션 의무

모든 ROI 슬라이드 하단에 추정치 캡션. 누락 금지.

## 9. S8: Past Sponsors / Reference Cases (0~2 슬라이드, 조건부)

### 9.1 분기 룰 (필수)

| 행사 유형 | S8 처리 |
|----------|--------|
| 기존 행사 (과거 회차 존재) | "Past Sponsors" — 과거 협찬사 로고 그리드 |
| 신규 행사 (1회차) | "Reference Cases" — 주최사 과거 실적 또는 유사 행사 레퍼런스 |
| 데이터 없음 | **S8 생략** (총 슬라이드 12~14장으로 축소) |

### 9.2 Past Sponsors 슬라이드

```
Past Sponsors
─────────────────────────────────────
[로고 그리드 5x4 = 20개]

(작은 캡션) 2020~2024 회차 협찬·후원사
```

로고는 그레이스케일 통일. 협찬사 정렬은 가나다순 또는 Tier순.

### 9.3 Reference Cases 슬라이드 (신규 행사용)

```
Reference Cases
─────────────────────────────────────
주최사가 운영해온 유사 규모 행사:

■ [유사 행사명 1] — 2023
  참가자 [N]명 / 협찬사 [N]개사

■ [유사 행사명 2] — 2024
  참가자 [N]명 / 협찬사 [N]개사
```

또는 산업 벤치마크 행사 인용:

```
유사 행사 벤치마크:
■ [국내 컨퍼런스 A] — 평균 참가자 N명 / 협찬사 N사
■ [해외 컨퍼런스 B] — 평균 참가자 N명 / 협찬사 N사
```

### 9.4 데이터 없음 처리

신규 행사이고 주최사 과거 실적 데이터도 없는 경우 S8을 생략한다. 빈 슬라이드를 만들지 말 것.

```
사용자 알림:
ⓘ 신규 행사 + 주최사 레퍼런스 데이터 없음 → 
  Past Sponsors / Reference Cases 섹션 생략
  최종 슬라이드 수: 13장 (예시)
```

## 10. S9: Contact & Next Steps (1 슬라이드)

### 10.1 콘텐츠 요소

| 요소 | 내용 |
|------|------|
| CTA 헤드라인 | "지금 함께하실 수 있는 [N]개 슬롯이 남아있습니다" |
| 다음 단계 3~5개 | 1) 견적 협의 → 2) Tier 선정 → 3) 계약서 송부 |
| 담당자 정보 | 이름·직급·이메일·전화 |
| 마감일 (있으면) | "협찬 신청 마감: 2026.03.15" |
| 본 사무국 로고 | 좌하단 |

### 10.2 CTA 헤드라인 표준 문구

`price_mode` 별:

```
on_request:
"견적 협의를 위해 본 사무국으로 연락 주십시오.
 잔여 슬롯: T1 1석 / T2 3석 / T3 6석"

explicit:
"위 가격으로 [N]개 슬롯에 한해 우선 협찬 가능합니다.
 잔여 슬롯: T1 1석 / T2 3석 / T3 6석"
```

### 10.3 마감일 강조

마감일이 있는 경우 `--jc-warning` 또는 `--jc-danger` 색상으로 강조. 임박 시(1개월 이내) `--jc-danger`.

### 10.4 담당자 정보

```
[담당자 이름] [직급]
✉ email@example.com
📞 010-XXXX-XXXX
```

이메일·전화는 클라이언트 토큰으로 외부 주입.

## 11. 슬라이드 수 가감 룰

### 11.1 행사 규모 기반

| 행사 규모 | 권장 슬라이드 수 |
|----------|----------------|
| 소형 (참가자 1,000명 미만) | 12~13장 |
| 중형 (1,000~5,000명) | 14~15장 |
| 대형 (5,000~20,000명) | 16~18장 |
| 메가 (20,000명+) | 18장 (상한 유지) |

### 11.2 행사 유형별 가감

| 행사 유형 | 강조 섹션 |
|----------|----------|
| 전시회·박람회 | S4(노출 자산), S6(매트릭스) +1슬라이드 |
| 컨퍼런스·포럼 | S3(청중), S7(ROI) +1슬라이드 |
| 기업 행사 | S2(Why), S5(Tier) 간소화, 총 12~13장 |
| 페스티벌 | S4(노출), S2(맥락) 시각 강화, 총 14~15장 |

## 12. 콘텐츠 작성 체크리스트

각 슬라이드 작성 후 확인:

- [ ] 모든 데이터에 출처가 명시되었는가
- [ ] 추측·과장 표현이 없는가 ("수억원", "확실한", "압도적" 금지)
- [ ] 정량화 가능한 모든 숫자가 정량화되었는가
- [ ] 회사 종속 표현이 0건인가 ("당사", "M&C" 등)
- [ ] Tier 색상이 design-tokens-mapping 룰에 따라 정확히 적용되었는가
- [ ] 슬라이드 분량이 행사 규모에 맞는가 (12~18장)
