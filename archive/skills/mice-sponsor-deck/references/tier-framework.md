# Tier Framework — 스폰서 등급 표준 구조

본 문서는 스폰서 Tier 5단 + In-kind 별도 트랙 표준 구조를 정의한다. 클라이언트별 명칭·가격 모드는 외부 변수로 토글한다.

---

## 1. 표준 구조 (5단 + 1트랙)

| Tier | 표준명(EN) | 표준명(KO) | 슬롯 수 권장 | 가격 비중 | 핵심 혜택 |
|------|-----------|-----------|------------|-----------|----------|
| T1 | Title | 타이틀 | 1~2석 | 100% (기준) | 행사명 결합권, 키노트 무대, 메인 사이니지 |
| T2 | Platinum | 플래티넘 | 2~4석 | 60~70% | 메인 무대 노출, 프리미엄 부스, VIP 만찬 |
| T3 | Gold | 골드 | 4~8석 | 35~45% | 세션 스폰서, 표준 부스, 디지털 자산 |
| T4 | Silver | 실버 | 6~12석 | 20~25% | 사이니지 노출, 컴팩트 부스, 프로그램북 |
| T5 | Bronze | 브론즈 | 무제한 또는 20석+ | 10~15% | 기본 노출, 행사 패스 |
| T6 | In-kind | 현물 후원 | 별도 트랙 | 비금전 | 물품·서비스 제공 대가 노출 |

### 1.1 가격 비중 적용 가이드

T1 가격을 기준값(100)으로 잡고 T2~T5 가격을 비중에 맞춰 산정한다. 발주처가 가격을 명시하지 않은 경우 본 비중표를 가이드로 사용.

**예시:** T1 = 1억원 → T2 = 6,500만원 → T3 = 4,000만원 → T4 = 2,500만원 → T5 = 1,000만원

### 1.2 슬롯 수의 의미

슬롯 수는 본 스킬의 핵심 영업 도구다. **희소성을 표현해야 영업이 성립한다.**

- T1~T2는 한 자릿수로 한정 → 강한 희소성
- T3~T4는 두 자릿수 → 중간 희소성
- T5는 무제한 또는 대량 → 진입 장벽 낮춤

## 2. 명칭 오버라이드 룰

클라이언트나 행사 성격에 따라 표준 명칭을 오버라이드 가능. 단 **상→하 5단 구조는 유지**.

### 2.1 한국 시장 대체명 후보

| 표준 | 일반 대체 | 보수·공공 행사 | 화려·문화 행사 | 보석·럭셔리 콘셉트 |
|------|----------|----------------|---------------|------------------|
| T1 | 타이틀 | 주관 | 메인 | 다이아몬드 |
| T2 | 플래티넘 | 공동주최 | 프레스티지 | 사파이어 |
| T3 | 골드 | 후원 | 프리미엄 | 루비 |
| T4 | 실버 | 협력 | 공식 | 에메랄드 |
| T5 | 브론즈 | 일반 | 일반 | 펄 |

### 2.2 영문 병기 모드 (`naming_mode`)

| 모드 | 표기 형식 | 적용 시나리오 |
|------|----------|-------------|
| `ko_first` (기본값) | `타이틀 (Title)` | 한국 발주처·국내 기업 영업 |
| `en_first` | `Title (타이틀)` | 외국계 기업 영업, 다국어 행사 |

### 2.3 4단 또는 6단 구조 변경 요청 처리

기본은 5단 구조다. 클라이언트가 4단(T5 생략) 또는 6단(T1 위에 "Presenting Sponsor" 추가) 요청 시:

1. 사용자에게 명시적 확인: "표준은 5단입니다. 4단/6단으로 변경하시겠습니까?"
2. 승인 시 적용. 단 가격 비중표는 비례 재산출 필요
3. 6단의 경우 추가 Tier 명칭은 사용자가 지정해야 함

## 3. 가격 표시 모드 (`price_mode`)

### 3.1 `on_request` 모드 (기본값)

가격을 데크에 명시하지 않고 "별도 협의" 처리. 한국 시장 안전 관행.

**표기 예시:**

```
T1 Title
한정 1석 · 가격 별도 협의
```

**적용 시나리오:**
- 공공 행사 (가격 비공개 관행)
- 발주처가 가격 미확정
- 다양한 스폰서 수준에 유연 대응 필요

**CTA 슬라이드 동작:**
- "견적 협의를 위해 본 사무국으로 연락 주십시오" 문구 자동 삽입
- 담당자 연락처 표기 의무

### 3.2 `explicit` 모드

가격을 슬라이드에 직접 표기.

**표기 예시:**

```
T1 Title
한정 1석 · KRW 100,000,000 (VAT 별도)
```

**적용 시나리오:**
- 민간 B2B 행사 (가격 명시 선호)
- 표준화된 패키지 상품 (예: SMART MICE PLANNER Bespoke Plan)
- 빠른 의사결정 영업

**가격 표기 룰:**
- 통화 표기: `KRW` 또는 `USD` (행사 지역 따라)
- 천 단위 콤마 의무
- VAT 별도 또는 포함 명시
- "한정 N석" 항상 병기 (희소성 유지)

## 4. 슬롯 수 미확정 처리 (Phase 1 경고 룰)

발주처가 Tier 슬롯 수를 확정하지 않은 단계에서 데크 작성 요청 시:

### 4.1 표기 처리

```
T1 Title
한정 [TBD] 석 · 가격 별도 협의
※ 슬롯 수 확정 시 통지
```

### 4.2 사용자 경고 출력

```
⚠ 다음 Tier의 슬롯 수가 미확정입니다: T1, T2

영업 데크의 핵심 무기는 희소성 표현입니다. 슬롯 수 미확정 상태에서
영업을 진행하면 협상력이 약화됩니다. 가능한 한 빠르게 발주처와
슬롯 수를 확정하는 것을 강력히 권장합니다.

현 단계에서 잠정 데크 빌드를 진행하시겠습니까? (Y/N)
```

### 4.3 데크에 자동 캡션 삽입

미확정 Tier가 있는 경우 표지에 작은 캡션:

```
ⓘ 본 자료는 잠정 안이며, Tier 슬롯 수는 확정 시 통지됩니다.
```

## 5. In-kind 트랙 (T6) 별도 처리

현물 후원은 금전 가격이 아닌 **현물·서비스 가치 환산**으로 처리한다.

### 5.1 현물 환산 가이드

| 현물 유형 | 환산 기준 |
|-----------|----------|
| 음료·식음료 | 시장 도매가 기준 |
| 인쇄물·기념품 | 제작 단가 × 수량 |
| 기술·플랫폼 제공 | 시장 SaaS 가격 또는 라이선스 비용 |
| 인력·서비스 제공 | 일당 × 투입일수 |

### 5.2 In-kind 혜택 매핑

T6는 일반적으로 T4(실버) 수준의 혜택 매트릭스를 적용한다. 단 환산 가치가 T3 수준 이상이면 T3 혜택 적용 가능.

### 5.3 표기 예시

```
T6 In-kind 현물 후원
환산 가치 KRW 30,000,000 상당 · T4 Silver 동등 혜택
```

## 6. Tier 시각 구분 (디자인 토큰 매핑)

각 Tier는 jc-design-system 의 색상 토큰으로 시각 구분한다. 자세한 매핑은 `design-tokens-mapping.md` 참조.

| Tier | 토큰 | HEX | 용도 |
|------|------|-----|------|
| T1 Title | `--jc-point-magenta` | `#E91E63` | 차별화·최상위 강조 |
| T2 Platinum | `--jc-accent` | `#2962FF` | 메인 시그니처 |
| T3 Gold | `--jc-point-orange` | `#FF5722` | 핵심 시각 강조 |
| T4 Silver | `--jc-text-muted` | `#5A6270` | 중립 톤 |
| T5 Bronze | `--jc-border-strong` | `#C9CFD8` | 절제 톤 |
| T6 In-kind | `--jc-point-neon` | `#00E676` | 별도 트랙 구분 |
